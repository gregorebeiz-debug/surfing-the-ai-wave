## 🌊 The Wave Today — Noticias que mueven la aguja

### MCP 2026-07-28: El protocolo que usas todos los días cambió de forma estructural

El Model Context Protocol lanzó su especificación final el 28 de julio, y es el cambio más importante desde su creación. El mensaje central: MCP abandona el modelo stateful y se convierte en un protocolo request/response completamente stateless.

Lo que cambia en concreto:
- **Se elimina el handshake** — initialize/initialized y el `Mcp-Session-Id` desaparecen. Cada request ahora lleva su propia versión de protocolo, identidad del cliente y capacidades en el campo `_meta`.
- **Deployment en serverless y edge se vuelve nativo** — un load balancer round-robin puede despachar cualquier request a cualquier instancia. Esto cambia la arquitectura de servidores MCP de raíz.
- **Seguridad reforzada**: issuer verification (RFC 9207) y resource indicators (RFC 8707). OAuth e OIDC son ahora ciudadanos de primera clase.
- **400 millones de descargas SDK mensuales** — 4x vs principios de año. MCP no es hype, es infraestructura crítica.

Claude Code ya soporta la nueva spec. Si construyes o mantienes servidores MCP propios, este cambio rompe el modelo mental de "sesión persistente". Hay breaking changes reales: revisar el changelog antes de actualizar SDKs no es opcional.

### Claude Sonnet 5: El precio sube el 1 de septiembre — quedan 21 días

Anthropic confirmó el fin del pricing promocional de Claude Sonnet 5. A partir del 1 de septiembre: input pasa de $2 a $3 por millón de tokens (↑50%), output de $10 a $15 por millón de tokens (↑50%). Si tienes pipelines en producción que invocan Sonnet 5 directamente vía API, esta es la señal para auditar volúmenes. Las palancas disponibles: prompt caching para reducir input tokens repetitivos, batching para uso no-urgente, y evaluar si Haiku 4.5 cubre casos de uso high-volume donde la capacidad de Sonnet no es crítica.

*Fuentes: [Releasebot Anthropic](https://releasebot.io/updates/anthropic)*

### OpenAI GPT-5.6 mejora Sol — y o3 se retira el 26 de agosto

El 7 de agosto, OpenAI lanzó mejoras a GPT-5.6 Sol en ChatGPT y expandió GPT-5.6 Luna a usuarios free. En benchmarks, Sol lidera en coding (Artificial Analysis Coding Index: 80 pts), pero en SWE-Bench Pro Claude Mythos 5 lo supera por 15 puntos (80.3% vs 64.6%). La familia Sol/Terra/Luna se consolida como el stack de trabajo principal de OpenAI. Más accionable: **o3 se retira de ChatGPT el 26 de agosto**. Si usas o3 como comparación o para casos específicos de reasoning, tienes 16 días.
