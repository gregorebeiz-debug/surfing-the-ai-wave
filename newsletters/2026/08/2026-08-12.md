### 2. MCP 2026-07-28: el protocolo se vuelve stateless — y eso lo cambia todo

El mayor update a MCP desde su lanzamiento (nov 2024) aterrizó el 28 de julio y Claude comenzó a soportarlo oficialmente esta semana. Los tres cambios clave:

- **Stateless core:** Sin `initialize handshake`, sin `Mcp-Session-Id`. Cualquier request puede llegar a cualquier instancia. MCP servers ahora despliegan en serverless y edge sin session stores.
- **OAuth 2.0 + OIDC hardening:** Los servers MCP se conectan directamente a sistemas de identidad enterprise (Entra, Okta) sin workarounds.
- **Versioned extensions:** MCP Apps (UIs HTML servidas por el server) y Tasks (trabajo de larga duración con poll + subscribe) son ahora paquetes versionados independientes.

Downloads del MCP SDK superaron 400 millones/mes — 4x de crecimiento interanual. El protocolo se consolida como estándar de facto.

*Fuentes: [Claude Blog](https://claude.com/blog/bringing-mcp-2026-07-28-to-claude), [Nerd Level Tech](https://nerdleveltech.com/mcp-stateless-protocol-enterprise-authorization)*

### 3. OpenAI lanza GPT-5.6-Cyber — 95% de éxito en exploits de ciberseguridad

El 10 de agosto, OpenAI lanzó GPT-5.6-Cyber a través del programa **Daybreak Red** (acceso restringido a defensores verificados). Es un fine-tune de GPT-5.6 Sol entrenado para workflows de ciberseguridad ofensiva: encontrar zero-days, desarrollar exploit chains. Resultados declarados: 95% de completion rate en su eval interno de Advanced Cybersecurity — vs 1.5% del Sol estándar. Ya encontró dos vulnerabilidades inéditas en V8 (JavaScript engine de Chrome), parcheadas como CVE-2026-15903.

El programa Daybreak ahora tiene dos tiers: **Blue** (Sol estándar con guardrails para defensa) y **Red** (GPT-5.6-Cyber para investigadores vetados).

*Fuentes: [OpenAI](https://openai.com/index/expanding-daybreak-as-the-cyber-defense-window-narrows/), [SecurityWeek](https://www.securityweek.com/openai-unveils-new-cybersecurity-model-gpt-5-6-cyber/)*

### Claude Code — Tres bugs críticos de MCP corregidos en agosto

Tres fixes importantes llegaron silenciosamente este mes:
1. **MCP OAuth 401 burst (macOS):** Servers OAuth fallaban con ráfagas de 401 después de timeout del keychain, como si el usuario nunca hubiera autenticado.
2. **request_timeout_ms ignorado:** La configuración per-server de timeout (vía `--mcp-config` o `.mcp.json`) era ignorada; todas las llamadas caían al default de 60s en sesiones nuevas.
3. **/usage sobreatribución:** El panel de uso cargaba tokens a servers MCP incorrectamente — sobrecontaba todo lo que ocurría después de cualquier llamada a un server.

**Por qué te importa:** Si tienes MCP servers con auth OAuth o herramientas de larga duración (web scraping, compilaciones, llamadas a APIs lentas), estos tres bugs te afectaban directamente y podían generar timeouts y reportes de costo incorrectos. Actualiza Claude Code antes de seguir depurando problemas que ya están resueltos.

## ⚠️ Buyer Beware — Alerta de hype

**Todos hablan del 95% de GPT-5.6-Cyber, pero ojo porque...**

El claim de 95% de completion rate en exploits de ciberseguridad viene de una evaluación interna de OpenAI — no auditada externamente. El acceso está restringido a "vetted defenders" vía Daybreak Red con un proceso de vetting no público, lo que hace imposible verificar las cifras de forma independiente hoy. El riesgo dual-use es genuino: un modelo que completa el 95% de tareas ofensivas es exactamente lo que actores maliciosos querrían si encuentran acceso. Las dos CVEs de Chrome V8 son verificables y técnicamente impresionantes. El resto del claim sigue siendo marketing sin auditoría externa. Espera reproductibilidad independiente antes de tomar la cifra como referencia.
