## 🌊 The Wave Today — Noticias que mueven la aguja

### OpenAI estrena "Astra" — La apuesta por multi-agentes de largo horizonte

El 1 de agosto, OpenAI filtró su próxima familia de modelos llamada "Astra". Sam Altman la demostró en el Capitolio ante senadores y reguladores: múltiples agentes coordinándose durante horas o días en matemáticas avanzadas y proyectos complejos. Como prueba de capacidad, Astra publicó en GitHub las demostraciones de diez problemas matemáticos sin resolver en décadas. Aún sin fecha de lanzamiento, precio, ni nombre definitivo — ni siquiera está claro si se llamará GPT-6 o coexistirá con GPT-5.6 (Sol/Terra/Luna).

**Por qué importa:** Astra es el salto conceptual que separa los agentes actuales (reactivos, one-shot) de sistemas que planifican, delegan sub-tareas y revisan resultados durante periodos prolongados sin intervención humana. Si las capacidades demostradas llegan a producción, el paradigma de automatización agentica cambia fundamentalmente. Monitorea esto de cerca.

### EU AI Act: el enforcement real comienza hoy (2 de agosto)

Desde ayer, la Comisión Europea activó el enforcement completo del AI Act. Entran en vigor: requisitos de Anexo III para sistemas de alto riesgo, obligaciones de transparencia del Art. 50, evaluaciones de conformidad, marcado CE, y poderes sancionadores del AI Office. Multas: hasta €35M o 7% del volumen global para incumplimientos graves; hasta €15M o 3% para violaciones de transparencia. Dato preocupante: el 78% de organizaciones aún no ha tomado medidas significativas de cumplimiento.

**Por qué importa:** Si construyes agentes de automatización para clientes europeos — o para empresas que operan en la UE — este es el deadline que no se puede ignorar. Los sistemas de IA que toman decisiones de alto impacto (crédito, contratación, priorización) ahora tienen requerimientos de documentación y auditoría exigibles legalmente. No es teórico: el AI Office tiene poderes de inspección activos desde hoy.

*Fuentes: [AI Journal](https://aijourn.com/eu-ai-act-enforcement-expands-on-2-august-2026-are-your-ai-systems-compliant/), [Comisión Europea](https://commission.europa.eu/news-and-media/news/safer-and-more-transparent-ai-2026-08-02_en), [Legal Nodes](https://www.legalnodes.com/article/eu-ai-act-2026-updates-compliance-requirements-and-business-risks)*

## 🛠 Tool & Repo Watch — Herramientas y repos

### Bumblebee (Perplexity AI) — Supply chain scanner para entornos de desarrollo

Herramienta open-source que escanea tus dependencias, configuraciones MCP, extensiones de VS Code/Cursor/Windsurf y paquetes de npm/PyPI/Go buscando compromisos conocidos de supply chain. Opera en modo solo-lectura: **nunca ejecuta npm, pip ni ningún package manager** — lee directamente desde los lockfiles y metadatos en disco. Esto evita activar payloads maliciosos que se esconden en hooks de install/postinstall. Cubre 8 ecosistemas de paquetes más extensiones de editor y configuraciones MCP. Binario único en Go, sin dependencias de terceros.

**Por qué te importa:** Usas Claude Code con MCPs de terceros, Cursor, y potencialmente docenas de extensiones de VS Code. Bumblebee escanea exactamente ese perfil: MCP configs, editor extensions, lockfiles de proyecto — todo sin ejecutar nada. Un comando, visibilidad completa de tu exposición. Con 4,800+ estrellas en GitHub y activamente mantenido (último commit: junio 25, 2026).

- **Repo:** [github.com/perplexityai/bumblebee](https://github.com/perplexityai/bumblebee) | **Estrellas:** 4,800+ | **Licencia:** Apache 2.0
- **Acción sugerida:** **Instalar ahora.** Especialmente si tienes MCPs de terceros activos en Claude Code o Claude Desktop.

### OpenClaw — Framework de agentes autónomos open-source (355K+ estrellas)

Framework self-hosted para agentes autónomos con 355,000+ estrellas en GitHub — uno de los proyectos open-source de más rápido crecimiento en la historia de GitHub. Memoria persistente, soporte multi-modelo (GPT, Claude, Gemini, DeepSeek), integración nativa Telegram/Discord/WhatsApp. OpenClaw-RL (feb 2026) añade entrenamiento de agentes personalizados desde feedback conversacional asíncrono. OpenAI es sponsor oficial manteniendo la licencia MIT.

**Por qué te importa:** Si quieres desplegar agentes autónomos que no dependan 100% de la infraestructura cloud de Anthropic u OpenAI, OpenClaw es el proyecto más maduro del ecosistema. El soporte de Claude como backend lo hace directamente compatible con tu stack. 355K estrellas indica comunidad masiva, plugins de terceros, y casos de uso documentados que ahorran tiempo de implementación.

- **Repo:** [github.com/openclaw/openclaw](https://github.com/openclaw/openclaw) | **Estrellas:** 355,000+ | **Licencia:** MIT
- **Acción sugerida:** **Explorar.** Vale revisar si sus capabilities de memoria y multi-agente complementan o reemplazan partes de tu stack actual.

### Make.com — MCP server integration: tus scenarios como tools nativas de Claude

Make.com lanzó integración MCP nativa que permite exponer tus scenarios de automatización como MCP servers, invocables directamente desde Claude Desktop o Claude Code sin necesidad de webhooks HTTP manuales. También tiene módulo nativo de AI Agents para construir agentes goal-driven que encadenan tool calls.

**Por qué te importa:** Si tienes workflows activos en Make.com, ahora pueden ser tools nativas de Claude — el modelo puede llamarlos directamente como si fueran funciones. Esto es una integración de primer nivel entre tu stack de automatización y Claude Code. Elimina la fricción de construir intermediarios HTTP.

- **Fuente:** [Make.com](https://www.make.com/en/compare/make-vs-n8n)
- **Acción sugerida:** **Explorar** la configuración MCP server en tu cuenta Make.com si tienes scenarios activos. Potencial ganancia inmediata en flujos que ya existen.
