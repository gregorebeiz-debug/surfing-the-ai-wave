### 2. MCP spec 2026-07-28 llega a Claude — El protocolo se vuelve stateless

Claude ahora soporta el MCP spec 2026-07-28, el mayor cambio al protocolo desde su lanzamiento. Los cambios clave:

- **Stateless core**: Se elimina la sesión de inicialización. Cada request lleva su propio contexto. Los servidores MCP pueden correr en infraestructura serverless y edge sin coordinación de estado.
- **OAuth/OIDC hardening**: Integración nativa con Okta, Microsoft Entra ID y otros identity providers enterprise. Se agrega validación de issuer; inicia migración desde Dynamic Client Registration hacia Client ID Metadata Documents.
- **MCP Apps y Tasks**: Framework de extensiones versionadas para UIs interactivas y trabajo de larga duración — path formal para extender el protocolo sin cambiar el core.
- **MCP Tunnels (research preview)**: Conecta Claude a servidores MCP dentro de redes privadas sin exponer endpoints públicos — sin reglas de firewall inbound, sin IP allowlisting.

**Por qué importa:** Si tienes servidores MCP propios, el spec stateless abre el camino a deployar en Lambda o Cloudflare Workers. Los MCP Tunnels son la feature más subestimada de este release: acceso a herramientas internas sin abrir puertos hacia internet. El OAuth hardening es relevante si tus workflows tocan Slack, GitHub o cualquier herramienta con OAuth — la integración ahora es production-grade.

### 3. Anthropic watermarkea todo el output de Claude — Globalmente, no solo EU

Desde el 2 de agosto, todos los modelos Claude nuevos incluyen marcas de agua machine-readable en el texto generado. Archivos usan el estándar C2PA. Cumple con el Artículo 50 del EU AI Act. Anthropic aplicó la medida globalmente — si eres usuario en Colombia, tu output también está marcado.

Las marcas de agua se pueden eliminar con conversión de formato, re-guardado o screenshots. Anthropic publicará las herramientas de detección. No hay instrucción de cambiar nada en tus workflows.

**Ojo crítico:** La robustez técnica es limitada (el propio Anthropic lo reconoce), pero la señal regulatoria es clara: el ecosistema AI se está moviendo hacia trazabilidad de origen del contenido. Para tus flujos de automatización, este cambio es hoy invisible. A futuro, pipelines que generan contenido para clientes podrían requerir gestionar o documentar estas marcas.

### Rick Hightower — "LangGraph vs CrewAI vs Claude Agent SDK: Which AI Agent Framework Actually Wins in 2026?"

Análisis técnico publicado este mes con código real comparando los tres frameworks principales. Hightower documenta el patrón híbrido que más equipos de producción están adoptando en 2026: **LangGraph como orquestador de estado de alto nivel** (state machines, human-in-the-loop, audit trails, rollback points) con **nodos que llaman al Claude Agent SDK** para tareas de razonamiento especializado. El argumento central: los frameworks no son mutuamente excluyentes.

La comparación honesta del artículo: Claude Agent SDK gana en simplicidad (50 líneas vs. 400 para un agente equivalente en LangGraph) y en acceso al ecosistema MCP (GitHub, Slack, bases de datos en minutos). LangGraph gana en control determinístico, estado persistente y flujos condicionales complejos. CrewAI gana en velocidad de prototipado para equipos con roles definidos. El artículo también analiza cuándo ninguno de los tres es la respuesta correcta.

**Por qué leer:** Si usas Claude SDK directamente — tu stack actual — este artículo valida ese approach y muestra el umbral exacto donde vale la pena agregar LangGraph encima. No es hype: incluye benchmarks de producción de empresas como Klarna, Uber y LinkedIn que corren LangGraph en escala.

### Claude Code — Novedades de Agosto 2026

El changelog de agosto trae cambios de impacto directo en el workflow diario:

- **`/design` skill**: Convierte una idea o screenshot en una interfaz editable — sin salir de la terminal.
- **Modo Concise**: Nuevo estilo de output que lidera con el resultado. Menos narrativa, más código. Actívalo si tus sesiones se vuelven verbosas.
- **Auto-continue después de límite**: Claude no para abruptamente al alcanzar el rate limit — reanuda automáticamente cuando el período se resetea.
- **`ANTHROPIC_DEFAULT_MODEL` env var**: Configura el modelo que arranca en nuevas sesiones. Útil si manejas múltiples proyectos con modelos distintos.
- **Reglas como oraciones**: Las reglas de allow/deny ahora se escriben en lenguaje natural — `"don't ask for confirmation when running tests"` en vez de sintaxis declarativa.
- **`/claude-api` migration**: Migra proyectos Python de `anthropic` 0.x a 1.x automáticamente.
- **Fix MCP OAuth Slack**: Corregido el bug de redirect URI mismatch en el sign-in MCP para Slack. Si tenías problemas autenticando Slack en Claude Code, ya está resuelto.
- **Costo con premium de inferencia US**: Los estimados de costo ahora incluyen el 1.1× premium por workspaces de data-residency en US.

**Por qué te importa:** El modo Concise + auto-continue son los cambios de mayor impacto en el día a día. La env var `ANTHROPIC_DEFAULT_MODEL` elimina el overhead de configurar el modelo en cada proyecto nuevo. El fix del OAuth de Slack es relevante si tienes integración MCP activa con Slack.

→ [Changelog oficial](https://code.claude.com/docs/en/changelog) | Acción: **Actualizar y configurar `ANTHROPIC_DEFAULT_MODEL`**
