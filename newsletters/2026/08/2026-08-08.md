### Claude Code se ejecuta en tu infraestructura: Self-Hosted Environments

Anthropic lanzó `claude self-hosted-runner`: convierte tus propias máquinas o contenedores en el entorno donde corren las sesiones de Claude Code (web, mobile, desktop, Routine). Disponible para planes Team y Enterprise; desactivado por defecto — debes activarlo explícitamente.

Lo que importa: el código fuente, los artefactos de build y los secretos de tu empresa nunca salen de tu red. Puedes pre-instalar compiladores, SDKs internos y CLIs propietarios en el entorno antes de que Claude arranque una sesión. El resultado: Claude puede generar PRs, diagnosticar fallos de CI y responder a eventos del workflow de desarrollo directamente desde infraestructura bajo tu control.

No es un feature cosmético. Es la pieza que faltaba para que equipos con requisitos de compliance puedan usar Claude Code en serio sin negociar con el área legal. Si estás en un equipo con restricciones de egreso de datos, esto merece atención inmediata.

### Inference Hooks: DLP inline para Claude Enterprise

Desde el 5 de agosto, Claude Enterprise puede interceptar cada prompt antes de que llegue al modelo. La organización corre su propio servidor de seguridad que recibe el transcript completo de la conversación y devuelve un veredicto allow/deny. Un único punto de configuración cubre claude.ai, Cowork y Claude Code — en web, desktop y CLI.

El alcance es más amplio de lo que parece: cuando Claude llama una herramienta a través de MCP, la respuesta también pasa por el hook antes de volver al modelo. Esto significa que datos que fluyen a través de MCP servers también quedan bajo el perímetro de seguridad de la organización.

Limitación importante que no se debe ignorar: solo allow/deny. No se puede reescribir ni redactar prompts parcialmente. Un prompt con datos regulados se bloquea completo. La redacción del lado de la respuesta está planeada para versiones futuras, no disponible aún.

*Fuentes: [Unite.AI DLP](https://www.unite.ai/anthropic-puts-inline-data-loss-prevention-inside-claude-enterprise/), [Anthropic Release Notes](https://releasebot.io/updates/anthropic)*

### MCP 2026-07-28: la revisión más grande desde el lanzamiento

El protocolo que conecta a Claude con el mundo acaba de pasar de stateful (bidireccional persistente) a stateless (request/response). Es un cambio arquitectural profundo, altamente solicitado por equipos que sufrían problemas de confiabilidad con conexiones persistentes en producción.

Las novedades críticas para quien construye con MCP:

- **Tool Annotations**: los servers ahora declaran la intención de cada herramienta (read-only, destructive, idempotent, external). Cinco propuestas de nuevas anotaciones ya están en revisión, impulsadas por el mayor entendimiento de riesgo en workflows agénticos.
- **Tasks extension**: soporte nativo para trabajo de larga duración sin mantener conexión activa. Los agentes pueden lanzar tareas y recibir resultados asíncronamente.
- **Enterprise-Managed Authorization estable**: Anthropic, Microsoft y Okta ya adoptaron el estándar. Gestión centralizada de autorización para MCP servers a nivel de organización.
- **MCP Apps**: servers pueden renderizar UIs propias directamente — nuevas posibilidades para herramientas con interfaz visual.

Si tienes MCP servers en producción o en construcción, este spec change define cómo diseñar los próximos. Leer la migración antes de actualizar es obligatorio.

*Fuentes: [MCP Blog Release Candidate](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/), [MCP Spec 2026-07-28](https://blog.modelcontextprotocol.io/posts/2026-07-28/), [The New Stack](https://thenewstack.io/model-context-protocol-roadmap-2026/)*

### Simon Willison — "New release of LLM: reasoning traces, OpenAI Responses, server-side tools, smarter logging"

LLM 0.32 — definido por el propio Willison como la versión más significativa desde el lanzamiento — suma cuatro capacidades que juntas cambian el perfil de la herramienta: reasoning traces visibles en terminal (puedes ver el "thinking" del modelo mientras responde), soporte nativo para la OpenAI Responses API, server-side tools (el servidor ejecuta las herramientas; el cliente recibe resultados limpios), y SQLite content-addressable rediseñado para logging inteligente de conversaciones. El nuevo default model es GPT-5.6 Luna — económico pero capaz. Soporta cientos de modelos desde un CLI o librería Python unificada, incluyendo toda la familia Claude.

**Por qué ver:** Si mezclas Claude con otros modelos en scripts, pipelines o experimentos rápidos, LLM 0.32 te da en una sola herramienta la capa de tool calling, reasoning traces y logging que antes tenías que construir por separado para cada proveedor. Útil también para benchmarking rápido entre Claude Opus 5, GPT-5.6 Sol y Gemini desde la misma interfaz.

[Leer post completo](https://simonwillison.net/2026/Aug/4/new-release-of-llm/)

### Bumblebee (Perplexity AI) — Scanner de supply chain para endpoints de desarrollo

Herramienta open-source de Perplexity AI que audita paquetes instalados, extensiones de editor y configs de MCP en segundos — sin ejecutar ningún package manager. Lee solo lockfiles y metadata de disco.

**Por qué te importa:** Usas MCP servers de terceros y extensiones de Cursor/Windsurf. Bumblebee fue creado como respuesta directa a los gusanos Shai-Hulud y Mini Shai-Hulud que comprometieron paquetes de TanStack, SAP y Zapier. Escanea exactamente los vectores que más te exponen: MCP configs + extensiones de editor + dependencias de npm/PyPI. El binario Go no tiene dependencias externas — el propio scanner no tiene supply chain risk. Tres modos: baseline (rutina), project (repo específico), deep (respuesta a incidente).

Cubre: npm, pnpm, Yarn, Bun, PyPI, Go modules, RubyGems, Composer + MCP + VS Code/Cursor/Windsurf/Chromium/Firefox.

### OpenClaw — Agente personal AI local · 355K+ ⭐ GitHub

Agente AI personal open-source que corre enteramente en tu infraestructura, mantiene memoria entre conversaciones y puede actuar en tu máquina. Conecta con 29 canales de chat (WhatsApp, Telegram, Discord, Slack, iMessage, Signal...) y más de 50 integraciones. Creado por Peter Steinberger (fundador de PSPDFKit), pasó de 9K a 210K estrellas en 10 días en enero, y ya supera las 355K — cruzando a React en número de estrellas.

**Por qué te importa:** No es para instalar sin más; es para estudiar. OpenClaw está definiendo la arquitectura de referencia de lo que es un agente personal en 2026: local gateway que conecta modelos con integraciones de forma unificada, memoria persistente, multi-canal. Si construyes agentes propios o piensas en arquitecturas de automatización personal, esta es la implementación más observada del ecosistema en este momento.
