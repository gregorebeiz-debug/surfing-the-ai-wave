### Claude marca cada palabra que escribe — globalmente

Desde el 2 de agosto, todos los outputs de Claude llevan un **watermark invisible**: una señal machine-readable embebida en el texto como patrón estadístico de distribución de tokens. No es un badge visible — sobrevive copiar/pegar y ediciones menores.

**El porqué:** EU AI Act, Article 50 (transparencia en contenido sintético). Deadline para modelos legacy: 2 de diciembre de 2026. Multas por incumplimiento: hasta €15M o 3% del revenue global.

**El alcance real:** Global, no solo Europa. Si generaste texto con Claude desde agosto 2, ese output ya lleva marca. Modelos anteriores a esa fecha no tienen la funcionalidad todavía — Anthropic tiene hasta diciembre para actualizarlos.

**Por qué importa más allá del compliance:** Si produces contenido con Claude para clientes o productos, ese contenido es técnicamente rastreable. No es un problema hoy. La pregunta correcta es si los sistemas downstream (plataformas, publishers, verificadores) van a empezar a distinguir o penalizar contenido marcado en el futuro cercano.

*Fuentes: [Anthropic](https://www.anthropic.com/news/claude-text-watermark), [TechCrunch](https://techcrunch.com/2026/08/11/anthropic-says-it-will-watermark-text-generated-by-its-ai-models/), [The Register](https://www.theregister.com/ai-and-ml/2026/08/11/anthropic-pledges-to-embed-watermarks-to-help-discern-ai-slop-in-sop-to-eu/5285792)*

## 🛠️ Tool & Repo Watch — Herramientas y repos

### Claude Code — Hooks PreModelSwitch/PostModelSwitch (Aug 28)

Claude Code ahora permite interceptar cambios de modelo en tiempo real. Los nuevos hook events `PreModelSwitch` y `PostModelSwitch` dejan bloquear, confirmar, o anotar cuando Claude Code cambia de modelo mid-sesión. Los `SessionStart` resume hooks ahora reciben también la "staleness" de la sesión y el costo estimado de re-cache.

**Por qué te importa:** Si tienes pipelines automatizados con Claude Code, ahora puedes auditar exactamente cuándo y por qué cambia de modelo y bloquear cambios no autorizados en producción. El dato de re-cache cost es crítico para controlar costos en sesiones largas — especialmente relevante si tienes agentes de larga duración corriendo sin supervisión.

Otros cambios del update: live streaming de tool calls de subagentes foreground a Remote Control, spend limit bar en `/usage`, y per-session prompt-cache analytics en `/cost` (hit ratio, misses, tokens re-cached, warm/cold status).

**Stars:** N/A (feature de Claude Code) | **Link:** [Changelog oficial](https://code.claude.com/docs/en/changelog)
**Acción sugerida:** Instalar update y revisar hooks si tienes automatizaciones en producción.

### OmniRoute v3.8 — Gateway unificado para 290+ proveedores de LLMs

Gateway local MIT-licensed que pone 290+ providers (Claude, GPT, Gemini, DeepSeek, Kimi, Mistral, y más) detrás de un único endpoint OpenAI-compatible. Incluye token compression propietario que reduce costos de prompt entre 15% y 95%. Cero telemetría, credenciales encriptadas AES-256. 48K+ stars en GitHub.

**Por qué te importa:** En tus pipelines de n8n o agentes, si necesitas routing inteligente (precio, latencia, disponibilidad) entre modelos sin tocar el código de la aplicación, OmniRoute es el proxy que lo hace transparentemente. Compatible con Claude Code vía endpoint personalizado — lo que significa que puedes apuntar Claude Code a OmniRoute y tener fallback automático a GPT o Gemini si Claude está caído (como el outage del 16 de agosto). También útil para clientes que prefieren modelos distintos.

### Bumblebee (Perplexity) — Scanner de supply chain para tu setup de dev

Binary de Go (Apache 2.0, zero dependencias externas) que escanea tu máquina buscando packages, extensiones y configuraciones comprometidas. Soporta: npm/pnpm/PyPI/Go modules, **configs de MCP servers**, extensiones de VS Code, y extensiones de browser.

**Por qué te importa:** Si tienes docenas de MCP servers configurados — y si usas Claude Code probablemente los tienes — Bumblebee escanea esas configs contra catálogos de amenazas conocidas *sin ejecutar nada*: no corre npm, no hace network calls, no lee tu source code. Tiene tres perfiles: `baseline` (rutina), `project` (repo específico), `deep` (incident response). Diseñado para correr incluso en una máquina potencialmente comprometida. Con el ecosistema MCP escalando rápido y poca cultura de seguridad alrededor, esto llena un hueco real.

**Stars:** Trending (open-sourced mayo 2026) | **Licencia:** Apache 2.0 | **Link:** [github.com/perplexityai/bumblebee](https://github.com/perplexityai/bumblebee)
**Acción sugerida:** Instalar — la seguridad de tu setup de dev es infraestructura, no opcional.
