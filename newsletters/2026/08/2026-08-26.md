### Anthropic watermarks todos los outputs de Claude — desde el 2 de agosto

Desde el 2 de agosto, todos los modelos Claude nuevos marcan su texto generado con **watermarks machine-readable invisibles** y firman archivos con el estándar C2PA. Cumplimiento del Artículo 50 del EU AI Act — vigente desde el 2 de agosto, con multas de hasta €15M o 3% del volumen global ante incumplimiento.

Lo que debes saber:
- Los watermarks **pueden persistir a través de algunas ediciones**, pero se eliminan con format conversion, re-saving o screenshots.
- Anthropic proveerá herramientas de detección para verificación de terceros.
- Aplicación global (no solo UE). Modelos antiguos tienen hasta el 2 de diciembre para cumplir.
- Limitación reconocida por Anthropic: si Claude traduce o edita texto humano, ese texto podría quedar marcado como "AI-generated" aunque el contenido original sea humano.

### MCP 2026-07-28 — El protocolo se vuelve stateless

El cambio más importante en infraestructura de agentes de los últimos 12 meses: MCP abandona el modelo bidireccional stateful y adopta **request/response puro**. Lo que esto rompe y lo que habilita:

**Lo que cambia (breaking):**
- El handshake `initialize/initialized` fue **eliminado por completo** — ya no existe `Mcp-Session-Id`
- Cada request ahora es autodescriptivo: lleva client info, capabilities y versión inline en un campo `_meta`
- Los features Roots, Sampling y Logging fueron marcados como **deprecated**
- El transporte HTTP+SSE (el original) queda como **Deprecated**

**Lo que habilita:**
- Servers pueden correr en **serverless y edge** sin Redis compartido ni session stores
- Se añaden headers requeridos de `method` y `tool-name` para routing sin parsear JSON body
- MCP acaba de superar 400M de descargas mensuales de SDK — 4x de crecimiento anual

El debate en la comunidad es real: [InfoQ pregunta si MCP stateless es simplemente un API con mejor branding](https://www.infoq.com/news/2026/08/mcp-stateless-gateway/). Ambos lados tienen argumentos válidos.

**Por qué ver:** Si construyes con Claude Code + MCP servers propios, este cambio te afecta directamente. Tus servers con handshake existentes necesitan actualización. La guía de breaking changes de Stacktree es el recurso más concreto disponible.

### Cloudflare Kitesurf — El primer browser para agentes de IA

Lanzado el 6 de agosto: un runtime de browser **construido específicamente para agentes de IA**, corriendo en V8 isolates sobre Cloudflare Workers. El razonamiento es sólido: un browser para agentes no necesita tabs, temas, extensiones ni UI visual — necesita eficiencia de tokens, scalability y compatibilidad con CDP.

**Números:**
- 3-7x menos CPU y memoria para tareas agentic típicas vs Chromium
- Stateless por diseño
- Pasa 235,000+ Web Platform Tests (97% DOM, 96% HTML subtests)
- Expone endpoint CDP — **compatible con Playwright, Puppeteer y MCP clients**
- Construido en Rust + WebAssembly, usando Blitz (rendering), Stylo (CSS parser de Firefox) y Boa JS
- Disponible gratis en beta en Browser Run

12 semanas de desarrollo: primer commit en mayo, beta en producción en agosto.

**Por qué ver:** Si tienes agentes que hacen web scraping o browser automation — sea desde n8n, Claude Code con Playwright, o pipelines custom — Kitesurf es una alternativa edge-native con costo operacional significativamente menor. El endpoint CDP + MCP lo hace plug-and-play con el stack que ya usas. En beta y gratuito ahora.

[Leer: TechCrunch](https://techcrunch.com/2026/08/07/cloudflare-launches-kitesurf-a-browser-built-for-ai-agents/) | [Docs oficiales](https://developers.cloudflare.com/browser-run/kitesurf/)
