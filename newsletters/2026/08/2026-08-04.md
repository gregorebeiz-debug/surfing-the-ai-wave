### MCP 2026-07-28: stateless, serverless-ready, y 400M descargas mensuales

La especificación MCP 2026-07-28 es el cambio más significativo al protocolo desde su lanzamiento. El titular técnico: se elimina el handshake `initialize/initialized` y el header `Mcp-Session-Id`. Cada request ahora es completamente autónomo — lleva su propia versión, identidad del cliente y capabilities. Consecuencia directa: los servidores MCP pueden desplegarse en infraestructura serverless y edge (AWS Lambda, Cloudflare Workers) detrás de cualquier load balancer round-robin estándar. Ya no se necesitan conexiones persistentes.

Los cambios adicionales son igualmente relevantes: Multi Round-Trip Requests (flujos multi-paso sin WebSocket), caching de list results, hardening de autorización alineado con OAuth 2.0 y OIDC enterprise (Entra, Okta sin workarounds), y un framework de extensiones formales para MCP Apps y Tasks. Anthropic confirmó que Claude adoptará esta spec. El SDK ya tiene actualizaciones Tier 1.

Por qué importa más de lo que parece: MCP supera 400 millones de descargas mensuales del SDK — 4x de crecimiento este año — y se está consolidando como el estándar de facto para conectar agentes de IA a aplicaciones. Este spec release hace que construir y operar servidores MCP sea radicalmente más económico. Si has estado posponiendo construir un MCP server propio (para conectar Claude a tus datos, a n8n, o a cualquier sistema interno), el argumento a favor acaba de volverse mucho más fuerte.

Luna a $0.20/$1.20 por millón de tokens es ahora uno de los LLMs comerciales más baratos disponibles — competitivo con opciones open-source en inferencia cloud. La mejora técnica detrás del precio: más de 15% mejor eficiencia de generación de tokens vía speculative decoding mejorado.

Por qué importa: Si tienes pipelines de automatización usando GPT vía API, la ecuación económica cambió. Luna es viable para tareas de clasificación, extracción y summarización de alto volumen donde antes solo considerabas modelos más ligeros. La presión de precios entre OpenAI y Anthropic beneficia directamente tu wallet si construyes con ambos.

Anthropic expandió Cowork a la app de Claude en iOS, Android y claude.ai web (rollout iniciado 7 de julio, beta en curso). ## 🔧 Tool & Repo Watch — Herramientas y repos

### OpenClaw — El agente autónomo open-source más starreado de la historia

**Qué es:** Framework open-source de agente IA que corre localmente. Se conecta a Claude, GPT-5.6, DeepSeek o modelos locales vía Ollama, y puede ejecutar comandos shell, leer/escribir archivos, navegar la web, enviar emails y controlar sistemas vía un sistema de "skills" extensible. Autónomo: no necesita intervención paso a paso.

**Por qué te importa:** Su arquitectura de skills es directamente análoga a como Claude Code maneja herramientas. Si ya construyes automatizaciones con Claude, OpenClaw es el runtime complementario para tareas que prefieres mantener completamente local y off-cloud. El caso de uso concreto: un agente 24/7 corriendo en tu máquina que ejecuta scripts, monitorea archivos, dispara webhooks a n8n, y reporta resultados — sin depender de ningún plan de suscripción. El riesgo real: surface de ataque amplia (shell + filesystem + acceso web = vector crítico). No conectar a sistemas de producción sin sandboxing.

- **GitHub stars:** 280,000+ (superó a React como el repo más starreado de GitHub en <60 días)
- **Link:** [OpenClaw](https://www.kdnuggets.com/openclaw-explained-the-free-ai-agent-tool-going-viral-already-in-2026)

### Claude Code: subagentes anidados hasta profundidad 3

**Qué cambió:** Después de habilitar anidamiento en profundidad 5 (junio), deshabilitarlo completamente (21 julio), y re-habilitarlo a profundidad 3 (24 julio, v2.1.219), Claude Code tiene ahora su modelo de agentes anidados estabilizado. Por defecto: orquestador → workers → helpers (3 niveles). Configurable con `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1` para deshabilitar el anidamiento.

**Por qué te importa:** Tres niveles son el punto óptimo para la mayoría de pipelines reales. El patrón natural es: Claude principal como orquestador de alto nivel → subagentes especializados por dominio → helpers para tareas atómicas. El token math se complica exponencialmente más allá de 2 niveles — cada frame hereda el contexto del padre, así que gestionar `budget_tokens` explícitamente en el prompt de cada subagente es crítico para no desperdiciar contexto.

- **Versión:** v2.1.219 (24 julio 2026)
- **Link:** [Claude Code Changelog](https://code.claude.com/docs/en/changelog)
- **Acción sugerida:** Explorar para workflows multi-etapa en Claude Code

### Claude Code: MCP connector data en artefactos publicados

**Qué es:** Los artefactos publicados desde Claude Code ahora pueden llamar connectors MCP en cada visualización. Un dashboard publicado muestra datos en vivo, sin necesidad de re-publicar.

**Por qué te importa:** Si publicas artefactos para clientes, equipos o uso propio, esto los convierte en interfaces vivas conectadas a tus datos. Compatible con cualquier connector MCP que ya tengas configurado en Claude (Google Drive, Gmail, APIs custom). El modelo es simple: el artifact llama al MCP connector cada vez que alguien lo ve, ejecuta la lógica, y renderiza con datos frescos.
