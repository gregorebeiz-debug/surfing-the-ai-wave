## 🌊 The Wave Today — Noticias que mueven la aguja

### 1. Anthropic pone marcas de agua invisibles en todo el texto de Claude — y aplica globalmente

A partir de los modelos lanzados el 2 de agosto de 2026, Claude embebe una señal imperceptible y legible por máquina en cada respuesta de texto. La marca viaja con el texto cuando se copia y pega, sobrevive ediciones menores, y Anthropic publicará las herramientas de detección para que cualquiera pueda verificarla. La motivación oficial es cumplir el Código de Transparencia del AI Act de la UE, pero Anthropic decidió activarlo en todas las geografías, no solo en Europa. Cubre Claude.ai, Claude API, Claude Code, Claude Cowork y Claude Tag.

Lo que importa: esto cambia el game para contenido generado con AI. Los detectores de AI actuales son poco confiables — esto crea una señal técnica verificable. Para Gregorio: si generas borradores, emails o código con Claude que luego distribuyes como output propio, ese contenido ahora potencialmente lleva una huella técnica. No es urgente actuar, pero sí entender las implicaciones para flujos donde el origen del texto importa.

### 2. OpenAI pausa Astra: primer modelo que alcanza nivel "Crítico" de riesgo cibernético

OpenAI frenó el desarrollo interno de Astra — su próximo modelo de frontera — después de que alcanzara el umbral "Crítico" de su Preparedness Framework. El nivel Crítico significa que el modelo puede, de forma autónoma, identificar zero-days o ejecutar ataques novedosos contra sistemas hardened sin apoyo humano. El nivel previo (High, donde cayó GPT-5.6 en junio) requería más scaffolding para completar ataques end-to-end. Astra lo supera solo.

La respuesta: monitoring universal de acciones de riesgo y desalineación en todas las aplicaciones agénticas de Astra, con monitores que evalúan el Chain of Thought y pueden interrumpir actividad de alto riesgo. Sin fecha de lanzamiento pública por ahora.

Lo que importa: esto es la primera vez que el framework de seguridad detiene activamente un modelo frontier antes de llegar al mercado. Señal de que las capacidades cibernéticas de los LLMs están acelerando en formas que las propias labs no esperaban. Hay que seguir esto de cerca — tanto para entender el contexto de los siguientes releases de OpenAI como para las implicaciones regulatorias que vienen.

*Fuentes: [Forbes](https://www.forbes.com/sites/jonmarkman/2026/08/09/openai-pauses-astra-after-it-nears-first-ever-critical-cyber-risk/), [The Hacker News](https://thehackernews.com/2026/08/openais-next-ai-model-astra-shows-cyber.html), [OpenAI](https://openai.com/index/responding-next-frontier-critical-cyber-capabilities/)*

### 3. GPT-5.6 Sol: 14X de velocidad con modo Ultrafast y agent performance mejorado

OpenAI lanzó GPT-5.6 con un modo Ultrafast para Sol que reclama hasta 14X de velocidad sobre el baseline. La actualización incluye mejor performance en tareas agénticas a menor costo, nuevos controles en la Responses API para continuidad de razonamiento, orquestación multi-agente nativa, tool calling programático mejorado, y mejor prompt caching. Los modelos Daybreak ya están disponibles en AWS desde el 11 de agosto. Además, OpenAI retiró o3 de ChatGPT (sunset 26 de agosto).

Sin demos técnicos verificados todavía. "14X de velocidad" es la afirmación de OpenAI — evaluación independiente pendiente.

## 🔧 Tool & Repo Watch — Herramientas y repos

### Claude Security Plugin (Beta) — Escáner de vulnerabilidades multi-agente en el terminal

Anthropic lanzó en beta el 23 de julio el plugin de seguridad para Claude Code. Instala desde el marketplace con un solo comando, agrega `/claude-security` a tu sesión activa, y corre un equipo de agentes Claude que mapea el codebase, identifica threats, conecta issues entre archivos y lógica de negocio, verifica independientemente los hallazgos, y genera patches para que tú los revises y apliques.

**Por qué te importa:** Corres Claude Code a diario para build de agentes y automatizaciones. Este plugin corre dentro de tu sesión existente — zero overhead de setup adicional. Lo ideal: `/claude-security` antes de cada commit en repos que exponen lógica sensible o APIs. Es gratis (usa tu inference existente de Claude) y disponible para todos los Claude Code users.

→ Sugerencia: **Install** | [Guía completa](https://www.metirai.com/blog/claude-security-plugin-public-beta-guide-2026)

Claves y datos residen en tu máquina con SQLite + AES-256. 23.6k+ estrellas en GitHub, activamente mantenido.

Si quieres alternar entre Kimi K3, DeepSeek-V4 y Claude sin cambiar config en cada tool — esto lo resuelve.

### Claude Code — Actualizaciones agosto 2026

- **GitLab MR support:** El flag `--worktree` y la vista `claude agents` ahora aceptan URLs de merge requests de GitLab (!N). Si tienes proyectos en GitLab además de GitHub, ya puedes usar el flujo de worktrees directamente con MRs.
- **MCP OAuth fix:** Se resolvió el bug donde el sign-in fallaba con redirect URI mismatch en servidores con cliente OAuth pre-registrado (afectaba Slack). Si tenías el conector MCP de Slack roto, actualiza.
- **SSE keepalive pings:** Previene idle-timeout disconnects en streaming largo contra Vertex y Bedrock. Relevante si usas Claude a través de AWS o GCP.
- **VSCode Focus View + sandbox credential masking:** Mejoras de UX y seguridad en el IDE.

**Por qué te importa:** Actualizaciones de mantenimiento con un impacto directo si usas Slack MCP o GitLab. El fix de OAuth especialmente — era un bug molesto. Actualiza Claude Code si no lo has hecho esta semana.

→ Sugerencia: **Update** | [Changelog](https://code.claude.com/docs/en/changelog)

### OpenClaw — 210k estrellas | Gateway AI local para 50+ integraciones de mensajería

Personal AI assistant que corre completamente en tus propios dispositivos. Actúa como gateway local conectando modelos AI a WhatsApp, Telegram, Slack, Discord, Signal, iMessage y 44 integraciones más. Creado por el fundador de PSPDFKit, viral desde enero 2026, ya en 210k+ estrellas.

**Por qué te importa:** Si tienes workflows de automatización en n8n que involucran mensajería, OpenClaw es el complemento local-first para el edge más personal — tus chats.
