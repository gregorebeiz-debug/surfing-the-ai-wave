### Anthropic Divide tu Uso de Claude en Dos Bolsillos — Deadline: 15 de Junio

A partir del 15 de junio, Anthropic separa el uso programático del interactivo en pools de crédito distintos. Claude Agent SDK, `claude -p`, Claude Code GitHub Actions y agentes de terceros salen del límite normal de tu suscripción y pasan a un crédito mensual separado, facturado a tarifas API completas sin rollover. El uso interactivo (Claude.ai web, Claude Code en terminal, Claude Cowork) no se toca.

**Las cifras:** Pro: $20/mes, Max 5x: $100/mes, Max 20x: $200/mes. Si consumes más, puedes habilitar "usage credits" para que el exceso se facture como API — o bloquearlo y que las llamadas fallen.

**Las dos acciones que debes tomar:** (1) Espera el email de Anthropic el 8 de junio para activar tu crédito — Anthropic envía un enlace de claim, no es automático. (2) Evalúa cuánto usas `claude -p` o GitHub Actions headless hoy; con $20 en Pro a tarifas API, el crédito se agota más rápido de lo que parece.

El análisis más honesto lo hace [MagnaCapax en GitHub Gist](https://gist.github.com/MagnaCapax/d9177e35b355853f03c730dfcaa693ef): para ciertos workloads el precio efectivo sube entre 12x y 175x respecto al acceso anterior. No es alarmismo — es matemática.

### Claude Code Dynamic Workflows — Decenas de Subagentes en Paralelo en una Sola Sesión

Anthropic lanzó Dynamic Workflows en research preview el 28 de mayo. La mecánica: Claude diseña su propio script de orquestación, ejecuta decenas a cientos de sub-agentes en paralelo dentro de una sesión, verifica los resultados, y te entrega el producto final. No es solo "más contexto" — es una arquitectura distinta donde el modelo escribe el pipeline que necesita para resolver el problema.

El caso de uso que pone los números en perspectiva: Bun usó Dynamic Workflows para migrar su runtime completo de Zig a Rust, generando 750,000 líneas de código con 99.8% del test suite pasando, once días desde el primer commit al merge.

Activación: `/workflows` para ver tus runs activos. También puedes activar el modo `ultracode` para que Claude decida automáticamente cuándo usar un workflow. Disponible para Max, Team Premium, Enterprise y via Claude API/Bedrock/Vertex AI.

**Advertencia real que hay que tomar en serio:** Los Dynamic Workflows consumen sustancialmente más tokens que una sesión normal. Empieza con una tarea acotada antes de lanzar sobre tu codebase completa.

En el mismo batch de actualizaciones: Opus 4.8 es el nuevo default para Max, Team Premium y Enterprise. Fast Mode en Opus 4.8 corre a 2x el costo estándar pero 2.5x la velocidad — relevante si tienes pipelines donde la latencia importa.

*Fuentes: [Anthropic Blog](https://claude.com/blog/introducing-dynamic-workflows-in-claude-code), [ExplainX.ai](https://explainx.ai/blog/claude-code-dynamic-workflows-2026), [Claude Code Changelog](https://code.claude.com/docs/en/whats-new)*

### Gemini 3.5 Flash en GA — El Precio/Rendimiento que Cambia el Cálculo para Agentes

Google liberó Gemini 3.5 Flash a disponibilidad general tras el Google I/O 2026 (19 de mayo). Los números que merecen atención: SWE-bench 81.0% — un punto porcentual sobre Claude Opus 4.6 (80.8%), ventana de contexto de 1M tokens, input acepta texto, imágenes, audio, video y PDFs, hasta 64K tokens de output. Precio: $1.50 por millón de tokens de entrada / $9 por millón de salida, con 90% de descuento en cached input ($0.15/M tokens).

La velocidad es el diferenciador real: 4x más rápido que modelos comparables de tier frontier. Para agentic workflows donde corres muchas llamadas LLM en serie o paralelo, esa diferencia se traduce directamente en tiempo de ejecución y costo.

**Lectura crítica:** No es una victoria aplastante sobre Claude — los benchmarks de coding y agentes están muy parejos entre los modelos top de 2026. Lo que sí cambia: para pipelines donde no necesitas las capacidades específicas de Claude (multimodal profundo, razonamiento largo), Gemini 3.5 Flash ofrece una alternativa seria con precio competitivo. Conviene tenerlo en el toolkit.

*Fuentes: [MarkTechPost](https://www.marktechpost.com/2026/05/20/google-introduces-gemini-3-5-flash-at-i-o-2026-a-faster-and-cheaper-model-for-ai-agents-and-coding/), [Google Blog](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-5/), [Appwrite Deep Dive](https://appwrite.io/blog/post/gemini-3-5-flash-deep-dive)*

## Tool & Repo Watch — Herramientas y repos

### MCP Tunnels + Self-Hosted Sandboxes (Anthropic Managed Agents)

Anthropic presentó dos features de infraestructura agéntica en Code with Claude London (19 de mayo), ambos con impacto directo en deployments privados:

**Self-hosted sandboxes:** La ejecución de herramientas ocurre en tu infraestructura (Cloudflare Workers, Daytona, Modal, Vercel). Anthropic gestiona orquestación y context handling; el código corre en tus servidores. Ya en beta pública.

**MCP Tunnels:** Permite que Managed Agents y la Messages API se conecten a servidores MCP privados sin exponer puertos al exterior. El gateway despliega una conexión outbound cifrada hacia la infraestructura de Anthropic — tus sistemas internos nunca son directamente alcanzables desde internet. En research preview.

**Por qué te importa:** El bloqueador histórico para agentes en producción ha sido el acceso a sistemas internos (bases de datos, APIs privadas, herramientas detrás de firewall). MCP Tunnels resuelve exactamente eso sin comprometer la postura de seguridad. Si construyes agentes con Claude Code + MCP servers locales, este feature es el camino hacia deployments más robustos.

→ [The Decoder](https://the-decoder.com/anthropic-adds-self-hosted-sandboxes-and-mcp-tunnels-to-claude-managed-agents/) | [InfoQ](https://www.infoq.com/news/2026/05/claude-mcp-tunnels/) | **Acción: Explore**

### Claude Code Plugins — Auto-Carga desde .claude/skills + Scaffolding

A partir de v2.1.150+, los plugins en `.claude/skills/` se cargan automáticamente al iniciar Claude Code. Nuevo comando: `claude plugin init <nombre>` genera el scaffold completo de un nuevo plugin. Autocompletado para `/plugin` con subcomandos, nombres instalados y plugins de marketplaces conocidos.

**Por qué te importa:** Si ya tienes skills personalizadas en `.claude/skills/`, ahora se activan sin configuración adicional — zero friction. `claude plugin init` acelera la creación de nuevas skills. Esto más Dynamic Workflows crean la combinación más potente hasta ahora para automatizar tareas complejas directamente desde Claude Code.

→ [Claude Code Changelog](https://code.claude.com/docs/en/whats-new) | **Acción: Usar hoy**

### claude ultrareview — Fleet de Agentes Cloud para Code Review

Research preview de `/ultrareview`: una flota de agentes en la nube especializados en hunting de bugs, con acceso a más contexto y capacidades de análisis que lo que corre en una sesión local. Disponible como comando en Claude Code CLI, Desktop y extensión VS Code.

### LangGraph v0.4 + LangMem — Memoria de Largo Plazo para Agentes

LangGraph v0.4 (abril 2026) trae mejoras en state persistence y checkpoints Human-in-the-Loop más granulares.
