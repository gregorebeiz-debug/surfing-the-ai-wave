### Great American AI Act: el Congreso quiere congelar las leyes estatales de IA por 3 años

Los representantes Jay Obernolte (R-CA) y Lori Trahan (D-MA) presentaron el borrador de 269 páginas del "Great American Artificial Intelligence Act". Su provisión central: preemption federal de toda ley estatal que regule el *desarrollo* de modelos frontier — por tres años. California AB 2013 (reporte de datos de entrenamiento), Colorado AI Act, y toda regulación estatal quedarían suspendidas si pasa. Las leyes que regulan el *uso y deployment* de IA quedan excluidas de la preemption.

Sigue siendo un discussion draft, no una ley. Pero la presión de la industria es real y bipartidista. Para quienes construyen agentes: menos fricción regulatoria en el corto plazo, pero también menos precedente de protección. El debate acaba de empezar.

### Anthropic — "Introducing Dynamic Workflows in Claude Code"

Claude Code v2.1.154 introdujo *ultracode*, una nueva configuración que activa effort level `xhigh` y permite que Claude auto-orqueste Dynamic Workflows: el modelo divide tareas complejas en subtareas independientes, las ejecuta como subagentes en paralelo, valida resultados, y entrega respuesta final consolidada — sin que el usuario tenga que escribir la palabra "workflow". Se activa desde el effort menu o pidiendo explícitamente que cree un workflow.

Casos de uso documentados internamente por Anthropic: auditorías de seguridad en codebases completas, bug hunts en paralelo sobre múltiples archivos, optimizaciones guiadas por profiler. Shippeado junto a Claude Opus 4.8 el 28 de mayo.

**Por qué explorar:** Usas Claude Code a diario para automatización y agentes. Ultracode cambia fundamentalmente cómo Claude aborda tareas complejas — ya no es un solo contexto secuencial, sino orquestación automática de subagentes paralelos. La próxima vez que le pases un task grande, actívalo y compara el output.

### Claude Code MCP — Bug fixes críticos en el ciclo reciente

Tres fixes con impacto directo en workflows con MCP:

1. **Timeout sub-1000ms:** Valores de timeout configurados por debajo de 1000ms ya no abortan silenciosamente cada tool call. Ahora se ignoran y caen al valor default (`MCP_TOOL_TIMEOUT` o default del sistema). `claude mcp get` los anota.
2. **Parallel tool calls:** Un Bash fallido ya no cancela el lote completo — cada tool retorna su propio resultado independientemente. Fix directo para workflows de múltiples herramientas en paralelo.
3. **Conectores claude.ai:** Los conectores que nunca usaste ahora se ocultan detrás de "Show unused connectors" — menos ruido en `/mcp`.

**Por qué te importa:** Si tienes MCP servers con timeouts custom bajo 1s, o workflows con múltiples tool calls en paralelo (como n8n → Claude → múltiples tools), estos fixes corrigen comportamiento que probablemente causaba fallos silenciosos. Actualizar Claude Code es el paso inmediato.

**Acción sugerida:** Instala/actualiza. Revisar tus MCP server configs.
