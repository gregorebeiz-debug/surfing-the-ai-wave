### URGENTE: Billing change June 15 — Tu Agent SDK deja de correr contra tu suscripción

A partir del **15 de junio de 2026**, el uso programático de Claude se separa en un pool de créditos independiente. Lo que cambia:

- **Afectado:** `claude -p` (headless), Claude Code GitHub Actions, Agent SDK, apps de terceros que autentiquen vía Agent SDK
- **No afectado:** Claude Code interactivo en terminal/IDE, claude.ai chat, Claude Cowork
- **Crédito mensual separado:** $20 (Pro), $100 (Max 5x), $200 (Max 20x) — a tasas de API completa, sin rollover
- **Para teams con CI/CD compartido:** Los créditos son por usuario, no pool de equipo. Si tienes workflows de GitHub Actions corriendo bajo credenciales de múltiples usuarios, considera migrar a API Platform pay-as-you-go.

**Acción concreta:** Si usas `claude -p` en scripts o GitHub Actions, revisa tu presupuesto ahora. El cambio ocurre en 7 días.

### Claude Code Dynamic Workflows — Ultracode es real y ya está disponible

El 28 de mayo, Anthropic lanzó en research preview los **Dynamic Workflows** para Claude Code, disponibles en todos los planes pagos (Pro, Max, Team, Enterprise). En Max y Team están activados por defecto.

Qué hace: Claude puede ahora crear dinámicamente scripts de orquestación, dividir trabajo complejo en subtareas paralelas, correr múltiples subagentes (hasta 1,000) de forma coordinada, y validar resultados antes de presentar la respuesta final. El progreso se guarda, los runs interrumpidos pueden reanudarse.

**Ultracode** es el modo de esfuerzo `xhigh` + activación automática de workflows: cuando está encendido, Claude decide por sí mismo cuándo una tarea justifica lanzar un workflow completo. Casos de uso documentados: bug hunts en todo el codebase, auditorías de optimización con profiler, security hardening passes completos.

**Por qué te importa:** Si construyes con Claude Code diariamente, esto cambia el tipo de tareas que puedes delegar. Un security audit de tu repo entero ya no es una tarea manual de horas. El modelo se convierte en un coordinador de agentes, no solo un generador de código.

*Fuentes: [Anthropic Blog](https://claude.com/blog/introducing-dynamic-workflows-in-claude-code), [InfoQ](https://www.infoq.com/news/2026/06/dynamic-workflows-claude-code/), [Claude Code Docs](https://code.claude.com/docs/en/workflows)*

### Claude Managed Agents: Sandboxes privados + MCP Tunnels

Anthropic anunció en Code with Claude London (mayo 2026) dos features nuevos para Managed Agents:

1. **Self-hosted sandboxes (public beta):** La ejecución de tools se mueve a infraestructura que tú controlas — tu servidor, Cloudflare, Daytona, Modal o Vercel. El loop de orquestación del agente sigue en Anthropic, pero los archivos, código y datos no salen de tu perímetro.

2. **MCP Tunnels (research preview):** Conexión cifrada end-to-end entre Claude y MCP servers dentro de tu red privada, sin exponer endpoints públicos ni abrir reglas de firewall inbound. Un gateway liviano abre una sola conexión outbound desde dentro de tu red.

**Por qué importa en tu stack:** Si tienes APIs internas, bases de datos privadas, o MCP servers locales que quieres conectar a Managed Agents, MCP Tunnels elimina el requisito de exponer esos sistemas al internet público. Pide acceso al research preview si construyes agentes con datos sensibles.

*Fuentes: [The Decoder](https://the-decoder.com/anthropic-adds-self-hosted-sandboxes-and-mcp-tunnels-to-claude-managed-agents/), [Claude Blog](https://claude.com/blog/claude-managed-agents-updates), [InfoQ](https://www.infoq.com/news/2026/05/claude-mcp-tunnels/)*

### OpenClaw — Agente personal open-source, auto-hospedado, 247k stars en GitHub

Qué hace: Gateway personal de IA que corre completamente en tus propios dispositivos y te conecta con AI en los canales que ya usas: WhatsApp, Telegram, Slack, Discord, Signal, iMessage. MIT license. Memoria a largo plazo, sub-agents, cron scheduling, 5,400+ community skills en ClawHub. Puede escribir nuevos skills autónomamente para nuevas tareas.

**Por qué te importa:** Si construyes automaciones y flujos de agentes que actualmente viven en n8n o Make.com, OpenClaw representa un paradigma diferente: el agente vive *en tu infraestructura* y se activa por los canales de mensajería que ya usas. No reemplaza n8n para workflows complejos de datos, pero para "AI assistant personal que habla WhatsApp y tiene memoria" es la opción más madura del mercado open-source. El repositorio original fue transferido a la OpenClaw Foundation (neutral, community-governed) después de que el creador Peter Steinberger se unió a OpenAI.

247k+ estrellas en GitHub. Acción: **Explorar** — especialmente la integración con WhatsApp y la API de skills para ver si se puede usar como capa de interfaz para tus agentes existentes.

*Fuente: [GitHub](https://github.com/openclaw/openclaw), [OpenClaw AI](https://openclaw.ai/), [DigitalOcean](https://www.digitalocean.com/resources/articles/what-is-openclaw)*

## Buyer Beware — Alerta de hype

**Todos hablan de la IPO de Anthropic como si fuera una inversión obvia, pero ojo porque:**

La valoración de $965B descansa sobre una tasa de crecimiento que asume que el mercado enterprise de AI coding y agentes seguirá expandiéndose a la misma velocidad. La cobertura de inversión está obviando tres riesgos reales: (1) Microsoft y Google están subsidiando sus propios modelos de coding para capturar developers en sus ecosistemas — MAI-Code-1-Flash en Copilot gratuito es competencia directa; (2) El billing change del 15 de junio muestra que el modelo de "suscripción flat" no escala — el revenue de agentes requiere monetización por uso; (3) OpenAI también prepara su IPO en el mismo ventana. No hay espacio para dos IPOs de $1T simultáneos sin que la demanda institucional se divida. El producto es excelente; la valoración es otra cosa.
