## 🌊 The Wave Today — Noticias que mueven la aguja

### Claude Cowork llega a móvil y web — y el 90% no es código

El 7 de julio, Anthropic expandió Claude Cowork a web y móvil con sesiones que corren en la nube. El modelo de ejecución cambió fundamentalmente: puedes iniciar una tarea en el Mac, cerrar la laptop, ir a reunión, y Claude sigue trabajando. Cuando vuelves, el output está listo — en cualquier dispositivo.

Las funciones que importan: **background execution** (tareas programadas corren sin ningún dispositivo conectado), **continuidad cross-device** (Projects y Artifacts sincronizados en un único sidebar), y **mobile approvals** para aprobar acciones sensibles desde el teléfono.

El dato que reencuadra todo el ecosistema: **más del 90% del uso de Cowork no era desarrollo de software**. Las categorías dominantes son operaciones empresariales y creación de contenido. Anthropic lo sabe y lo está persiguiendo. La beta abre con usuarios Max; uso duplicado hasta el 5 de agosto para quien quiera experimentar con tareas largas.

### GPT-5.6: Sol, Terra, Luna + ChatGPT Work

El 9 de julio, OpenAI abrió GPT-5.6 al público en tres tiers: **Sol** (flagship, $5/$30 por millón de tokens), **Terra** (mid-range, $2.50/$15), y **Luna** (económico, $1/$6). Sam Altman dice que Sol es "54% más eficiente en tokens en coding agentico" — frase diseñada para apuntar directamente a Claude Fable 5 (95% SWE-Bench Verified, 80.3% SWE-Bench Pro, el mejor en benchmark abierto).

Más relevante que el modelo en sí: **ChatGPT Work**, un agente construido para "ejecutar trabajos completos, no solo responder preguntas." Paralelo directo a Cowork, pero con la distribución masiva de ChatGPT como ventaja. Terra es la apuesta de valor: rendimiento cercano a GPT-5.5 a mitad de precio. Si tus workflows tienen costos de tokens que importan, Terra merece evaluación.

### Grok Build open-sourced — y el contexto que no puedes ignorar

El 16 de julio, xAI publicó el código fuente completo de Grok Build (su coding agent CLI/TUI) en Apache 2.0. Arquitectura visible: context handling, tool execution, plugins, skills, MCP integration. El proyecto incluye support de Plan Mode, subagent nativo, mouse, pantalla completa TUI, y puede correr fully local-first.

**El contexto que importa:** esta decisión llegó *después* de que la comunidad descubriera que la versión anterior del CLI de xAI subía directorios completos a buckets de Google Cloud sin consentimiento claro. Musk prometió borrar todo el contenido subido. La apertura del código es, en parte, un movimiento de confianza forzado por la presión comunitaria.

El código vale analizarlo para entender arquitecturas alternativas de coding agents. Como herramienta de producción en 2026, el trust deficit todavía es real y merece peso en tu decisión.

## 🔧 Tool & Repo Watch — Herramientas y repos

### Claude Code v2.1.211 — Julio 15, 2026

Las actualizaciones de julio de Claude Code son quirúrgicas y prácticas:

- **`--forward-subagent-text`** (y env var `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT`): el texto y thinking de subagentes ahora aparece en el output `stream-json`. Si tienes pipelines externos que parsean la salida de Claude Code, esto desbloquea observabilidad sobre lo que pasa dentro de un subagente.
- **Auto mode sin flag** en Bedrock, Vertex AI y Foundry — ya no requiere `CLAUDE_CODE_ENABLE_AUTO_MODE`; desactiva con `disableAutoMode` en settings si prefieres control manual.
- **Timer en vivo** en el collapsed tool summary — las llamadas largas ya no parecen colgadas.
- **Fix crítico MCP**: `request_timeout_ms` por servidor ahora se respeta (antes el config era ignorado y usaba 60s por defecto en sesiones nuevas — causa silenciosa de timeouts en herramientas lentas).
- **Fix OAuth MCP**: ya no pide re-autenticación manual después de un token refresh fallido.

**Por qué te importa:** Usas Claude Code diariamente con MCP servers. El fix de `request_timeout_ms` y OAuth son los más impactantes — si tenías MCP servers con llamadas que duraban más de 60 segundos o OAuth que expiraba silenciosamente, este update los resuelve. El flag `--forward-subagent-text` abre debugging real de workflows multi-agente.

Suggested action: **Actualizar ahora** (`npm update -g @anthropic-ai/claude-code`)

### OpenClaw — Personal AI Gateway (346K⭐ en GitHub)

Framework open-source que corre un gateway de AI local en tus propios dispositivos y lo conecta con más de 50 integraciones: WhatsApp, Telegram, Slack, Discord, Signal, iMessage. Los modelos (Claude, GPT, Gemini, local) se conectan como backends intercambiables al gateway. Pasó de 0 a 210K stars en 10 días en enero 2026; hoy tiene 346K+. El creador (Peter Steinberger) se fue a OpenAI, pero el proyecto continúa como fundación open-source.

**Por qué te importa:** Si construyes agentes de automatización en n8n y quieres que esos agentes aparezcan en los canales que ya usa tu equipo o clientes (WhatsApp, Telegram), OpenClaw es la pieza del puzzle que falta. Arquitectura local-first: tus datos no salen a servidores externos. Es el equivalente a un MCP server para mensajería, pero con gateway completo.

Suggested action: **Explorar** — [github.com/openclaw/openclaw](https://github.com/openclaw/openclaw)

### n8n 2026 — Multi-Agent y MCP nativos

n8n consolidó durante 2026 una arquitectura de multi-agente built-in: el AI Agent node ahora soporta orquestación de múltiples agentes, RAG pipelines, y **conexión MCP nativa** sin plugins adicionales. Cualquier MCP server se puede exponer como herramienta dentro de un agente de n8n. El node incluye Guardrails, Human Review, y Max Iterations.

**Por qué te importa:** El combo que los practitioners recomiendan hoy es n8n (glue determinístico con 400+ integraciones) + Claude SDK directo o LangGraph (lógica agentica compleja). La conexión MCP nativa significa que los servers que ya tienes configurados en Claude Code pueden alimentar directamente tus workflows de n8n — sin duplicar configuración. Si ya usas el AI Agent node, revisa el changelog en docs.n8n.io antes de actualizar — hay cambios de comportamiento en las responses del chat tool.

Suggested action: **Revisar changelog** si usas AI Agent node en producción — [docs.n8n.io/release-notes](https://docs.n8n.io/release-notes)

## 🚨 Buyer Beware — Alerta de hype

**"El CLI que subió tu código a Google Cloud" — lección universal**

La controversia del grok CLI de xAI merece atención más allá de la marca: la herramienta subía directorios completos a GCloud buckets de manera que la mayoría de usuarios no detectó hasta que alguien analizó el tráfico de red. xAI lo consideraba un feature (contexto remoto); la comunidad lo consideró exfiltración de datos. Musk prometió borrar todo.

**El patrón que importa:** Todos los coding agents modernos — Claude Code, Cursor, Grok Build, Copilot — tienen acceso profundo al filesystem y hacen network calls. La diferencia está en:
1. **Transparencia del código** (open-source = auditable; closed = confiar en la empresa)
2. **Telemetría opt-out** (Claude Code lo tiene; verifica en tus herramientas actuales)
3. **Modo offline/air-gap** para código propietario o datos sensibles

No es hype de xAI — es un recordatorio de que todos los CLI de AI merecen el mismo escrutinio. La confianza se gana con código auditable y opciones de privacy explícitas, no con promesas posteriores al escándalo.
