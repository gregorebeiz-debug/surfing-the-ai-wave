### 3. MCP spec 2026-07-28 — Release Candidate con breaking changes

El **Model Context Protocol** lanzó su Release Candidate para la spec del 28 de julio. Hay cambios que rompen compatibilidad que necesitas conocer si tienes servidores MCP en producción:

- **Sessions eliminadas:** `Mcp-Session-Id` desaparece del transporte Streamable HTTP. Los endpoints de lista (`tools/list`, `resources/list`) ya no varían por conexión.
- **Nuevos headers obligatorios:** `Mcp-Method` y `Mcp-Name` en HTTP para que load balancers y gateways puedan enrutar sin inspeccionar el body.
- **Response caching:** Los resultados de `list` y `resource read` ahora incluyen `ttlMs` y `cacheScope` — reduce las llamadas repetidas.
- **MCP Apps:** Los servidores ahora pueden incluir interfaces HTML interactivas en iframes seguros — los hosts renderizan la UI y las acciones pasan por el mismo flujo de auditoría que un tool call.
- **Tasks extension:** Promovida a oficial. Reemplaza el modelo bloqueante por polling via `tasks/get`.
- **Enterprise-Managed Auth:** Ahora estable. Adoptada por Anthropic, Microsoft, Okta.

*Fuentes: [MCP Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/), [Stacktree](https://stacktr.ee/blog/mcp-2026-spec-changes)*

### Claude Code — Memory leaks resueltos, mejoras de estabilidad

Esta semana, Claude Code recibió un conjunto de fixes críticos de memoria y estabilidad:

- **Memory leaks reparados:** MCP stdio server stderr acumulaba hasta 64MB por servidor; documentos LSP permanecían abiertos indefinidamente (ahora LRU con cap de 50 docs); crecimiento sin límite de payloads en sesiones headless/SDK.
- **Worktree isolation fix:** Los subagentes en worktrees podían ejecutar comandos git-mutating contra el checkout principal del repo — ya corregido.
- **Screen reader mode:** `claude --ax-screen-reader` o `CLAUDE_AX_SCREEN_READER=1`.
- **Vim:** nuevo setting `vimInsertModeRemaps` para mapear secuencias como `jj` → Escape.
- **Live elapsed-time counter** en la UI.

**Por qué te importa:** Si corres Claude Code con múltiples MCP servers activos (como tu setup), los leaks de 64MB por servidor en sesiones largas podían acumularse. Esta actualización directamente mejora la estabilidad de tus sesiones de trabajo.

## ⚠️ Buyer Beware — Alerta de hype

**Todos hablan de "AI Work Agents" (ChatGPT Work, Claude Cowork, Gemini Enterprise, Make AI Agents)**, pero ojo porque: estas herramientas requieren acceso profundo a tus datos corporativos y apps conectadas. Ninguna de ellas ha sido auditada públicamente para privacidad de datos en flujos agenticos autónomos multi-hora. El hype está superando la madurez operacional — son prometedoras como POC, pero antes de conectarlas a datos sensibles, revisa los términos de retención de datos y las políticas de auditoría de cada plataforma.
