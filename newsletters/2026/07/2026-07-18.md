### La Gran Semana de Modelos: GPT-5.6 (Sol/Terra/Luna), Grok 4.5, Muse Spark 1.1 — y el precio de la inteligencia frontier se desplomó

Entre el 8 y el 9 de julio ocurrió la mayor concentración de lanzamientos frontier del año. OpenAI lanzó **GPT-5.6** en tres variantes: Sol ($5/$30 por M tokens, flagship con multi-agent nativo y soporte de subagentes concurrentes), Terra ($2.50/$15, balance costo/potencia), y Luna ($1/$6, rápido y económico). Junto al modelo llegó **ChatGPT Work**, un agente que toma "un objetivo y lo convierte en trabajo terminado" combinando Codex con ChatGPT — orientado a usuarios no técnicos, pero con capacidades reales de larga duración. En el mismo periodo, xAI lanzó **Grok 4.5** (500K contexto, diseñado con Cursor para coding y agentic tool calling) y Meta presentó **Muse Spark 1.1** (multimodal, $1.25/$4.25, enfocado en multi-agent workflows). El patrón de fondo: el costo de inteligencia frontier cayó un 60-70% en una semana. Recordatorio: **Claude Sonnet 5** es el modelo default para todos los usuarios Free y Pro desde el 1 de julio, con pricing introductorio de $2/$10 hasta agosto 31, antes de regresar a $3/$15.

### MCP publica su Release Candidate: protocolo sin estado y Enterprise Auth estable (fecha final: julio 28)

El equipo de Model Context Protocol publicó el RC de la próxima especificación mayor. El cambio más importante: **eliminación del `Mcp-Session-Id` header** — el protocolo pasa a ser completamente sin estado. Consecuencia directa: cualquier request MCP puede aterrizar en cualquier instancia del servidor. Ya no se necesitan sticky sessions, shared session stores ni deep packet inspection. Un servidor MCP que antes requería infraestructura compleja ahora puede correr detrás de un load balancer round-robin estándar. También se formalizó **Enterprise-Managed Authorization** (ahora estable), ya adoptada por Anthropic, Microsoft y Okta — una capa centralizada de control de acceso a servidores MCP vía identity provider corporativo. Adicionalmente, X (Twitter) lanzó su propio hosted MCP server para que Claude, Cursor y Grok Build accedan directamente a la plataforma.

*Fuentes: [MCP Blog RC](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/), [InfoQ Enterprise Auth](https://www.infoq.com/news/2026/07/mcp-ema-enterprise-auth/), [TechCrunch X MCP](https://techcrunch.com/2026/06/30/x-now-offers-an-mcp-server-to-make-its-platform-easier-for-ai-tools-to-use/)*

### Claude Cowork llega a móvil y web + Claude Code con 50% más límites hasta mañana (julio 19)

Desde el 7 de julio, Claude Cowork está disponible en web y móvil para suscriptores Max — antes era exclusivo de desktop. Puedes iniciar un task desde el escritorio, recibir updates en el teléfono, y recoger el output terminado después. Anthropic extendió también la promoción de Claude Code (50% más límites semanales) hasta el 19 de julio para usuarios Pro, Max, Team y Enterprise. Si no has aprovechado la cuota extra, **mañana es el último día**.

### disler/claude-code-hooks-mastery — "5 Production Hooks From Scratch"

Repositorio con tutorial paso a paso que construye 5 hooks de producción para Claude Code: desde bloquear comandos peligrosos (exit code 2 = bloqueo) hasta validar outputs antes de que lleguen al usuario. Cubre los 17 lifecycle events del sistema de hooks, la diferencia entre prompt hooks (una llamada LLM directa) y agent hooks (subagente con acceso completo a tools), y la configuración en `.claude/settings.json` con matcher regex.

**Por qué explorar:** Los hooks son la diferencia entre Claude Code como asistente y Claude Code como sistema de producción confiable. Si ya usas Claude Code diariamente, dominar hooks es el siguiente salto de madurez: agrega gates deterministas en los puntos críticos de tu pipeline sin depender de que el LLM recuerde las reglas.

## 🛠️ Tool & Repo Watch — Herramientas y repos

**Orca (stablyai/orca)** — ADE (Agent Development Environment) para fleet de coding agents en paralelo. Corre Claude Code, Codex, OpenCode o Pi side-by-side, cada uno en su propio worktree, con vista unificada en desktop y móvil.
**Por qué te importa:** Si experimentas con múltiples agentes o quieres comparar Claude Code vs Codex en el mismo task en tiempo real, Orca es la capa de orquestación que falta en tu stack actual. Directamente relevante a tu workflow de automatización.
→ [GitHub](https://github.com/stablyai/orca) | Acción: **Instalar y explorar**

---

**herdr** — Terminal multiplexer consciente de agentes: workspaces persistentes, tabs, panes y detección de estado para CLI coding agents. Piénsalo como tmux pero diseñado específicamente para sesiones largas de Claude Code.
**Por qué te importa:** Si corres Claude Code en tasks que duran horas (pipelines, automatizaciones de negocio), herdr evita que pierdas el estado de sesión cuando se desconecta la terminal. Compatible directamente con Claude Code CLI.
→ Acción: **Monitor**

---

**CubeSandbox (Tencent)** — Sandbox de ejecución aislada para agentes con VM-level isolation (RustVMM + KVM), compatible con E2B API, fast startup, network controls y audit support.
**Por qué te importa:** Cuando tus agentes de Claude Code o n8n ejecuten código generado con inputs externos, necesitas aislamiento real — no solo Docker. CubeSandbox es la alternativa open-source a E2B con hardware-level isolation. Evalúa si tu stack de automation agents lo requiere.
→ Acción: **Explorar si tienes agentes ejecutando código de terceros**

---

Desde 2026, Ollama también actúa como cloud proxy — misma API, mismos comandos, mismo puerto.
**Por qué te importa:** Si usas Ollama para modelos locales en n8n o como fallback offline a Claude API, la nueva capa de agent experience y el tool calling mejorado son pasos concretos hacia agentes locales más capaces. Laguna XS 2.1 vale la pena probar para coding tasks pesados.
→ [GitHub](https://github.com/ollama/ollama) | Acción: **Actualizar**

## ⚠️ Buyer Beware — Alerta de hype

**Todos hablan de los benchmarks de GPT-5.6 Sol, pero ojo porque...** el claim de que Sol supera a Claude Fable 5 por 13.1 puntos en "Agents' Last Exam" llega en una semana donde OpenAI controló la narrativa de benchmarks. "Agents' Last Exam" es un benchmark diseñado por OpenAI — evalúa capacidades que Sol fue optimizado para demostrar. El "Christmas in July" con cuatro modelos frontier en 48 horas es exactamente el tipo de momentum que convierte benchmarks de PR en evidencia técnica ante los ojos de la prensa. Espera 2-3 semanas para evaluaciones independientes (Chatbot Arena, LMSYS, pruebas propias de la comunidad) antes de migrar pipelines críticos basándote en estos números.
