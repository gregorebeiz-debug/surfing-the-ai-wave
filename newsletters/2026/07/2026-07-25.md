### Claude Opus 5: Inteligencia near-frontier a $5 por millón de tokens

Anthropic lanzó ayer Claude Opus 5, su nuevo modelo flagship diseñado para trabajo cognitivo intensivo. El precio de entrada es $5/MTok input y $25/MTok output — la mitad que Fable 5 — con una ventana de contexto de 1M tokens. Opus 5 es ahora el modelo default en Claude Max.

Los benchmarks son contundentes: **43.3% en Frontier-Bench** (duplica el score de Opus 4.8 y supera a GPT-5.6 Sol), **30.2% en ARC-AGI-3** (aproximadamente 3× el modelo más cercano), y **Elo 1,861** en GDPval-AA v2 para conocimiento laboral. La novedad operativa clave: un toggle de esfuerzo low/medium/high por request, lo que permite calibrar costo/capacidad sin cambiar de modelo.

### Claude Code 2.1.219: Opus 5 como default, nuevos hooks y controles de seguridad

Lanzado también el 24 de julio, este release de Claude Code (27 cambios) hace a Opus 5 el modelo Opus por defecto en Claude Code con fast mode activable a $10/$50/MTok. Lo relevante para builders:

- **DirectoryAdded hook** — se dispara cuando `/add-dir` o `register_repo_root` del SDK registra un nuevo directorio mid-sesión. Util para monorepos con workspaces dinámicos.
- **sandbox.network.strictAllowlist** — bloquea hosts no-allowlisted en comandos sandboxed sin prompts adicionales, reforzando el aislamiento de agentes.
- **Nested subagent forwarding** — subagentes en profundidad 2+ ahora aparecen en `stream-json` cuando `--forward-subagent-text` está activo. Mejora la observabilidad en workflows multi-agente complejos.
- **Bugfixes críticos** — plugins cargados via `--settings` que no se activaban, feature flags que expiraban en sesiones largas, y `/ultrareview` rechazando repos sin merge base.

*Fuentes: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [Releasebot](https://releasebot.io/updates/anthropic/claude-code)*

### GPT-5.6 Sol/Terra/Luna en GA: nuevo tier presupuesto y prompt caching al 90% de descuento

OpenAI lanzó GPT-5.6 en tres variantes para todos los usuarios de ChatGPT y API el 9 de julio. Lo más relevante no es el modelo en sí — sino dos cambios estructurales:

1. **GPT-5.6 Luna** a $1/$6 por millón de tokens — un nuevo tier presupuesto sin precedente en la familia GPT. Si tienes pipelines que hoy usan modelos más baratos de OpenAI, Luna es el upgrade más costo-efectivo disponible.
2. **Nuevo sistema de prompt caching** — cache breakpoints explícitos, vida mínima de 30 minutos, lecturas de cache al **90% de descuento** (vs. 50% anterior). Para workflows con system prompts largos o contexto repetido, esto es un cambio material en costos.

El contexto: GPT-5.6 y Grok 4.5 se lanzaron el mismo día, la primera vez en la historia del sector que dos modelos frontier compiten en lanzamiento simultáneo.

## Tool & Repo Watch — Herramientas y repos

### OmniRoute — Gateway AI universal, MIT, con 271 proveedores y compresión de tokens de hasta 95%

**Qué es:** Gateway AI open-source que unifica 271 proveedores (90+ con tier gratuito, 40+ gratuitos permanentemente) y 500+ modelos bajo un único endpoint compatible con OpenAI. Compatible out-of-the-box con Claude Code, Cursor, Cline, GitHub Copilot y Codex.

**Por qué te importa:** Si te estás chocando con rate limits en Claude Code —o querés acceder a modelos como Kimi K3, GLM-5 o DeepSeek sin gestionar 5 API keys distintas— OmniRoute resuelve eso con failover automático en milisegundos. El diferenciador técnico real es **RTK+Caveman compression**: reduce el consumo de tokens entre 15% y 95% dependiendo del prompt, con 11 opciones de pipeline componibles. Ya llegó a **23.6K estrellas** en GitHub (v3.8.49).

**Stars/forks:** ~23.6K estrellas | [GitHub](https://github.com/diegosouzapw/OmniRoute)

**Acción sugerida:** **Instalar** — especialmente si usas Claude Code intensivamente o gestionás múltiples proveedores en tus automatizaciones.

### Bumblebee (Perplexity AI) — Escáner de supply-chain para endpoints de desarrollador, incluyendo configs MCP

**Qué es:** Herramienta open-source (Apache 2.0) en Go, un solo binario, sin dependencias externas. Escanea de forma read-only packages, extensiones del editor, extensiones del browser y — crítico — **archivos de configuración MCP**, buscando compromisos conocidos de supply-chain.

**Por qué te importa:** Usás MCP extensivamente. Cada nuevo servidor MCP que instalás es un vector potencial de ataque — algo que casi ninguna herramienta de seguridad cubre hoy. Bumblebee lee solo metadatos (lockfiles y manifests), nunca ejecuta install scripts ni lifecycle hooks, lo que significa que no activa malware al escanear. Perplexity lo desarrolló como respuesta a una campaña masiva de supply-chain threats en mayo 2026. Si tenés `.mcp.json` o configs locales de MCP, esto vale la pena correr ya.

**Stars/forks:** En crecimiento | [GitHub](https://github.com/perplexityai/bumblebee) | [Docs](https://www.marktechpost.com/2026/05/23/perplexity-open-sources-bumblebee-a-read-only-supply-chain-scanner-for-developer-endpoints/)

**Acción sugerida:** **Instalar** — corre una sola vez sobre tu entorno de desarrollo para auditar exposición.
