### 2. Claude Fable 5 vuelve + Sonnet 5 es el nuevo default (desde julio 1)

Dos noticias del ecosistema Claude que llevan una semana activas pero vale consolidar: desde el 1 de julio, **Fable 5** está disponible globalmente de nuevo tras 19 días de suspensión por export controls. La causa: investigadores de Amazon encontraron un método para bypasear sus safeguards via prompting. La solución: un nuevo clasificador de cyberseguridad que bloquea la técnica específica en >99% de casos; las requests bloqueadas se redirigen a Opus 4.8 sin rechazarse. Ahora opera bajo usage credits para Pro/Max/Team.

Simultáneamente, **Claude Sonnet 5** se convirtió en el modelo default para todos los usuarios Claude (Free y Pro). Es el Sonnet más agentico construido hasta la fecha, con contexto nativo de 1M tokens, y el más cercano a Opus 4.8 en tareas de coding y tool use. Pricing promocional $2/$10 por Mtok hasta el 31 de agosto.

### 3. Claude Cowork llega a web y móvil — sesiones que corren sin tu laptop

Anthropic expandió Cowork a web y móvil con una feature crítica: **sesiones remotas en beta**. Lo que cambia: las sesiones y archivos se sincronizan a tu cuenta Claude, los tasks programados corren en background sin necesidad de tener el dispositivo abierto, y se agregaron write tools de Microsoft 365 (draft y envío de emails, gestión de calendario, creación/update de archivos en OneDrive y SharePoint). ## 🔬 Deep Dives — Vale la pena explorar directamente

### Spec RC — "MCP 2026-07-28: El Protocolo Vuelve a Ser Stateless"

El Release Candidate del próximo spec MCP está disponible ahora; la versión final llega el **28 de julio**. El cambio central es arquitectónico: **MCP ahora es stateless a nivel de protocolo**. Se elimina el handshake de inicialización y el session ID — cualquier request puede llegar a cualquier instancia del servidor, lo que desbloquea escalado sobre HTTP estándar sin sesiones pegadas a una instancia. Cambios específicos: nuevos headers `Mcp-Method` y `Mcp-Name` para que load balancers y rate-limiters puedan enrutar sin inspeccionar el body; `ttlMs` y `cacheScope` en `tools/list` para caching tipo HTTP Cache-Control; nuevo extension framework para **Tasks** (trabajo de larga duración) y **MCP Apps** (UIs renderizadas por el servidor).

**Por qué importa:** Cada MCP server que usas — GitHub, Gmail, Playwright, los que construyes — necesitará actualizar su implementación para el 28 de julio. Los SDK Tier 1 tienen una ventana de 10 semanas. Si tienes MCP servers propios, el RC merece revisión ahora antes de que haya rush de última hora.

[Leer spec RC](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/) | [Análisis de cambios y breaks](https://stacktr.ee/blog/mcp-2026-spec-changes)

## 🛠 Tool & Repo Watch — Herramientas y repos

**Claude Code 2.1.191** — `/rewind` después de `/clear`, −37% CPU, fix MCP OAuth

El update de Claude Code con mayor impacto práctico en semanas. `/rewind` ahora funciona después de `/clear`: te da un picker navegable de toda la historia de conversación incluyendo turns borrados, con opción "Summarize up to here" para comprimir contexto. El 37% de reducción en CPU viene de coalescer text updates en batches de 100ms en vez de render por token. El fix de MCP OAuth resuelve `invalid_scope` failures en GitLab self-hosted y enterprise IdPs.

**Por qué te importa:** Usas Claude Code diariamente — `/rewind` elimina el dolor de hacer `/clear` accidentalmente y perder contexto. El 37% CPU cut es real si corres sesiones largas o tienes specs modestas. El fix MCP OAuth puede desbloquear servers que tenías atascados.

**OpenClaw 250k⭐ → bajo custodia de OpenAI Foundation**

El framework de agentes personales AI más viral de la historia de GitHub (250k estrellas en ~60 días, más rápido que React en su primera década) cambió de estructura. Peter Steinberger ("el ClawFather", ex-fundador de PSPDFKit) se unió a OpenAI y transfirió el proyecto a una fundación no-profit con OpenAI como sponsor principal. Sigue MIT license. OpenClaw ejecuta workflows autónomos, responde mensajes, hace browsing, y corre automatizaciones — activado por algo tan simple como un SMS.

**Por qué te importa:** El riesgo de abandono que tenía como proyecto de un solo fundador desaparece. Con OpenAI detrás, OpenClaw va a integrar con la API de OpenAI out-of-the-box — pero los principios de arquitectura (agente autónomo, triggered por mensajes, tool-use nativo) son aplicables independientemente del LLM. Si builds automation agents, es el repo de referencia este año.

**LangGraph Q2 2026** — Per-node timeouts, DeltaChannel, v2 typed streaming

LangGraph entregó su quarter más activo con tres features de producción: per-node timeouts (un nodo atascado ya no cuelga todo el graph), DeltaChannel para state diffing eficiente, y una v2 typed streaming API.

**Por qué te importa:** Los per-node timeouts resuelven el pain point más común en graphs complejos en producción. El typing en la streaming API también reduce bugs silenciosos.
