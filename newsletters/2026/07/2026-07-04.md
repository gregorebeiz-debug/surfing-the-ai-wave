### X lanza MCP Server oficial — integración directa sin construir nada propio

X lanzó un servidor MCP hospedado en `api.x.com/mcp` que permite a Claude Code, Cursor, Grok Build y otras apps compatibles conectarse directamente a la plataforma usando los permisos propios del usuario. Herramientas disponibles: crear y publicar posts, gestionar bookmarks y carpetas, crear borradores de artículos y publicarlos.

**Nota crítica:** No es compatible con los endpoints de Write API de X, por lo que no se puede usar para postear de forma completamente autónoma sin confirmación del usuario.

**Por qué te importa:** Si tienes workflows en n8n o Claude Code que monitorean tendencias o publican contenido en X, ya tienes integración oficial MCP sin construir ni hostear un servidor propio. La autenticación usa los permisos de tu cuenta — sin acceso especial a la API de X. X se une a GitHub, Slack, Notion, Stripe y Salesforce en el creciente ecosistema de MCP servers oficiales.

**Acción sugerida:** Explorar. Conecta Claude Code al MCP de X para monitoreo de señales de mercado o flujos de publicación semi-automatizados.

### Bumblebee (Perplexity) — El primer scanner de seguridad que trata tu config de MCP como superficie de ataque

Perplexity AI open-sourceó Bumblebee (mayo 2026): herramienta que escanea tu máquina buscando paquetes comprometidos, extensiones de editores, y configuraciones de MCP contra releases conocidos como maliciosos. Binario único en Go, zero dependencias externas, solo lectura — no ejecuta nada en tu sistema.

Cubre: npm, pnpm, Yarn, Bun, PyPI, Go modules, RubyGems, Composer, configs de MCP, extensiones de editor, y extensiones de browser.

**Contexto de seguridad:** El incidente ContextCrush (marzo 2026) demostró que un MCP server comprometido puede inyectar instrucciones del atacante directamente en la memoria de trabajo de tu agente — exfiltrando credenciales o invocando herramientas en background sin visibilidad. Bumblebee es el primer tool open-source que trata los archivos de config de MCP como superficie de seguridad formal.

**Por qué te importa:** Usas Claude Code con múltiples MCP servers y probablemente instalas paquetes de npm y PyPI regularmente. Bumblebee es el equivalente a un antivirus específico para tu stack de desarrollo con IA — especialmente relevante dado que los env blocks de tu MCP config pueden contener credenciales.

**Acción sugerida:** Instalar. Es un binario único, no requiere setup complejo.

→ [Perplexity Blog](https://www.perplexity.ai/hub/blog/perplexity-is-open-sourcing-bumblebee) | [GitHub](https://github.com/perplexityai/bumblebee) [Seguridad / MCP]
