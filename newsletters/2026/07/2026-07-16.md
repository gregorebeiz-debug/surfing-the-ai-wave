### Claude Sonnet 5 se convierte en el default para todos los usuarios de Claude

Desde el 1 de julio, Sonnet 5 reemplazó a Sonnet 4.6 como modelo por defecto para todos los usuarios Free y Pro. Los benchmarks cuentan una historia interesante: en terminal work supera a Opus 4.8 (80.4% vs 74.6%), y en Humanity's Last Exam with tools casi empata con Opus (57.4% vs 57.9%). En agentic coding marca 63.2%, entre Sonnet 4.6 (58.1%) y Opus 4.8 (69.2%). El pricing introductorio es $2/$10 por millón de tokens hasta el 31 de agosto, luego sube a $3/$15. Para contexto: es el modelo más eficiente que puedes usar con Claude Code ahora mismo, y ejecuta la misma calidad que antes costaba Opus.

*Fuentes: [Anthropic](https://www.anthropic.com/news/claude-sonnet-5), [Vellum Benchmarks](https://www.vellum.ai/blog/claude-sonnet-5-benchmarks-explained)*

### MCP 2026-07-28: El protocolo se vuelve stateless — Release Candidate ya disponible

El Release Candidate de la especificación MCP 2026-07-28 está disponible **ahora mismo**, con la versión final llegando el 28 de julio. Es el mayor cambio al protocolo desde su lanzamiento. El titular: MCP es ahora stateless en el core. Un servidor MCP que antes requería sticky sessions, session store compartido y deep packet inspection en el gateway, ahora puede correr detrás de un load balancer round-robin estándar. Además: MCP Apps (interfaces HTML server-rendered en iframe), Tasks extension (llamadas asíncronas de larga duración), y auth alineada con OAuth/OIDC. Los Beta SDKs para Python, TypeScript, Go y C# ya están disponibles.

Para Gregorio: si tienes servidores MCP propios corriendo ahora — o planeas construirlos — este cambio es crítico. Los breaking changes son reales: la capa de sesión desaparece, los headers `Mcp-Method` y `Mcp-Name` son ahora obligatorios, y el caching de tools/list respuestas cambia. Tienes **12 días** para validar antes del final.

*Fuentes: [MCP Blog RC](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/), [SDK Betas](https://blog.modelcontextprotocol.io/posts/sdk-betas-2026-07-28/), [WorkOS Auth Changes](https://workos.com/blog/mcp-2026-spec-agent-authentication)*

### OpenAI lanza GPT-5.6 — 3 modelos, nuevo modo "ultra"

GPT-5.6 es una familia de tres modelos: Sol (flagship, $5/$30 por millón), Terra (mid-tier, $2.50/$15) y Luna (rápido/barato, $1/$6). Sol incluye un modo "ultra" que permite delegar trabajo a sub-modelos, con 54% más eficiencia de tokens en tareas de agentic coding. También lanzaron ChatGPT Work, un producto para equipos que integra contexto de herramientas de trabajo y convierte notas y borradores en trabajo terminado. Relevante principalmente como referencia comparativa: Sol compite directamente con Opus 4.8 y Fable 5.

*Fuentes: [Axios GPT-5.6](https://www.axios.com/2026/07/09/ai-openai-gpt-release)*

## 🛠 Tool & Repo Watch — Herramientas y repos

### Claude Code v2.1.211 — Artifacts + /doctor + Auto mode safety

El último release de Claude Code (v2.1.211 al 15 de julio) viene con tres adiciones de peso:

- **Artifacts:** Convierte output de sesiones en páginas web vivas y compartibles en claude.ai (beta para Team/Enterprise). Útil para PR walkthroughs, dashboards, checklists de incidentes.
- **`/doctor` command:** Nuevo comando que audita salud de instalación, detecta skills y MCP servers no usados, y propone recortar CLAUDE.md. Pide confirmación antes de cambiar nada.
- **Auto mode safety:** Auto mode ahora bloquea alteraciones de archivos de transcripción de sesión y pide confirmación antes de `rm -rf` sobre variables no resolubles desde el contexto.

**Por qué te importa:** El `/doctor` es directamente relevante para tu setup: si tienes MCP servers registrados que no usas o skills acumulados, los está consumiendo en contexto sin valor. Córrelo ahora. Los Artifacts en modo beta de Team son una forma nueva de entregar reportes o dashboards generados por agentes sin necesidad de infra extra.

Acción sugerida: **Actualizar + correr `/doctor`**

→ [Claude Code What's New](https://code.claude.com/docs/en/whats-new) | [Changelog](https://claudefa.st/blog/guide/changelog)

### Microsoft Agent Framework 1.0 — Semantic Kernel + AutoGen fusionados

Microsoft fusionó Semantic Kernel y AutoGen en **Microsoft Agent Framework 1.0** (lanzado el 3 de abril). Un solo framework que consolida lo que antes eran dos proyectos separados con filosofías distintas.

**Por qué te importa:** Si tienes código usando AutoGen o Semantic Kernel, esto implica migration path. Si estás evaluando frameworks de agentes para proyectos nuevos, MAF 1.0 es ahora el candidato de Microsoft frente a LangGraph y CrewAI. Dado tu stack (Claude Code + CrewAI/LangGraph), el impacto directo es bajo a menos que trabajas con clientes en Azure.

Acción sugerida: **Monitor** (a menos que tengas proyectos .NET o Azure)

OpenCut es el repo #1 en GitHub trending hoy: editor de video open-source, alternativa directa a CapCut. Stack web, sin instalación. Reescritura desde cero en proceso.
