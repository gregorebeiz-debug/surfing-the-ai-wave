## 🌊 The Wave Today — Noticias que mueven la aguja

### Claude Fable 5 sale de las suscripciones — hoy es el último día

A partir de mañana (8 de julio), **Fable 5 deja de estar incluido** en los planes Pro, Max, Team y Enterprise estándar. Se mueve a usage credits a tarifa API: **$10/M tokens input, $50/M output** — habilitables desde Settings → Usage en claude.ai. Anthropic aclara que la medida es temporal y atribuye el cambio a demanda "muy alta y difícil de predecir". Un ingeniero de Claude Code confirmó públicamente que esperan reintegrar Fable 5 a las suscripciones una vez que tengan capacidad suficiente.

La lectura honesta: esto no es una decisión de negocio manejable — es un problema de infraestructura. Fable 5 tiene un costo computacional significativamente mayor que Sonnet 5, y la demanda post-lanzamiento los tomó desprevenidos. Lo positivo es que el camino de migración natural existe: Sonnet 5 (ver siguiente item) cubre la mayoría de casos de uso de Fable 5 a una fracción del costo y ya corre como default en Claude Code.

### Claude Sonnet 5 — Default en Claude Code, números que convencen

Lanzado el 30 de junio, **Sonnet 5 es ahora el modelo default** para todos los usuarios de Claude Code — Free, Pro y Max. Los benchmarks son concretos: **72.7% en SWE-bench Verified** (vs 62.3% de Sonnet 4.6, un salto de +10 puntos), **76.1% en Terminal-Bench 2.1** (+20.7 puntos sobre el anterior), y 63.2% en SWE-bench Pro. Precio promocional de $2/$10 por Mtok hasta el 31 de agosto. Contexto nativo de 1M tokens.

Lo interesante es el posicionamiento agéntico: Sonnet 5 puede planificar, usar herramientas y ejecutar tareas de forma autónoma en un nivel que antes requería Opus. Con effort levels ajustables, a nivel Extra High se acerca al rendimiento de Opus 4.8 en benchmarks de OSWorld y BrowseComp. En términos prácticos: si usas Claude Code para agentes de coding, ya tienes una actualización de productividad directa sin costo adicional dentro de la suscripción.

### GPT-5.6 Sol / Terra / Luna — Preview restringido de OpenAI

OpenAI presentó su próxima familia de modelos en tres tiers: **Sol** (flagship, $5/$30 por Mtok), **Terra** (mid-tier equilibrado, $2.50/$15), y **Luna** (velocidad y costo bajo, $1/$6). Por ahora el acceso está limitado a ~20 organizaciones revisadas por el gobierno de EE.UU. — lanzamiento general esperado para mediados de julio. Sol corre en Cerebras a hasta 750 tokens/segundo.

Contexto estratégico que importa: **Anthropic ya superó a OpenAI en revenue anualizado** según datos self-reportados ($47B ARR de Anthropic vs menos de OpenAI), y en paralelo OpenAI propone ceder un 5% de equity al gobierno de EE.UU. a cambio de coordinación en el rollout. El péndulo competitivo se movió más de lo esperado en 12 meses.

### Claude Agent SDK — Subagentes jerárquicos y marketplace de plugins

El Agent SDK de Anthropic ya soporta **subagentes jerárquicos hasta 3 niveles de profundidad** con ejecución paralela. La integración MCP es la más profunda de cualquier framework: Playwright, Slack, GitHub, y 200+ servidores MCP se conectan con una línea de configuración. El **marketplace de plugins** permite distribuir extensiones completas de Claude Code — skills, subagents, slash commands, hooks, MCP server definitions — como unidades instalables y versionadas.

**Por qué te importa:** Directamente para tu workflow diario. Ya puedes delegar subagentes en paralelo desde Claude Code — por ejemplo, un reviewer de código que lanza simultáneamente un security-scanner, un style-checker y un test-coverage agent, y consolida los resultados. El marketplace cambia cómo compartes y reutilizas tu trabajo entre proyectos; es el equivalente a un npm ecosystem para extensiones de Claude Code.

### MCP Spec 2026-07-28 — Release Candidate: stateless, MCP Apps y Tasks

La especificación final del Model Context Protocol llega el 28 de julio. Cambios principales que importan: **core stateless** (escala en HTTP ordinario, sin WebSockets persistentes), **MCP Apps** (los servidores pueden enviar interfaces HTML que el host renderiza en un iframe sandboxed con auditoría completa), y **Tasks extension** para operaciones long-running asíncronas — el server responde con un task handle, el cliente sondea con tasks/get, tasks/update, tasks/cancel. Auth se alinea con OAuth + OpenID Connect. Adopción actual: 78% de equipos AI enterprise ya tienen agentes con MCP en producción, 97M descargas mensuales del SDK.

**Por qué te importa:** Tus MCP servers actuales (Gmail, GitHub, Google Drive) no rompen — la spec mantiene backward compatibility. Pero MCP Apps es el cambio más disruptivo: tus servidores podrán tener interfaces propias que Claude Code renderiza. Para tus agentes de automatización, la Tasks extension elimina los timeouts en operaciones largas.

[Blog MCP](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/) | [Spec changes](https://stacktr.ee/blog/mcp-2026-spec-changes) — **Acción: Monitor hasta el 28 de julio**

### OpenClaw — 210k estrellas, asistente AI local con iOS/Android nativo

[OpenClaw](https://github.com/openclaw/openclaw) es un asistente AI personal que corre en tus propios dispositivos como gateway local, conectándose a WhatsApp, Telegram, Slack, Discord, Signal, iMessage y 20+ canales más. Pasó de 9k a 210k+ estrellas en meses — una de las trayectorias más rápidas en GitHub este año. El 30 de junio lanzaron apps nativas iOS y Android con pareo por QR al gateway local.

**Por qué te importa:** Si buscas un hub de agentes que opere local-first con acceso a tus canales de comunicación sin que tus datos pasen por vendor cloud, OpenClaw es la opción más madura en este momento. Conecta con cualquier modelo — Claude, GPT, modelos locales via Ollama. Dicho esto, cuidado con el scope de permisos: puede leer archivos, ejecutar comandos y actuar por schedule. Northeastern University lo calificó como potencial "privacy nightmare" si se configura sin restricciones. Instalar con intención, no por hype.
