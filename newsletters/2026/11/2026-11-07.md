### 2. Claude Code v2.1.319 + Cloud Setup Automático (6 de noviembre)

Dos mejoras que aterrizan esta semana en Claude Code:

**Cloud Setup automático:** A partir del 6 de noviembre, Claude Code en cloud (planes Pro, Max, Ultra) ahora detecta las dependencias del repositorio, configura el acceso a la red y registra las API keys automáticamente para sesiones futuras. Las keys se almacenan sin que Claude las vea directamente. Para tu flujo de desarrollo en la nube, esto elimina pasos de configuración manual en cada sesión nueva.

**v2.1.319:** Cambia el comportamiento de auto-mode cuando telemetría o feature flags están desactivados. Menor en apariencia, pero relevante si corres entornos de Claude Code con configuraciones restringidas.

*Fuentes: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [Daily Diff Issue #210](https://github.com/dboeter/daily-diff/issues/210)*

## 🔧 Tool & Repo Watch — Herramientas y repos

### OmniRoute — Gateway de AI gratuito, 1,400+ modelos, nativo con Claude Code
**[github.com/cheaper-inference/OmniRoute](https://github.com/cheaper-inference/OmniRoute)** | ⭐ 85,284 | Forks: 12,878

Qué hace: un gateway MIT (auto-hospedado) que expone un único endpoint compatible con la API de Anthropic, pero enruta hacia 375 proveedores (150+ con tier gratuito) incluyendo Claude, GPT, Gemini, DeepSeek, Kimi, MiniMax, GLM. Soporta compresión RTK+Caveman (15–95% reducción de tokens según el caso). Integración explícita con Claude Code via `omniroute setup-claude-code`.

**Por qué te importa:** Si estás construyendo agentes o pipelines de automatización que hacen muchas llamadas a LLMs, OmniRoute puede reducir significativamente los costos de desarrollo y testing. El caso de uso más directo: usar modelos gratuitos para iteraciones de desarrollo y cambiar a Claude para producción, todo sin modificar tu código. Con 85K estrellas y más de 900 contribuidores, esto ya no es un experimento marginal.

**Ojo crítico:** OmniRoute NO te da Claude gratis. Te da otros modelos. Si tu Claude Code rutea a través de OmniRoute hacia modelos gratuitos, no estás usando Claude — estás usando lo que sea que el gateway asigne. Para producción, esto importa.

**Acción sugerida:** Instalar en un entorno de desarrollo para testing de pipelines con modelos gratuitos. Para producción: Claude directo.

## ⚠️ Buyer Beware — Alerta de hype

**Todos hablan de "Claude Code gratis con OmniRoute"** — pero ojo porque lo que se ofrece no es Claude. OmniRoute enruta hacia modelos gratuitos de otros proveedores (Kimi, DeepSeek, MiniMax, etc.) usando una API compatible con Anthropic. El costo real lo controlan esos proveedores upstream, con sus propias políticas de datos y rate limits. Para experimentación y desarrollo: válido. Para afirmar que "estás usando Claude gratis": incorrecto.
