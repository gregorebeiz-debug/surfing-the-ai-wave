### Claude Fable 5.2 y Mythos 5.2 — El motor bajo el capó de Claude Code

Lanzados el 9 de noviembre, Fable 5.2 y Mythos 5.2 comparten el mismo modelo subyacente con reglas de acceso diferentes: Fable es público (con safety classifiers), Mythos es para organizaciones verificadas. Fable 5.2 es el modelo **Medium** (default) en Claude Code actualmente.

Especificaciones clave: 30% más rápido que sus predecesores, contexto de 1 millón de tokens, cutoff de conocimiento junio 2026. Precios: $8/M tokens de entrada, $40/M tokens de salida — reducción frente a Fable 5.1. Para los planes Pro, Anthropic ha anunciado que Fable 5.2 estará disponible principalmente vía usage credits después del 16 de noviembre.

**Punto crítico:** Anthropic posiciona estos modelos para "trabajo técnico exigente" (coding complejo, finanzas, ciencias), mientras sugiere Opus 5.5 para tasks cotidianas de coding. Esto es un cambio de posicionamiento. Con el IPO encima, el tiering de modelos probablemente se va a optimizar aún más agresivamente hacia monetización. No es alarmante, pero sí es un patrón a monitorear.

## 🛠 Tool & Repo Watch — Herramientas y repos

### Kong/kong — API + AI Gateway con gobernanza MCP nativa

**44,398 ⭐ | 5,244 forks | Trending en GitHub hoy | Lenguaje: Lua**

Kong es el API gateway enterprise líder que ha evolucionado en infraestructura de IA. La versión Kong AI Gateway 2.2 (lanzada septiembre 30, 2026) añade gobernanza de herramientas MCP, políticas de identidad para accesos AI, gestión de costos por modalidad, y soporte ampliado de providers. Además lanzaron un MCP Registry en Kong Konnect para registrar, descubrir y gobernar servidores MCP en producción. También anunciaron integración con NVIDIA NeMo Switchyard para routing inteligente de LLMs por request.

**Por qué te importa:** Si builds agentes con MCP servers, Kong es la capa de producción que falta entre tus agentes y los LLMs externos. Resuelve exactamente los problemas que aparecen cuando escales de prototipo a producción: governance de tools, rate limiting, cost tracking por agente/usuario, routing a múltiples providers (OpenAI, Claude, Gemini) desde un punto centralizado. Se integra con n8n via HTTP nodes. Elimina el problema de gestionar credenciales y quotas de múltiples APIs por separado.

**Sugerido:** [Explorar](https://github.com/Kong/kong) — especialmente si tienes pipelines MCP multi-proveedor o proyectas escalar agentes a producción enterprise.

### Claude Code 2.1.319 — MCP tasks asíncronas en background

Lanzado el 6 de noviembre, esta versión agrega soporte para MCP tasks asíncronas: cuando un servidor MCP ejecuta un tool call como tarea larga, Claude Code ahora la mueve al background automáticamente y notifica el resultado cuando termina, sin bloquear la sesión activa.

**Por qué te importa:** Si usas Claude Code con MCP servers custom (o servidores como Gmail, Drive, GitHub), las tool calls lentas ya no bloquean tu flujo de trabajo. Crítico para automatizaciones que involucran scraping, generación de documentos, o deploys disparados desde Claude Code. También se suma al protocolo MCP 2026-07-28 que establece background tasks como estándar.

**Sugerido:** [Actualizar](https://claudekit.io/en/updates/claude-code-2-1-319/) — disponible ahora via `claude update`.
