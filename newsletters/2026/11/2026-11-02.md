### Anthropic se prepara para salir a bolsa: IPO en la semana del 9 de noviembre

Anthropic presentó su S-1 público ante la SEC el 26 de octubre, con planes de cotizar en Nasdaq bajo el ticker **ANT**. **Por qué importa:** Anthropic dejará de ser una empresa privada. Eso significa más presión de reportes trimestrales, pero también más capital para seguir siendo la única alternativa técnicamente seria a OpenAI. La estructura de la oferta — Clase A con poder de voto limitado para el público — indica que el equipo fundador (7 co-fundadores con 50.1% de votos) mantiene el control. Buena noticia para la estabilidad del ecosistema Claude.

**Por qué importa:** OpenAI acaba de estandarizar la idea del agente-como-empleado. El concepto de "Dot especializado" — con identidad, responsabilidades y herramientas propias — es exactamente el modelo que has estado construyendo con CrewAI/LangGraph. La pregunta real: ¿puede Claude Code competir con esto en el espacio enterprise, o el ecosistema MCP ya ofrece mayor flexibilidad?

### Claude Code 2.1.292: cambio de protocolo MCP que puede romper tus servers

Claude Code 2.1.292 cambió el protocolo por defecto para servidores MCP locales (stdio) a la versión **2026-07-28**, sin actualizar la documentación, que sigue describiendo el comportamiento anterior como opt-in. El impacto concreto: servidores de canal que negocian el protocolo 2026-07-28 no pueden entregar mensajes de canal bajo el nuevo handshake. Para revertir al comportamiento anterior: `MCP_PROTOCOL_NEGOTIATION=legacy`.

**Por qué importa:** Si tienes MCP servers configurados en tu Claude Code y algo dejó de funcionar después de la actualización, aquí está la causa. Revisa la versión del protocolo que negocia cada server antes de empujar cualquier cambio a producción. La documentación oficial sigue siendo inconsistente — no es el único que estará confundido esta semana.
