### Claude Fable 5.2 y Mythos 5.2: el nuevo techo técnico de Anthropic

Anthropic liberó el 9 de noviembre sus dos nuevos modelos de punta: **Claude Fable 5.2** y **Claude Mythos 5.2**. Comparten el mismo modelo base, pero con distintos niveles de acceso: Fable es la versión de acceso general (con guardrails en ciberseguridad y biología), mientras que Mythos requiere verificación mediante los programas Cyber Verification y Life Sciences Verification de Anthropic.

Los números que circulan: 30% más rápido que las versiones 5.1, posicionado en el primer puesto del [Artificial Analysis Intelligence Index v5](https://artificialanalysis.ai) con un puntaje de 65. El pricing aún no está confirmado oficialmente, pero los reportes señalan $8/M tokens de entrada y $40/M de salida (con fast mode al doble). Anthropic Enterprise puede usar estos modelos vía Claude Security.

¿Por qué importa? Fable 5.2 es el modelo que probablemente termines usando en Claude Code en los próximos días. Es más rápido, está optimizado para coding pesado, finanzas y ciencias — exactamente el tipo de trabajo que haces con agentes y automatizaciones. Mythos 5.2 está diseñado para investigación avanzada con restricciones reducidas, disponible solo con verificación. Para el uso diario, Fable 5.2 es el candidato real.

Lo que falta confirmar: pricing oficial, contexto máximo, y qué tan superior es Fable 5.2 a Sonnet 5.5 para tareas de agentes en Claude Code. Revisa el changelog de tu plan Pro para saber cuándo será el roll-out.

### OpenAI corta el acceso a Cursor — y SpaceX es el problema

Ayer (12 de noviembre) venció el plazo que OpenAI le impuso a Cursor para terminar el suministro de sus modelos. El trasfondo: SpaceX adquirió Anysphere (empresa madre de Cursor) en agosto 2026 por ~$60B. OpenAI citó "violaciones de contrato y problemas de compliance" con compañías vinculadas a Elon Musk y se negó a seguir siendo proveedor. No le extenderá acceso a futuros modelos, incluido Astra.

Dato que lo calibra: Cursor afirmó que los modelos de OpenAI representaban sólo el **5% del tráfico** en su plataforma. El resto ya corría sobre Claude y otros proveedores. Los otros (Anthropic, Google) siguen disponibles sin cambios.

Implicación directa: si usás Cursor o lo evaluás, este movimiento confirma que la dependencia de un solo proveedor de LLM es un riesgo de negocio real — no sólo una preferencia técnica. Claude Code sigue siendo la apuesta más integrada con el ecosistema Anthropic, y Cursor/Claude es la combinación más usada en la práctica. El drama OpenAI–Musk tiene cada vez más consecuencias concretas en el tooling cotidiano.

## 🔧 Tool & Repo Watch — Herramientas y repos

### Claude Code 2.1.292 — Cambio de protocolo MCP stdio

La versión 2.1.292 de Claude Code migró los servidores MCP sobre stdio al protocolo revisado **2026-07-28**. La setting afectada: `MCP_PROTOCOL_NEGOTIATION`, con opciones `auto` (negocia con HTTP, claude.ai connector y stdio) y `legacy` (protocolo anterior). Un canal de server en el protocolo nuevo no puede entregar channel messages en esta versión — Claude Code no lo registra como channel server.

**Por qué te importa:** Si tenés servidores MCP customizados en tu setup de Claude Code, este cambio puede romper la conexión silenciosamente. Es el tipo de fallo que solo ves cuando el tool no aparece en `/mcp` o devuelve errores crípticos en medio de una sesión. La documentación oficial todavía describe el comportamiento anterior, así que el changelog del release es la única fuente confiable por ahora.

Acción sugerida: **Verificar** — abrí Claude Code, corré `/mcp` y confirmá que todos tus servers tienen estado `connected`. Si alguno no aparece, revisá la config de MCP_PROTOCOL_NEGOTIATION.

### marimo-team/marimo — 23,557 ⭐ — Reactive Python notebooks, AI-native

Un notebook de Python que resuelve el problema clásico de Jupyter: **estado oculto**. Marimo es reactivo — cambiar una celda re-ejecuta automáticamente las dependientes. Los notebooks se guardan como Python puro (compatible con git), son ejecutables como scripts, y se pueden deployar como web apps directamente.

La feature que más importa para 2026: **marimo pair** — Claude Code puede "manejar" el notebook directamente, permitiendo que el agente itere sobre datos, corra queries SQL y genere código mientras ves los cambios en tiempo real. Hay también marimo-lens (sep 2026) para explorar un notebook con un agente de forma interactiva.

**Por qué te importa:** Si construís pipelines de análisis o prototipás agentes que procesan datos, marimo es una alternativa seria a Jupyter que se integra nativamente con Claude Code. El hecho de que se guarde como Python puro significa que podés versionarlo, hacer PR, auditarlo — exactamente lo que un stack serio requiere. Con 23k+ stars y trending hoy en GitHub, el momentum es real.

Acción sugerida: **Explorar** — `pip install marimo` y `marimo tutorial intro`.

## ⚠️ Buyer Beware — Alerta de hype

### El IPO de Anthropic y la presión que viene

Todos celebran el IPO de Anthropic como una validación del ecosistema AI. Ojo porque la narrativa puede ser demasiado optimista:

La valoración de $70–78/acción implica un múltiplo de revenue enorme sobre una compañía que todavía opera con pérdidas significativas. Una vez pública, Anthropic tendrá que reportar quarterly, gestionar expectativas de Wall Street, y potencialmente sacrificar decisiones de largo plazo (safety research, precios accesibles para developers) a favor de márgenes. Las empresas de AI que salieron a bolsa antes de este ciclo mostraron volatilidad severa en los primeros 12 meses. No es que el IPO sea malo — es que el hype de "Anthropic pública = todo mejor para developers" es simplificado. Puede ser lo opuesto en el corto plazo.
