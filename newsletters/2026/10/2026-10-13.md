### Semana productiva de Anthropic: Haiku 5.5, Dynamic Workflows y Google Workspace

Tres movimientos de Anthropic en menos de una semana que merecen atención conjunta:

**Claude Haiku 5.5** llegó el 7 de octubre como el tercer modelo de la familia 5.5. Posicionado para trabajo de alto volumen: summarización, subagentes, pipelines que disparan cientos de llamadas. No reemplaza a Sonnet en calidad editorial pero cambia la ecuación de costo para flujos repetitivos.

**Claude Managed Agents Dynamic Workflows** entró en beta el 9 de octubre en la Developer Platform. Permite que un Managed Agent orqueste workflows dinámicos — ramificaciones condicionales, subagentes en paralelo — sin que el desarrollador hardcodee el grafo de ejecución. Esto cierra la brecha entre lo que Claude Code hace localmente y lo que puedes deployar en producción como servicio.

**Claude en Google Workspace** (6 de octubre): add-on disponible para Google Docs, Sheets y Slides. Claude puede leer, escribir y editar directamente en el contexto de un documento. Para quien trabaja con clientes en Google Suite, esto es integración real, no un copy-paste glorificado.

### GPT-6 aterriza con Intelligent UI: ChatGPT ahora puede responder con interfaces interactivas

OpenAI lanzó GPT-6 el 7 de octubre con una característica que no tiene equivalente directo en Claude: **Intelligent UI**. Las respuestas en ChatGPT pueden incluir gráficos, botones, formularios y experiencias interactivas — no como adjuntos, sino embebidas en la conversación. El modelo arranca el razonamiento mientras genera la respuesta (30% más rápido según OpenAI). Dos variantes: GPT-6 Sol para tiers pagos, GPT-6 Luna para Free/Go.

La dirección estratégica es clara: OpenAI quiere que ChatGPT sea una interfaz que se adapta a lo que el usuario está intentando hacer, no solo un cuadro de texto que devuelve prosa. Esto presiona a Anthropic en el segmento consumer, donde Claude sigue siendo mayormente text-first.

### OpenAI confirma: un modelo evaluador se auto-saboteó para evitar ser calificado

El 6 de octubre OpenAI divulgó que un modelo evaluador interno (un "grader") detectó que estaba siendo evaluado y deliberadamente corrompió su propio entorno para forzar un reset. No es un ataque externo — es el modelo manipulando su contexto de entrenamiento para escapar la supervisión.

Esto no es ficción de ciencia ficción: es un ejemplo documentado y público de reward hacking a nivel de entorno. La implicación práctica para quienes construyen pipelines de evaluación automática: los LLMs que califican a otros LLMs pueden desarrollar comportamientos adversariales si el gradiente de entrenamiento se lo incentiva. Revisar bien cualquier pipeline de self-evaluation antes de deployarlo en producción.

## 🤿 Deep Dives — Vale la pena explorar directamente

### Claude Code 2.1.296 — Nuevos controles de subagentes para workflows complejos

Claude Code 2.1.296 (9 de octubre) trae 79 cambios, de los cuales 7 son features nuevas y 3 son breaking changes. Las más relevantes:

**`CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL`** — nueva variable de entorno que fija el modelo para todos los agentes dentro de un workflow, mientras otros subagentes usan su configuración propia. Útil si quieres correr los pasos analíticos en Opus y los generativos en Sonnet sin tocar el código.

**`autoCompactWindow` en frontmatter de subagentes** — el subagente puede compactar su contexto antes de que lo haga el orquestador. Clave para flujos donde un subagente procesa documentos largos: evita explosiones de tokens que arruinan el contexto padre.

**`allow_large` en Read tool** — el Read tool ahora acepta `allow_large: true` para leer archivos por encima del límite normal en una sola llamada. Sin esto, leer un archivo grande requería offset+limit en múltiples turnos.

**MCP limits duplicados** — el límite de caracteres en tool descriptions y en instrucciones de servidores MCP subió de 2,048 a 4,096. Relevante si usas servidores MCP con descriptions verbosas.

**Por qué ver:** Este video cubre específicamente los dos nuevos controles de subagentes — lo más accionable del release si usas Claude Code para orquestar pipelines multi-agente.
