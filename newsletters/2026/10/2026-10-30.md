### 1. Claude Duet: el agente proactivo de Anthropic abre research preview

Anthropic lanzó el 21 de octubre la research preview de **Claude Duet** para usuarios Pro y Max en EE.UU. (iOS, Android, claude.ai). A diferencia del chat reactivo, Duet corre en background usando **Opus 5.5**: monitorea tus apps conectadas, prioriza tareas y genera un briefing matutino sin que lo pidas. Solo te interrumpe cuando hay una acción irreversible — pagar, firmar, enviar — y las credenciales nunca son visibles al agente.

El contexto competitivo importa: Anthropic llega dos semanas después de Meta Muse y OpenAI dots, lanzados en septiembre. Actualmente en **waitlist** para US Pro/Max — si usas Claude Pro, aplica ya para entrar en el primer lote.

La pregunta que nadie responde aún: ¿qué pasa con los datos que el agente procesa en background? La arquitectura dice que es seguro; el tiempo dirá.

### 2. n8n 3.0 entra en beta — stable en diciembre, breaking changes masivos

El 27 de octubre n8n liberó la beta de la versión 3.0. **No hay features nuevas** — el punto es consolidar todos los breaking changes acumulados del año en un solo salto mayor: mejor reliability, seguridad hardened y APIs limpias. La versión stable llega en diciembre 2026. Ya existe una herramienta de migración oficial.

Mientras tanto, la **2.45.0** (Oct 20) sí trajo mejoras reales: nuevas herramientas de agentes y workflow, **permisos MCP mejorados**, y notificaciones de migración. La 2.43 hizo Browser Use disponible para todos.

Si tienes flows de producción en n8n: **no actualices a 3.0 beta**. Espera el stable de diciembre y usa la migration tool antes de saltar. Las mejoras de MCP en 2.45.x sí merecen una actualización controlada ahora.

*Fuentes: [docs.n8n.io](https://docs.n8n.io/changelog/release-notes), [n8n Community](https://community.n8n.io/t/announcing-n8n-version-3-0-coming-soon/324016)*

## 🔧 Tool & Repo Watch — Herramientas y repos

### @anthropic-ai/sandbox-runtime — Open Source Apache 2.0

Anthropic liberó el runtime de sandbox que usa Claude Code internamente. Empaquetado como npm `@anthropic-ai/sandbox-runtime`. Usa `sandbox-exec` en macOS, `bubblewrap` en Linux, alpha en Windows (WFP + NTFS ACLs). Research preview — las APIs pueden cambiar.

**Por qué te importa:** Estás en Claude Code todo el día. Este package te da el mismo nivel de aislamiento filesystem/network que usa Claude Code en tus propios agentes y pipelines. Si construyes herramientas con ejecución de código — flows de LangGraph, agentes n8n con code nodes, automatizaciones con Python arbitrario — este es el sandbox que querrías entre tu código y el sistema. No hay motivo para construir tu propio desde cero.

GitHub: [anthropics/sandbox-runtime](https://github.com/anthropics/sandbox-runtime) | ⭐ Research preview | **Acción: Explorar**

### Claude Code v2.1.302 — Plugin System oficial + Mods API

La v2.1.302 (Oct 17) formalizó el plugin system con un directorio first-party y una **Mods API** en JS/TypeScript para hooks sobre tool calls. Los plugins existían en beta antes, pero ahora hay un contrato oficial de extensibilidad con Claude Code Cloud Sessions.

**Por qué te importa:** Puedes escribir mods que intercepten tool calls en Claude Code, agreguen paneles, banners de estado o slash commands propios. Si automatizas workflows dentro de Claude Code, esta API es el punto de entrada para customizaciones sin hackear internals. Es la diferencia entre usar Claude Code como herramienta y extenderlo como plataforma.

Referencia: [tech-insider.org](https://tech-insider.org/claude-code-plugins-official-mods-cloud-sessions-2026/) | **Acción: Instalar y explorar**

### OpenCode — Coding agent terminal open-source (trending GitHub, Oct 2026)

OpenCode es el coding agent de terminal más descargado que no es Claude Code ni Codex — completamente open source, agnóstico a modelo (puedes apuntar a cualquier LLM). Según el snapshot de OSS Insight de octubre, `anomalyco/opencode` está entre los repos con mayor momentum en AI este mes.

**Por qué te importa:** No lo necesitas para reemplazar Claude Code. Pero si construyes pipelines automatizados donde quieres un coding agent sin costo de API de Anthropic, o en entornos donde los datos no pueden salir a Anthropic, OpenCode con un modelo local es la arquitectura. También útil como referencia de cómo están diseñados estos agentes por dentro.

GitHub: [anomalyco/opencode](https://github.com/anomalyco/opencode) | **Acción: Monitor**

TanStack publicó la versión 1.0 de su AI stack. Integra query management, streaming y tool use en el ecosistema React/Next.js con el patrón familiar de TanStack Query/Router.
