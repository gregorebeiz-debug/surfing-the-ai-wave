### Anthropic presenta su S-1: el IPO es oficial

El 26 de octubre, Anthropic, PBC presentó formalmente su declaración de registro ante la SEC para una oferta pública inicial de acciones Clase A. Planea cotizar en Nasdaq bajo el ticker **ANT**. Con un revenue run rate anualizado superior a $47B y $2.7B en ganancias en el primer semestre de 2026, Anthropic sería la primera de las grandes empresas de IA generativa en salir a bolsa. La oferta depende de condiciones de mercado; varios reportes apuntan a noviembre como fecha probable.

Por qué importa ahora: el IPO cambia los incentivos de Anthropic. Hasta ahora, Dario Amodei podía priorizar seguridad sobre velocidad sin rendir cuentas a accionistas públicos. Eso cambia. Presta atención a cómo evoluciona el roadmap de productos en los próximos 6-12 meses post-IPO.

### Claude Haiku 5.5: el modelo construido para subagentes

Lanzado el 7 de octubre, Claude Haiku 5.5 es el modelo más pequeño y rápido de la familia Claude 5.5. Ficha técnica: contexto de 1M tokens (5x más que Haiku 4.5), hasta 128K tokens de output, adaptive thinking con 5 niveles de esfuerzo (Low, Medium, High, Xhigh, Max), y un precio ~75% menor que su predecesor. Construido explícitamente para subagentes, clasificación, routing, extracción de datos y browser use de alta velocidad.

**Punto crítico:** el nuevo tokenizer genera ~30% más tokens del mismo texto comparado con Haiku 4.5. Si tienes pipelines que migran de Haiku 4.5 y calculas "75% más barato", recalcula primero — el ahorro real es menor. Para casos nuevos, el precio/rendimiento es excelente.

*Fuentes: [Anthropic blog](https://www.anthropic.com/news/announcements), [Claudelog](https://claudelog.com/faqs/what-is-claude-haiku-5-5/)*

### Anthropic entra en drug discovery: resultados preliminares y adquisición

El 27 de octubre, Anthropic publicó los primeros resultados de sus colaboraciones con 6 organizaciones farmacéuticas: BigHat Biosciences, Bristol Myers Squibb, Divergence Labs, Enveda, Generate Biomedicines, y The Column Group. Claude Science — plataforma lanzada en junio con 60+ herramientas especializadas en genomics, bioquímica y HPC — está reduciendo el trabajo administrativo en investigación farmacéutica hasta un 89%. Anthropic también adquirió Mithril Medicine, una startup de una sola persona enfocada en descubrimiento de moléculas para enfermedades raras.

Contexto relevante: Novo Nordisk también firmó colaboración con Anthropic en septiembre. Claude no es solo un chatbot corporativo — Anthropic está construyendo verticales propias. Esto afecta cómo se posiciona la empresa en el IPO.

*Fuentes: [Digital Health News](https://www.digitalhealthnews.com/anthropic-partners-with-six-life-sciences-organizations-to-advance-drug-development-with-claude), [Four Week MBA](https://fourweekmba.com/ai-anthropic-buys-a-drug-startup-runs-claude-in-6-partnerships/)*

### OpenAI Agents API expandido — computer use, multi-agent, context compaction

OpenAI amplió su Agents API (en beta pública desde septiembre) con cuatro capacidades nuevas: **computer use**, **multi-agent support**, **tool search**, y **context compaction**. En paralelo, DevDay (29 de septiembre) anunció "Dots" — agentes always-on personales powered by GPT-6 Astra — y la Decisions API para flujos agenticos estructurados.

**Por qué te importa:** Si construyes agentes con Claude SDK, este es el ecosistema con el que compites o del que puedes tomar ideas. Computer use en el Agents API de OpenAI presiona a Anthropic a acelerar su propia oferta de browser/computer use nativa. Multi-agent support con context compaction es directamente relevante si estás diseñando sistemas de agentes con n8n o LangGraph.

→ [OpenAI DevDay Recap](https://openai.com/blog/devday-2026-recap) | [SmartScope análisis](https://smartscope.blog/en/blog/was-announced-openai-devday-2026-features-plan-developer-2026/) [AI Agents]
Acción sugerida: **Explorar** — revisa los nuevos endpoints si tienes proyectos multi-agent en desarrollo.

### n8n 2.43.3 — los deprecated nodes ahora bloquean en vez de advertir

La versión 2.43.3 (9 de octubre) cambia el comportamiento con nodos deprecated: ya no es un warning — ahora bloquea la creación o actualización de workflows que los usen.

**Por qué te importa:** Si usas n8n para pipelines de automatización y tienes workflows con nodos legacy (HTTP Request v1, Function Node legacy), la próxima actualización puede silenciosamente romper tu CI/CD o impedir que guardes cambios en workflows existentes. Audita tus workflows **antes** de actualizar.

→ [n8n Changelog](https://docs.n8n.io/changelog/release-notes-1.x) | ~60K⭐ GitHub [AI Automation]
Acción sugerida: **Auditar** workflows antes de actualizar a 2.43.3+.

### Claude Code 2.1.292 — nuevo protocolo para servidores MCP stdio

Claude Code 2.1.292 migró la conexión con servidores MCP stdio al protocolo revision 2026-07-28. La documentación oficial aún describe el comportamiento anterior (opt-in). La variable `MCP_PROTOCOL_NEGOTIATION` controla si Claude Code negocia el nuevo protocolo con tu servidor.

**Por qué te importa:** Si tienes MCP servers propios que usas con Claude Code — incluyendo los que construiste para tus automatizaciones — verifica compatibilidad con el nuevo protocolo. Si tu servidor no maneja protocol negotiation, puede fallar silenciosamente o con errores crípticos.

→ [Mixed News análisis](https://mixed-news.com/en/claude-code-2-1-292-stdio-mcp-protocol-2026-07-28-docs-contradict/) [Claude Ecosystem]
Acción sugerida: **Verificar** — prueba tus MCP servers locales contra Claude Code 2.1.292+.
