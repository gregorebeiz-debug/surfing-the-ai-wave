### GPT-5.5 Instant: nuevo modelo por defecto en ChatGPT

OpenAI reemplazó GPT-5.3 Instant con **GPT-5.5 Instant** como modelo por defecto el 5 de mayo. Las mejoras son medibles: 52.5% menos alucinaciones en prompts de alto riesgo (medicina, derecho, finanzas), respuestas más concisas, mejor razonamiento STEM e imagen, y contexto más rico para usuarios Plus/Pro. Para quienes usan ChatGPT complementando su stack principal, es un upgrade real. La cifra de 52.5% en hallucinations es la que hay que monitorear — si se sostiene en uso real, cambia el caso de uso en tareas críticas.

## 🔧 Tool & Repo Watch — Herramientas y repos

### Claude Managed Agents: Self-Hosted Sandboxes + MCP Tunnels

Dos features enterprise anunciadas en Code w/ Claude London el 19 de mayo. Los **self-hosted sandboxes** (public beta) mueven la ejecución de tools a infraestructura tuya o de providers como Cloudflare, Daytona, Modal, y Vercel — Anthropic gestiona la orquestación, vos controlás el cómputo y los datos. Los **MCP tunnels** (research preview) permiten que Managed Agents se conecten a servidores MCP privados sin exponerlos a internet: un gateway local establece una conexión outbound cifrada hacia la infraestructura de Anthropic.

**Por qué te importa:** Tenés servidores MCP corriendo localmente. Los MCP tunnels son exactamente lo que necesitás para conectar agentes Claude a esos sistemas sin abrir puertos públicos ni comprometer la seguridad de red. El modelo de self-hosted sandboxes con Modal o Vercel también encaja directamente con tu stack de automatización. Explorar ahora, no esperar.

→ [The New Stack](https://thenewstack.io/anthropic-mcp-tunnels-sandboxes/) | [InfoQ Deep Dive](https://www.infoq.com/news/2026/05/claude-mcp-tunnels/)

**Acción sugerida:** Explorar. Testear MCP tunnels en research preview con tus servidores MCP locales.

### Claude Code v2.1.152 — 8 features nuevas, 16 bug fixes

Lanzado el 26 de mayo. Los cambios que importan: **`/code-review --fix`** ahora aplica automáticamente los cambios al working tree — el loop review → fix → commit es ahora un solo comando. **Skill management** con `/reload-skills` y `disallowed-tools` para control granular de plugins en proyectos complejos. **`/resume` para background sessions** — las sesiones iniciadas con `--bg` ahora aparecen en el picker con duración. Vim mode incluye búsqueda en historial con `/` en NORMAL mode. Fix crítico: startup que colgaba hasta 75s cuando `api.anthropic.com` era inalcanzable ahora timeout en 15s.

**Por qué te importa:** Usás Claude Code todos los días. El `/code-review --fix` convierte el flujo de revisión en un loop automatizado sin pasos manuales intermedios. El fix de startup de 75s es relevante específicamente en entornos cloud donde la conectividad fluctúa — como este.

→ [DevelopersIO](https://dev.classmethod.jp/en/articles/20260524-claude-code-updates-v2-1-152/) | [GitHub Releases](https://github.com/anthropics/claude-code/releases)

**Acción sugerida:** Instalar. `npm update -g @anthropic-ai/claude-code`

### AWS MCP Server — GA desde May 6

MCP server oficial de AWS en general availability. Acceso a más de 15,000 operaciones de la AWS API via MCP, con ejecución de Python en sandbox aislado del filesystem local, documentación actualizada en tiempo real, y governance completo via IAM + CloudTrail. Sin costo adicional — solo pagás los recursos AWS que tus agentes consumen. Disponible en us-east-1 y Frankfurt.

**Por qué te importa:** Si usás Claude Code o agentes para automatizar infraestructura cloud, este es el MCP server más completo para AWS. El modelo de seguridad (IAM context keys, CloudTrail logging) es lo que faltaba para usar agentes en ambientes con compliance. Si no tenés recursos en AWS hoy, es irrelevante. Si sí, instalar ya.

→ [AWS Blog](https://aws.amazon.com/blogs/aws/the-aws-mcp-server-is-now-generally-available/)

**Acción sugerida:** Instalar si usás AWS. Monitor si no.
