## 🌊 The Wave Today — Noticias que mueven la aguja

### Claude Code v2.1.142: Agent View, Goal Mode y Opus 4.7 en Fast Mode

La actualización más impactante esta semana para el workflow de Gregorio. **Agent View** (`claude agents`) permite monitorear todas las sesiones activas desde una sola pantalla — si corres múltiples instancias de Claude Code en paralelo en distintos proyectos, esto elimina el caos de terminales dispersas. **Goal Mode** (`/goal`) mantiene al agente en loop hasta cumplir una condición definida, sin intervención manual — útil para tareas de testing o deployment largas. Y el cambio más divisivo: **Fast Mode ahora usa Opus 4.7 por defecto** (antes Opus 4.6), entregando 2.5x más velocidad a cambio de 6x el costo ($30/M tokens input vs $5/M en standard). Análisis crítico: el salto de velocidad es real, pero el multiplicador de costo no escala linealmente con el valor. Úsalo para iteración rápida en prototipos, no como default permanente en proyectos de producción.

### Claude Managed Agents: Self-Hosted Sandboxes + MCP Tunnels (19 mayo)

Anthropic liberó dos features que hacen viable por primera vez el deployment de agentes Claude en entornos enterprise con compliance estricto. **Self-Hosted Sandboxes** (public beta): tus archivos, paquetes y servicios sensibles quedan en tu propia infraestructura — el agent loop de orchestration sigue en Anthropic, pero la ejecución sale de tus servidores. **MCP Tunnels** (research preview): los agentes alcanzan MCP servers dentro de redes privadas sin exponerlos al internet público — una conexión outbound saliente, sin reglas de firewall inbound. El patrón es consistente con lo que Anthropic anunció en Code with Claude: multiagent orchestration, Outcomes (criterios de éxito iterativos), y Dreaming (memoria entre sesiones que mejora agentes entre runs). Esto no es feature bloat — es la infraestructura para agentes que realmente funcionan en producción, fuera del sandbox.

*Fuentes: [Claude Blog](https://claude.com/blog/claude-managed-agents-updates), [9to5Mac](https://9to5mac.com/2026/05/19/anthropic-enhances-claude-managed-agents-with-two-new-privacy-and-security-features/), [VentureBeat](https://venturebeat.com/orchestration/claude-agents-can-finally-connect-to-enterprise-apis-without-leaking-credentials), [InfoQ](https://www.infoq.com/news/2026/05/code-with-claude/)*

### Google I/O 2026: Antigravity 2.0, Gemini 3.5 y WebMCP

Google presentó su contraataque al momento Anthropic. **Antigravity 2.0**: plataforma agent-first con CLI propio, subagentes especializados, terminal sandboxing y credential masking — la respuesta directa a Claude Code. **Gemini Omni y Gemini 3.5 Flash**: Omni trabaja desde video como input primario (multimodalidad real); Gemini 3.5 Flash combina inteligencia frontier con capacidades de acción directa. Lo más estratégico para developers web: **WebMCP**, estándar web abierto propuesto que expone herramientas estructuradas a agentes browser-based — esencialmente MCP pero para la web abierta. Si Vercel o Next.js lo adoptan, el stack de Gregorio se vuelve nativamente agentic sin capas adicionales. También: Managed Agents en la Gemini API (ejecución de agentes con herramientas en sandbox Linux aislado, un API call), y Android CLI para que agentes interactúen con Android Studio y dispositivos reales. La carrera de infraestructura agentic entre Google y Anthropic se acelera.
