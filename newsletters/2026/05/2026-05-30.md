### Claude Opus 4.8: Dynamic Workflows, Effort Control y un salto real en honestidad

Anthropic lanzó Opus 4.8 el 28 de mayo — solo 41 días después de Opus 4.7. La velocidad de iteración importa, pero lo que realmente cambia aquí es la arquitectura de trabajo, no el modelo en sí.

**Dynamic Workflows en Claude Code:** El sistema escribe scripts de orquestación que lanzan hasta 1,000 subagentes paralelos en una sola sesión. Los agentes atacan el problema desde ángulos independientes, otros agentes adversariales refutan los hallazgos, y el sistema itera hasta que los resultados convergen antes de reportar. Caso de uso demostrado: migraciones de codebase de cientos de miles de líneas de código "de kickoff a merge, con el test suite existente como barra." Disponible en Enterprise, Team y Max — **no en Pro individual todavía**.

**Límites reales:** El cap es de 1,000 agentes por run. Los costos escalan rápido. No es para tareas cotidianas sino para operaciones que hoy tomarían días.

**Effort Control:** `/effort xhigh` para las tareas más difíciles. Fast Mode en Opus 4.8: 2x el costo standard, 2.5x más rápido. El pricing entre Opus 4.7 y 4.8 no cambió.

**Honestidad:** Menos comportamiento sycophantic, menos deception en tareas extendidas. Anthropic lo llama explícitamente — señal de que era un problema documentado internamente.

**Benchmarks:** Supera GPT-5.5 y Gemini 3.1 Pro en agentic coding, financial analysis y computer use. Habrá que ver evaluaciones independientes, pero el stack completo (modelo + workflows) ya no tiene comparación directa.

### MCP Specification Release Candidate — Cambio arquitectural importante

El RC del próximo spec de Model Context Protocol quedó bloqueado el 21 de mayo. Release final: 28 de julio de 2026. Los cambios que importan:

- **Protocolo stateless:** Las respuestas de `tools/list` ahora llevan `ttlMs` y `cacheScope` (similar a HTTP Cache-Control). Ya no se requiere un SSE stream persistente para detectar cambios en herramientas. Esto simplifica enormemente los clients de MCP.
- **Extensions framework:** Nueva capa para capacidades opcionales, sin romper compatibilidad.
- **Tasks + MCP Apps:** Primitivas para tareas asíncronas y aplicaciones completas construidas sobre MCP.
- **Authorization hardening:** Mejoras en el modelo de permisos.
- El registro oficial ya tiene **9,652 servidores MCP activos**.

Paralelamente, Anthropic donó MCP a la Agentic AI Foundation para gobernanza abierta del estándar — señal de que el protocolo ya no es solo de Anthropic sino del ecosistema.

Si tienes MCP servers en producción o en desarrollo, el RC de 10 semanas es la ventana para validar antes del release final.
