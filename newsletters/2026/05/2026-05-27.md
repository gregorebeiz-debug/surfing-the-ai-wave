## 🌊 The Wave Today — Noticias que mueven la aguja

### Code with Claude 2026: Anthropic rediseña el contrato entre humano y agente

El 6 de mayo, Anthropic celebró su conferencia anual de desarrollo en San Francisco. Lo que parecía ser un evento de anuncios incrementales resultó en una reorientación de producto: de "AI que genera código" a "AI que entrega resultados autónomamente".

**Qué se anunció:**
- **Claude Managed Agents** con tres pilares: *Dreaming* (Claude revisa sesiones pasadas y cura su propia memoria entre runs), *Outcomes* (defines el resultado final y el agente trabaja en loop hasta lograrlo con evaluador propio), y multi-agent orchestration (agente principal delega a subagentes especializados en paralelo con filesystem compartido)
- **Agent View + comando `/goal`**: dashboard `claude agents` para manejar múltiples sesiones paralelas; `/goal "condición verificable"` mantiene a Claude trabajando autónomamente turno a turno hasta cumplirla
- **Límites duplicados** en Claude Code para Pro, Max, Team y Enterprise
- **Partnership con SpaceX Colossus** (220,000 GPUs NVIDIA)
- **Routines**: Claude Code como agente proactivo que revisa tu repositorio y abre PRs antes de que abras el laptop

**El análisis:** Anthropic no está mejorando un chatbot — está construyendo infraestructura para agentes de producción. La combinación Outcomes + Agent View + /goal convierte Claude Code en un sistema async-by-default: dejas de supervisar pasos, defines resultados verificables. El cambio no es incremental.

### Microsoft abandona Claude Code internamente — La crisis de costos enterprise se hace visible

A partir del 30 de junio, Microsoft cancela la mayoría de licencias internas de Claude Code en su división Experiences & Devices (Windows, Microsoft 365, Outlook, Teams, Surface). Los ingenieros migran a GitHub Copilot CLI. La causa: costos de $500–$2,000 por usuario/mes cuando la adoption rate llega al 84–95%. Uber quemó su presupuesto entero de AI coding 2026 en 4 meses. Gartner ya predice que el 25% del presupuesto AI 2026 global se deslizará a 2027.

**El análisis crítico:** Las herramientas son tan buenas que los ingenieros las usan constantemente — eso rompe la matemática enterprise. Esta historia no es sobre que Claude Code sea malo; es sobre que los precios de tokens no han bajado lo suficientemente rápido para uso intensivo a escala de miles de ingenieros. Para builders individuales con suscripción Pro, el ROI sigue siendo claro. Para Gregorio: esto es información de mercado, no una señal de cambiar stack.

*Fuentes: [The Next Web](https://thenextweb.com/news/microsoft-claude-code-retreat-ai-cost), [Fortune](https://fortune.com/2026/05/22/microsoft-ai-cost-problem-tokens-agents/), [Codimite](https://codimite.ai/blog/microsoft-cancels-claude-code-access-after-ai-budget-overrun/)*

### Claude Code Agent View + `/goal` — Features que cambian el flujo de trabajo diario
Disponible en Claude Code v2.1.139+. `claude agents` abre dashboard de todas las sesiones activas con status, último response, y si necesitan tu input. `/goal "condición verificable"` mantiene a Claude trabajando autónomamente hasta que la condición se cumple; evaluador por IA verifica después de cada turno.
**Por qué te importa:** Cambia el paradigma de sync (tú esperas a Claude) → async (Claude te llama cuando necesita). Para pipelines multi-step como los que ya construyes, el patrón /goal + Agent View es exactamente cómo deberías estar operando. Actualizar Claude Code es la primera acción de hoy.

## ⚠️ Buyer Beware — Alerta de hype

**Todos hablan de "AI coding saves money in enterprise" — pero los números reales están llegando y no son los del pitch deck.**

Microsoft ($500–2,000/usuario/mes), Uber (presupuesto anual quemado en 4 meses), Gartner (25% del presupuesto AI 2026 deslizándose a 2027). El problema no es que las herramientas fallen — es que funcionan tan bien que el consumo escala exponencialmente. Los vendedores de AI citaban ahorros del 30–40% en productividad de ingeniería; nadie modeló qué pasa cuando la adoption rate llega al 90%. Para builders individuales el ROI sigue siendo positivo. Para enterprise sin pricing por capacidad en vez de tokens, la matemática está rota. Ojo cuando evalúes el "caso de negocio" de qualquier herramienta que cobra por token.
