## 🔭 Deep Dives — Vale la pena explorar directamente

### Anthropic — "Introducing Dynamic Workflows in Claude Code"

Los Dynamic Workflows son la novedad técnica más relevante de esta semana para Gregorio. La mecánica: Claude no solo ejecuta tareas secuenciales — escribe un script JavaScript que actúa como orquestador, define qué subagentes lanzar, en qué orden, con qué lógica condicional o de loops. El estado intermedio vive en variables del script (fuera del contexto de conversación), lo que elimina el token tax de las cadenas de subagentes largas. Una demo interna generó 750,000 líneas de código en 11 días con 99.8% del test suite verde.

Para activarlo: escríbele a Claude "Crea un dynamic workflow para [tarea]" o activa la nueva configuración `ultracode` en Claude Code.

**Por qué explorar ahora:** Usas Claude Code diariamente para tareas de coding complejas. Dynamic Workflows convierte lo que antes era secuencial (y caro en tokens) en paralelo coordinado. El límite de 1,000 subagentes es artificial por ahora — la arquitectura en sí es el cambio arquitectural más grande desde que Claude Code se lanzó.

[Leer guía oficial](https://claude.com/blog/introducing-dynamic-workflows-in-claude-code)

### Claude Code v2.1.152 — Agent View + Security Plugin + Rate Limits Doblados

**Agent View:** Gestiona múltiples sesiones desde un solo CLI — lanza agentes, envíalos al background, revisa su estado y salta de vuelta cuando necesiten input. El workflow que hacías en múltiples terminales, ahora nativo.

**Security Plugin:** Monitorea edits, diffs y commits en tiempo real, señala patrones peligrosos antes de producción. Rate limits doblados para developers, startups y enterprises.

**Por qué te importa:** Es la herramienta que usas todos los días. Agent View + Dynamic Workflows juntos cambian cómo coordinas trabajo paralelo — ya no necesitas orquestar manualmente sesiones separadas. Actualiza ya.

Acción sugerida: **Actualizar** (`claude update`)
