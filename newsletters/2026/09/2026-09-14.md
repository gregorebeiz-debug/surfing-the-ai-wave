### Claude Fable 5.1 y Mythos 5.1: el stack que usas acaba de mejorar (y abaratarse)

Anthropic lanzó Claude Fable 5.1 como su modelo de producción de propósito general. El dato que importa: **supera ahora a Claude Opus 5 en todos los benchmarks publicados**, incluyendo agentic coding, long-horizon workflows, y visual/frontend code generation. Contexto: 1M tokens, output máximo 128K.

El watermark es invisible sin la API de detección, no agrega tokens, y no lleva información de usuario.

Mythos 5.1 llega exclusivamente para participantes del Project Glasswing (cybersecurity y life sciences) con salvaguardas menos restrictivas.

### Alerta de seguridad: vulnerabilidades de sandbox en Claude Code, Codex y Cursor — más un ataque agentic real a escala

Investigadores divulgaron esta semana vulnerabilidades de sandbox en **Claude Code, OpenAI Codex y Cursor** (reportadas a vendors este verano, ahora públicas). El timing no podría ser peor: un actor de amenaza de habla rusa usó **cientos de agentes IA** construidos sobre OpenAI Codex y un modelo DeepSeek para explotar vulnerabilidades y comprometer al menos **440 instancias de PaperCut NG/MF** en 395 organizaciones de 48 países.

La señal más importante no es el exploit específico — es el patrón: **los ataques ya son agentic**. El vector ya no es "un hacker con un exploit" sino "cientos de agentes IA coordinados ejecutando exploits en escala y velocidad no humana". Las vulnerabilidades de sandbox en las herramientas que usas para coding y automatización necesitan revisión activa.

Anthropic, OpenAI y Cursor están al tanto. Mantén Claude Code actualizado y revisa los permisos de tus agentes en producción.

## 🔧 Tool & Repo Watch — Herramientas y repos

### Claude Code v2.1.269 — Plugin Evals + Headless + MCP

Release del 11 de septiembre. Las novedades que te afectan directamente:

- **`claude plugin eval`** — Nuevo comando para correr la suite de evaluación de un plugin contra Claude Code. Genera reportes JSON + HTML reproducibles. Primera vez que los evals de plugins son flujo de trabajo formal.
- **`--permission-prompts none`** — Flag para hosts headless no atendidos: todo lo que normalmente requeriría un prompt se deniega automáticamente mientras el permission mode activo sigue decidiendo el resto. Ideal para pipelines de automatización sin intervención humana.
- **`managedMcpServers`** — Las organizaciones pueden proveer servidores MCP HTTP/SSE a todos sus usuarios desde configuración central. Si trabajas en equipo con MCP, esto cambia la gestión.
- **Fix MCP HTTP+SSE** — Corregido bug crítico: servidores configurados como `http` que solo soportaban SSE legacy nunca conectaban. Claude Code ahora hace fallback a SSE según el spec MCP. Si tenías MCP servers propios que "no funcionaban", puede ser esto.
- **Restricción de sitios en web_search/web_fetch** — Para agentes managed: ahora puedes definir qué sitios pueden alcanzar estas tools. Control de seguridad importante para agentes en producción.

**Por qué te importa:** `--permission-prompts none` puede transformar cómo estructuras tus Routines y automatizaciones headless — ya no necesitas workarounds para pipelines no atendidos. El fix MCP es relevante si alguna vez tuviste un servidor propio que fallaba silenciosamente. Y si desarrollas plugins, los evals formales son exactamente lo que faltaba.

**Acción:** Actualizar ahora. Revisar `--permission-prompts none` para tus automatizaciones. Si tienes MCP servers propios, probar si el fix resuelve conexiones previas.
