## 🌊 The Wave Today — Noticias que mueven la aguja

### Claude Code Projects: threads paralelos que siguen corriendo cuando cierras el laptop

Anthropic lanzó ayer el rediseño más significativo de Projects para Claude Code. La mecánica: una sola conversación actúa como coordinadora y puede arrancar múltiples sesiones cloud en paralelo. Describes qué necesitas, Claude divide el trabajo en threads independientes, cada uno con su propio modelo y nivel de esfuerzo de razonamiento, y todos comparten el mismo pool de memoria. Los threads siguen corriendo después de cerrar tu laptop. Beta hoy para usuarios seleccionados de Pro y Max.

Esto no es feature incremental. Es un cambio de modelo mental: dejas de "correr prompts" y empiezas a "delegar proyectos". La diferencia entre supervisar 5 sesiones de Claude Code manualmente y tener un coordinator que las maneja automáticamente es la diferencia entre herramienta y agente real. El tradeoff es que estás en beta y el comportamiento del coordinator todavía no está documentado exhaustivamente — experimenta con proyectos pequeños antes de apostarlo todo.

### Claude Fable 5.1: cache reads -75%, costos agentic -45%

Si llamas a la API desde pipelines de n8n o usas Claude Code intensivamente, tu factura baja sin cambiar nada de tu lado.

### Cloudflare: el tráfico bot superó al humano en mayo de 2026

Cloudflare reportó que 57.4% de los requests a sitios web ya son automatizados. El tráfico agentic AI creció **7,851% interanual** y llegó 18 meses antes de lo que el propio CEO de Cloudflare proyectaba. El 52% de los crawls son ahora para entrenamiento de IA. Matthew Prince quiere que las AI companies paguen por ello.

Para quien construye productos web: tus métricas de tráfico ya no son confiables como proxy de comportamiento humano. Rate limiting, analytics, y costos de bandwidth necesitan recalibración. Si tienes bots propios (agentes web, scrapers para pipelines), el entorno de red donde operan está cambiando rápido — más friction, más rate limits, más costos eventualmente.

*Fuentes: [Fortune](https://fortune.com/2026/09/18/cloudflare-ceo-matthew-prince-ai-bots-human-web-traffic-pay/), [NBC News](https://www.nbcnews.com/tech/tech-news/bot-web-traffic-overtaken-human-web-traffic-data-shows-rcna348522)*

## 🔧 Tool & Repo Watch — Herramientas y repos

### fast-jev-compaction — Plugin de compactación inteligente para Claude Code

**Qué hace:** Optimiza el proceso de compactación de Claude Code evaluando tool calls y resultados en un solo request, eliminando ítems stale mientras preserva el contexto relevante verbatim.

**Por qué te importa:** En sesiones largas de Claude Code, la compactación automática es donde más contexto se pierde silenciosamente — Claude "olvida" trabajo previo y repite pasos ya hechos. Este plugin hace la compactación selectiva en lugar de agresiva. Si trabajas en proyectos de múltiples sesiones (que con Projects ahora son más probables), esto directamente reduce los errores de contexto perdido.

### n8n v2.36 — Modelos de AI sin API keys propias

**Qué hace:** Desde v2.36, puedes usar modelos de AI en los ~70 nodos de AI de n8n sin crear cuenta en el proveedor ni gestionar API keys. Disponible en planes de n8n Cloud seleccionados.

**Por qué te importa:** Si tienes workflows en n8n que llaman a modelos de AI, esto elimina la fricción de credenciales para experimentar rápido. El tradeoff es dependencia del intermediario n8n: si tu plan cambia o el proveedor falla, tus pipelines también. Para prototipos y flujos no críticos, excelente. Para pipelines de producción con SLAs, mantén tus propias keys.

## 🚨 Buyer Beware — Alerta de hype

Todos hablan de **GPT-6 Astra como "posible AGI"**, pero ojo porque:

OpenAI declaró que el modelo "may represent AGI" mientras simultáneamente admite que es el primer modelo en alcanzar nivel "Critical" de ciberseguridad — puede desarrollar nuevos exploits en sistemas bien protegidos de forma autónoma. Eso no es una declaración inocente de capacidad: es la primera vez que un modelo llega a ese umbral en el propio framework de safety de OpenAI, y la compañía lo está usando como marketing positivo. Si tu organización adopta este modelo en producción (vía API o integraciones), revisa el System Card antes — especialmente las restricciones sobre prompts de ciberseguridad que el modelo rechaza por defecto en su versión restringida actual.

*Fuente: [GPT-6 Astra System Card](https://deploymentsafety.openai.com/gpt-6-astra)*
