## 🌊 The Wave Today — Noticias que mueven la aguja

### 1. Claude Fable 5.1 + Mythos 5.1: El upgrade silencioso que más importa es el precio del cache

Anthropic lanzó Claude Fable 5.1 el 1 de septiembre. El número headline es 52.6% en Terminal-Bench-Science (vs 24.7% de Fable 5 y 29.0% de Opus 5), con ventana de 1M tokens y output máximo de 128K. Pero lo que realmente mueve la aguja para usuarios con cargas de trabajo agenticas: **cache reads bajan de $1 a $0.25 por millón de tokens — un recorte del 75%.** Anthropic estima que esto reduce los costos típicos de workloads tokenizados en ~25%, y workloads agenticos en ~45%.

**Cambio de breaking que no puedes ignorar:** `tool_choice` con valor `any` o `tool` ahora retorna un 400. El forced tool use desapareció. Si tienes agentes que fuerzan herramientas, actualiza los prompts antes de migrar.

Mythos 5.1 es el mismo modelo con safeguards más fuertes, disponible solo para partners de ciberseguridad y ciencias de la vida.

Precios sin cambio: $10 entrada / $50 salida por millón de tokens. El batch processing a $5/$25.

### 2. OpenAI Astra: El primer modelo que cruza el umbral "Critical" de ciberseguridad — y no se lanza irrestricto

OpenAI publicó el writeup de safety de Astra, su próximo modelo, admitiendo que es el primero en cruzar su umbral "Critical" de capacidades ofensivas de ciberseguridad: puede identificar y explotar zero-days en sistemas críticos reales sin intervención humana, y diseñar estrategias de cyberataques end-to-end en targets hardened.

La decisión: lanzamiento restringido. Acceso ofensivo solo para partners del programa Daybreak Blue (testers aprobados). Monitoreo de chain-of-thought en producción. OpenAI lo llama "su modelo más alineado hasta la fecha."

El precedente es significativo: es la primera vez que una frontier lab frena un modelo por capacidades ofensivas antes del lanzamiento general, no después.

*Fuentes: [CNBC](https://www.cnbc.com/2026/09/01/open-ai-astra-cyber-model.html), [TechCrunch](https://techcrunch.com/2026/09/01/open-ais-astra-model-is-on-the-way-and-very-good-at-breaking-into-computer-systems/), [OpenAI](https://openai.com/index/pacing-model-development-cyber-capabilities/)*

### 3. Meta Muse Spark 1.3: El open-source que llegó al frontier — y es serio para agentes

Meta lanzó Muse Spark 1.3 el 2 de septiembre. Los números relevantes para builders de agentes: 20% menos tool calls, 25% menos tokens, ventana de 1M tokens, 75.4% en DeepSWE 1.1, 98.5% en long-context retrieval. En el Artificial Analysis Intelligence Index, el modelo max (62 puntos) queda detrás solo de Fable 5.1 y Opus 5.

Precio estable: $1.25 entrada / $4.25 salida — una fracción del costo de Fable. Para pipelines agenticos de alto volumen donde el costo domina, Muse Spark 1.3 es una alternativa real que justifica evaluación seria.

*Fuentes: [Bloomberg](https://www.bloomberg.com/news/articles/2026-09-02/meta-releases-more-powerful-ai-model-edging-closer-to-rivals), [Artificial Analysis](https://artificialanalysis.ai/articles/muse-spark-1-3), [MarkTechPost](https://www.marktechpost.com/2026/09/03/meta-ai-released-muse-spark-1-3-an-agentic-coding-model-that-uses-20-fewer-tool-calls-and-25-fewer-tokens-than-muse-spark-1-2/)*

## 🛠 Tool & Repo Watch — Herramientas y repos

### Claude Code — Changelog Septiembre 2026

**¿Qué cambió:**
- `/diff` — Panel lateral que muestra cambios no commiteados mientras Claude edita. En fullscreen, se abre junto a la conversación. Útil para revisar lo que Claude está haciendo sin salir del flujo.
- `/skill-doctor` — Nuevo comando que muestra qué skills cargadas no se están usando y cuánto context cuestan. Herramienta directa para optimizar tu CLAUDE.md.
- `bashOutputMaxChars` / `taskOutputMaxChars` — Puedes subir el output inline de comandos hasta 128K caracteres, evitando que Claude pierda contexto en runs largos.
- MCP reconnect automático — Los MCP servers remotos en sesiones no-interactivas y SDK que antes se colgaban tras perder conexión ahora reconectan automáticamente o reportan como fallidos.
- `allowedMcpServers` ahora solo gobierna servidores que el usuario agrega manualmente, no los managed MCP servers.

**Por qué te importa:** `/skill-doctor` solo ya justifica el upgrade — puedes ver exactamente qué skills de tu CLAUDE.md están ocupando context sin usarse. El reconnect automático de MCP es crítico si corres sesiones no-interactivas o Routines con MCP servers externos.

*Acción sugerida:* Actualiza Claude Code y corre `/skill-doctor` en tu sesión principal.

*Fuente: [Claude Code Docs](https://code.claude.com/docs/en/changelog)*

### Anthropic Managed Agents — Public Beta activa ($0.08/hora de sesión)

El Managed Agents de Anthropic lleva en public beta desde abril 2026 pero merece revisión fresca. Es una infraestructura hosted para agentes autónomos: tú mandas eventos a una sesión via `/v1/agents`, Anthropic corre el harness y sandbox, y tú streameas los resultados. Sin construir tu propio agent loop.

**Stack técnico:** `anthropic` v0.121.0 (Messages API) + `claude-agent-sdk` v0.2.134 (harness con subagents, MCP, checkpointing, cost tracking). El header de beta es `managed-agents-2026-04-01`.

**Pricing real:** Token rates estándar + $0.08 por session-hour activa + $10 por 1,000 búsquedas web dentro de sesiones.

**Por qué te importa:** Si estás corriendo agentes de larga duración que necesitan checkpointing y no quieres mantener infraestructura, esto elimina el overhead. Si ya usas Claude Code con Routines para automatización, el SDK agéntico es la capa de producción natural para escalar.

*Acción sugerida:* Explorar — especialmente si tienes pipelines que corren más de 30 minutos.

*Fuentes: [Hatchworks](https://hatchworks.com/blog/claude/claude-agent-sdk-and-managed-agents/), [Zylos Research](https://zylos.ai/research/2026-04-20-claude-agent-sdk-managed-agents-architecture/)*

### Google Workspace MCP Server — Gmail, Drive y Docs sobre MCP en producción

Google Workspace ahora tiene un MCP server oficial. Los agentes pueden conectarse a Gmail, Drive y Docs via MCP en producción — el mismo protocolo que ya usas en Claude Code/Desktop.

**Por qué te importa:** Si construyes agentes de automatización con n8n o pipelines custom, ahora tienes acceso estandarizado a Google Workspace sin manejar OAuth manualmente para cada servicio. Directo compatible con el ecosistema MCP que ya tienes.

*Acción sugerida:* Explorar e integrar en pipelines que ya tocan Google Workspace.

*Fuente: [Strac.io](https://www.strac.io/blog/google-workspace-mcp-server)*

## ⚠️ Buyer Beware — Alerta de hype

**Todos hablan de Astra como "la IA más peligrosa jamás construida", pero ojo:** El framing de "demasiado buena para lanzar" es también una maniobra de PR perfecta que coloca a OpenAI como el actor responsable del frontier. La decisión de restringir es real, el monitoreo de chain-of-thought es real — pero la narrativa de peligro extremo también mueve conversación, captación de partners y presión regulatoria en dirección favorable a OpenAI. Evalúa el anuncio por sus implicaciones técnicas (el umbral Critical es concreto), no por el drama de la cobertura mediática.
