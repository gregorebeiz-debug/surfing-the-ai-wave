### Semana pesada en Anthropic: Fable 5.1 + EFS

El 1 de septiembre Anthropic publicó dos movidas simultáneas que pasan desapercibidas detrás del ruido de OpenAI:

**Claude Fable 5.1 y Mythos 5.1** — Dos modelos idénticos con diferentes niveles de safeguards, orientados a coding, knowledge work e investigación científica. Mythos 5.1 tiene restricciones más laxas para casos de uso científico avanzado.

**Enterprise Frontier Safeguards (EFS)** — La solución al problema que bloqueaba a empresas reguladas: cómo usar Claude sin que Anthropic retenga datos, pero manteniendo detección de misuse entre sesiones. La solución: los logs van al cloud del cliente (AWS S3, Azure Blob o GCS) bajo las llaves de encriptación del cliente. Anthropic corre la lógica de detección sin acceso humano al contenido. Desarrollado con 100+ empresas de finanzas, salud, manufactura y sector público.

**Por qué importa:** EFS es arquitectura enterprise seria. Si algún cliente de Gregorio está en sectores regulados (finanzas, salud), esto baja la barrera para adoptar Claude en producción. La separación datos/lógica es el patrón correcto — no un parche.

*Fuentes: [MarkTechPost](https://www.marktechpost.com/2026/09/02/anthropic-enterprise-frontier-safeguards-efs/), [Anthropic](https://www.anthropic.com/news/enterprise-frontier-safeguards), [Unite.AI](https://www.unite.ai/anthropic-announces-enterprise-frontier-safeguards-customer-held-data/)*

## 🔧 Tool & Repo Watch — Herramientas y repos

### OpenClaw — Agente open-source, 250K+ GitHub stars, definido en Markdown

**Qué es:** Framework MIT-licensed para agentes AI auto-hospedados. Cada agente se define en un archivo `SOUL.md` con identidad, reglas y skills — sin Python, sin objetos de configuración complejos. Soporta Claude 4, GPT-4o, Gemini 2.0 y DeepSeek V3. Integra con Telegram, Discord y WhatsApp. Incluye 162 templates de agentes en 24 categorías y marketplace de skills.

**Por qué te importa:** Si construyes agentes con Claude SDK y los defines manualmente hoy, OpenClaw ofrece una capa de abstracción liviana que no te ata a un framework pesado como LangGraph. El patrón SOUL.md encaja con cómo ya documentas tus proyectos en CLAUDE.md. Con 250K+ estrellas y licencia MIT, la comunidad es activa y el riesgo de abandono es bajo.

**Acción sugerida:** Explorar — especialmente el marketplace de skills y los 162 templates.

→ [openclaw.ai](https://openclaw.ai/) | [GitHub](https://github.com/openclaw/openclaw) | ★ 250K+

### Claude Code — managedMcpServers para organizaciones

La actualización más reciente de Claude Code agrega `managedMcpServers`, un setting que permite a organizaciones distribuir servidores MCP HTTP/SSE a todos sus usuarios sin que cada uno configure su `.mcp.json` manualmente. También se corrigió el bug que causaba que sesiones remotas tardaran 60 segundos en iniciar un turno después de que una página de browser-hosted MCP server desapareciera, y se mejoró el tiempo de inicio de sesiones headless/SDK en ~50ms.

**Por qué te importa:** Si manejas Claude Code para múltiples colaboradores o clientes, `managedMcpServers` es el feature que faltaba para distribuir servidores MCP (como el de Gmail, GitHub o Google Drive) centralmente, sin depender de que cada usuario lo configure. Importante para escalar workflows de automatización.

**Acción sugerida:** Instalar la versión más reciente de Claude Code. Revisar el [changelog](https://code.claude.com/docs/en/changelog).

## ⚠️ Buyer Beware — Alerta de hype

**Todos hablan de GPT-6 Astra como AGI, pero ojo porque...**

OpenAI lleva años moviendo el goalpost de qué cuenta como AGI. GPT-6 Astra tiene scores perfectos en benchmarks de razonamiento — benchmarks diseñados por la industria, algunos contaminados por los datos de entrenamiento de los mismos modelos que los evalúan. El claim de AGI de Brockman es marketing estratégico ahead of la presión competitiva con Anthropic y el posible IPO de Anthropic en octubre.

Lo que sí es real: el modelo parece genuinamente más capaz en multi-step reasoning. Lo que no está validado: que sea "AGI" en ningún sentido técnico o filosófico consensuado. Evaluarlo con tus propios casos de uso antes de cualquier decisión de migración.
