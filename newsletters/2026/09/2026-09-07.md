### 1. Anthropic dobla la apuesta: Fable 5.1 + Mythos 5.1 + Enterprise Frontier Safeguards

El 1 de septiembre, Anthropic lanzó tres movimientos en simultáneo:

**Fable 5.1 y Mythos 5.1** — Son el mismo modelo subyacente con distintos niveles de salvaguardas. Fable 5.1 es la versión GA con protecciones de producción estándar; Mythos 5.1 está disponible para organizaciones de ciberseguridad y ciencias de la vida verificadas por el gobierno de EE.UU. El cambio de precio más relevante: las lecturas de caché caen un **75%** — de $1 a $0.25 por millón de tokens. Para workloads con contexto repetido (agentes, RAG, pipelines de código), esto puede reducir el costo operativo a la mitad o más. También mejoran los benchmarks vs Fable 5 y GPT-5.6 Sol. Los falsos positivos en biología caen un 85%.

**Enterprise Frontier Safeguards (EFS)** — Combina zero data retention con detección automatizada de abusos, pero con un giro clave: los logs de actividad van a la infraestructura del cliente (AWS S3, Azure Blob o GCS), no a Anthropic. Los sistemas de detección de Anthropic operan sobre esa data sin revisión humana del contenido. Fue co-desarrollado con más de 100 clientes incluyendo Goldman Sachs, Morgan Stanley y Citi. Soporta Claude Code, Claude Enterprise, Bedrock, Google Agent Platform y Microsoft Foundry. Rollout en fases a partir del Q4 2026.

**Por qué importa:** Fable 5.1 ya es el modelo por defecto en Claude Code. La reducción de caché al 25% del precio anterior es directamente material para pipelines con sesiones largas. EFS abre Claude a verticals que eran inaccesibles por compliance.

### 2. OpenAI lanza GPT-6 Astra — computer use en producción, benchmarks que saturan

El 3 de septiembre, OpenAI presentó GPT-6 Astra, su nuevo modelo flagship de razonamiento. En pocas palabras: el salto más grande desde GPT-4.

- **Computer use real:** Navega como un humano — completa formularios, recorre webs, maneja spreadsheets "a velocidad sobrehumana" según OpenAI.
- **Contexto de 1.05M tokens**, salida máxima de 128K, input de texto e imagen.
- **Benchmarks extremos:** 98% en FrontierMath Tier 4, 99.9% en ARC-AGI-3. Diseñado para trabajo profesional, ingeniería de software, ciencias, salud.
- **Precio API:** $10/M input, $50/M output. Llega a ChatGPT, API, Azure y Bedrock.
- **Advertencia:** Calificado como "Critical" en el Preparedness Framework de ciberseguridad de OpenAI — prompts en áreas sensibles son rechazados en la versión pública.

**Por qué importa:** GPT-6 Astra establece una nueva barra de referencia para computer use autónomo. No es una mejora incremental — es el modelo más capaz disponible en API hasta ahora. Fable 5.1 y Astra ahora compiten directamente en el mismo espacio de workloads complejos y agentes de largo aliento.

### Claude Code 2.1.260 — El update que cambia el flujo de trabajo diario

Anthropic publicó una secuencia de releases entre el 3 y 4 de septiembre (v2.1.257 → 2.1.261) que en conjunto constituyen uno de los updates más densos de Claude Code hasta la fecha:

**Lo más práctico:**
- **Panel diff en vivo** (`/diff` en fullscreen): muestra tus cambios sin commitear mientras Claude edita — elimina el ciclo de alt-tab a `git diff` después de cada paso.
- **`/claude-api upgrade`**: migra automáticamente proyectos Python de `anthropic 0.x` a `1.x` — un comando, sin refactor manual.
- **Diagnósticos de caché y skills**: `/cost` ahora indica por qué no se activó la caché del prompt.
- **Startup más rápido**: el sandbox y el arrange de MCP ya no bloquean el primer frame. Para quienes abren y cierran Claude Code frecuentemente, se nota.
- **Descarga 78% más pequeña**: 75MB en lugar de 340MB en Linux x64 (compresión zstd).
- **Límites mayores de salida** en tareas y comandos inline.
- **Fable 5.1 como modelo por defecto** desde 2.1.257.
- Mejoras en VS Code workflows, selección de modelo, Remote Control y estabilidad de sesiones.

**Por qué ver:** Si usas Claude Code todos los días, este update tiene cambios directos en velocidad, visibilidad de cambios y costo de operación. El panel diff y el upgrade automático de SDK son los dos que más tiempo ahorran.

Eso significa que puedes conectar tu agente personal a Google Calendar, Notion, Home Assistant o cualquier API custom sin hardcodear credenciales ni escribir integraciones propias. Para alguien que ya usa Claude Code y construye automation workflows, OpenClaw es el puente entre tu stack de agentes y tus canales de comunicación diarios. El MCP server marketplace está en desarrollo.

- **Estrellas GitHub:** 384,000+

### MCP 2026-07-28 Spec — El protocolo se vuelve stateless

**Qué cambia:** La especificación MCP de julio 2026 transforma el protocolo de bidireccional/stateful a request/response stateless. Un servidor MCP remoto que antes necesitaba sticky sessions, session store compartido e inspección profunda de paquetes ahora puede correr detrás de un load balancer round-robin estándar.

**Por qué te importa:** Si construyes o despliegas servidores MCP en producción, esto simplifica radicalmente la infraestructura. Agrega extensiones para UIs server-rendered (MCP Apps) y trabajo de larga duración (Tasks). Autorización más cercana a OAuth/OIDC estándar. Python, Go y C# son SDKs Tier 1; Rust en beta. El ecosistema ya tiene 200+ servidores para GitHub, Slack, PostgreSQL, Stripe, Figma, Docker, Kubernetes.

- **Acción sugerida:** Monitorear si tienes servidores MCP en prod — la migración puede simplificar tu infra. Explorar si estás construyendo nuevos servidores.
