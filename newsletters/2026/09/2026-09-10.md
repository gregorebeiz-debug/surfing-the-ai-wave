## 🌊 The Wave Today — Noticias que mueven la aguja

### ECC: El "sistema operativo" para agentes de código ya tiene 255k estrellas

ECC (affaan-m) no es un plugin más para Claude Code. Es una capa de sistema operativo completa para agentes de código: 68 agentes especializados, 286 skills, 94 comandos, memoria persistente cross-session, y un hook system de verificación determinista que corre fuera del contexto del modelo. La arquitectura central: "plan → test → implement → review → verify → remember → improve" — instalada una vez, fundamental siempre.

El diferenciador no es la cantidad de skills, sino cómo está diseñado el sistema de memoria. El **Memory Vault** persiste contexto en Markdown local e inspectable, compartible entre Claude Code, Codex, Kimi y OpenCode. Los **Instincts** extraen patrones aprendidos de sesiones reales con confidence scoring, y los **Skills** se cargan on-demand para mantener el context window optimizado. **AgentShield** escanea el harness en busca de vulnerabilidades de configuración. Se instala con `npx ecc-universal setup` y Claude Code lo descubre nativamente.

Con 255,524 estrellas y 38,259 forks, ECC define el estado del arte del trabajo con agentes de código hoy. Si usas Claude Code diariamente y no lo conoces, tienes un gap concreto.

*Fuentes: [GitHub — affaan-m/ECC](https://github.com/affaan-m/ECC)*

### Convergencia en el ecosistema de "agent output quality": dos frameworks en trending global simultáneamente

`ayghri/i-have-adhd` (+4,650 estrellas hoy, 36k totales) y `obra/superpowers` (+688 hoy, 284k totales) subieron juntos al trending global de GitHub el mismo día. No es coincidencia: el mercado está reconociendo que la **calidad del output de agentes de código es el cuello de botella del momento**.

`i-have-adhd` resuelve el problema micro: 10 reglas de formato que reformatan respuestas de agentes para ser directas y accionables — "lead with the next action", "number multi-step tasks", "suppress tangential information". Disponible como skill para Claude, Cursor, Gemini, Kimi y Qwen. `superpowers` resuelve el problema macro: una metodología completa de desarrollo agentico — brainstorming colaborativo → validación de diseño → TDD forzado → subagent-driven-development → review de dos etapas. 681 commits, activo desde octubre 2025, soporta Claude Code, Cursor, Devin, Gemini CLI y GitHub Copilot.

Que ambos suban juntos sugiere que la maduración del ecosistema de agentes está pasando de "¿qué agente usar?" a "¿cómo hacer que el agente produzca trabajo verificable y accionable?". Esa es la pregunta correcta.

*Fuentes: [i-have-adhd](https://github.com/ayghri/i-have-adhd) | [superpowers](https://github.com/obra/superpowers)*

### OmniRoute normaliza el acceso multi-LLM: 63k estrellas, 352 proveedores, gateway gratuito

OmniRoute (+591 hoy) es un gateway de IA MIT-licensed que centraliza 352+ proveedores de LLM y 1200+ modelos en un único endpoint. Routing inteligente con 19 estrategias (round-robin, cost-optimization, context-aware). Token compression integrada que ahorra entre 15-95% de tokens (89% promedio). La oferta más notable: catálogo de ~1.47B tokens gratuitos/mes de 150+ proveedores sin costo inicial. Se despliega vía npm, Docker, Electron desktop, o Android (Termux). Soporte nativo para OpenAI, Anthropic, Google, xAI, DeepSeek, Mistral y Meta.

El hecho de que un gateway gratuito con estas capacidades alcance 63k estrellas señala que el problema de "vendor lock-in de LLM" está siendo tomado en serio por la comunidad. La compression de tokens es el feature menos visible pero potencialmente más valioso para workflows de contexto largo.

*Fuentes: [GitHub — diegosouzapw/OmniRoute](https://github.com/diegosouzapw/OmniRoute)*

## 🔧 Tool & Repo Watch — Herramientas y repos

### ECC — Agent Harness Operating System para Claude Code
68 agentes especializados, 286 skills, memory vault persistente, hook profiles (minimal/standard/strict) para verificación determinista fuera del modelo.
**Por qué te importa:** Usas Claude Code todos los días. ECC es la respuesta sistémica a tres problemas concretos de tu workflow: contexto que se pierde entre sesiones, agente que repite los mismos errores, y falta de handoffs entre herramientas. ⭐ 255,524 | [GitHub](https://github.com/affaan-m/ECC) | **Acción: Instalar — `npx ecc-universal setup`**

### mcp-memory-service — Memoria persistente open-source para agentes
REST API + knowledge graph + consolidación autónoma. Compatible con Claude, LangGraph, CrewAI y AutoGen. SQLite-vec para búsqueda semántica local. 1,934 estrellas.
**Por qué te importa:** Si tienes agentes en n8n o pipelines de LangGraph que necesitan recordar contexto entre ejecuciones, esta es infraestructura que puedes auto-hostear sin depender de servicios cloud de memoria. El MCP server integrado hace que Claude Code acceda a la memoria directamente. Alternativa open-source a Mem0 y similares.
⭐ 1,934 | [GitHub](https://github.com/doobidoo/mcp-memory-service) | **Acción: Explorar**

### Orca — ADE para flota de agentes paralelos
Corre Claude Code, Codex, Cursor, OpenCode y 30+ CLI agents simultáneamente, cada uno en su propio git worktree aislado. Comparas outputs y mergeas el ganador. App móvil para monitoring remoto. 65,545 estrellas.
**Por qué te importa:** El caso de uso principal para ti: cuando tenés un problema arquitectónico complejo y querés ver cómo lo enfocan Claude Code vs Codex vs OpenCode simultáneamente, Orca lo centraliza. Elimina el overhead de configurar múltiples terminals y gestionar worktrees manualmente. El mobile companion para monitorear agentes corriendo en background es genuinamente útil.
⭐ 65,545 | [GitHub](https://github.com/stablyai/orca) | **Acción: Explorar**

### claude-prompts-mcp — MCP server para templates y workflow chains
Prompts reutilizables, multi-step chains con quality gates, sintaxis de operador para componer workflows. Exporta directamente como skills nativos a Claude Code, Cursor, OpenCode y Gemini CLI.
**Por qué te importa:** Si repetís los mismos prompts complejos en Claude Code (análisis de arquitectura, revisión de seguridad, generación de tests), este MCP los convierte en skills instalables y compartibles. La exportación directa a Claude Code skills — sin fricción — es el diferenciador versus simplemente tener un directorio de prompts.
⭐ 187 | [GitHub](https://github.com/minipuft/claude-prompts-mcp) | **Acción: Instalar**

### open-second-brain — Memoria local para Claude Code viviendo en Obsidian
Memoria persistente para Claude Code y Hermes Agent que vive en tu Obsidian vault. "Nightly dream passes" convierten correcciones repetidas en preferencias confirmadas con confidence scoring. Adapters para Claude Code, Codex y OpenClaw.
**Por qué te importa:** Si ya usas Obsidian para tu base de conocimiento personal, esto cierra el loop con tu agente de código. El "dream pass" nocturno es una implementación concreta de aprendizaje continuo: cada vez que corriges a Claude, el sistema eventualmente internaliza esa preferencia como patrón confirmado. Más personal que ECC, complementario si ya tenés un vault activo.
⭐ 397 | [GitHub](https://github.com/itechmeat/open-second-brain) | **Acción: Explorar**
