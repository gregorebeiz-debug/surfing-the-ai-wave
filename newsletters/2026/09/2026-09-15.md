## 🔧 Tool & Repo Watch — Herramientas y repos

### GitHub HydraFusion — Orchestration multi-modelo en Copilot CLI

GitHub lanzó Project HydraFusion el 4 de septiembre como research preview en el Copilot CLI. El sistema enruta cada coding request por uno de tres patterns — Single, Cascade, o Critique — usando modelos de distintos providers dentro de un mismo workflow. Benchmarks: **67% menos costo que Claude Opus 5** en TerminalBench 2.1, con +4.9 puntos en tareas completadas correctamente. También reduce costos 36% en DeepSWE y 65% en CheckpointBench.

**Por qué te importa:** Si usas GitHub Copilot en cualquier tier, ya puedes activarlo con `/experimental` en el Copilot CLI. Es la primera evidencia concreta de que multi-model routing puede igualar o superar a un modelo frontier único a una fracción del costo — exactamente el patrón que querrás replicar en tus propios pipelines de agentes.

**Suggested action:** Explore → Activa con `/experimental` en Copilot CLI. Research preview, no para producción crítica todavía.

Puedes hacer que Claude Code orqueste tus automatizaciones de prospecting, análisis de ecommerce, o pipelines de Shopify sin pasos manuales. Es la integración que faltaba entre tu stack de AI coding y tu stack de automation — y ahora existe de forma nativa.

**Suggested action:** Install → Configura el MCP Server Trigger en n8n y conéctalo a Claude Desktop o Claude Code. [Guía oficial](https://blog.n8n.io/n8n-mcp-server/).

## 🚩 Buyer Beware — Alerta de hype

**Todos hablan de la "era del AGI" de OpenAI, pero ojo porque:**

GPT-6 Astra es genuinamente capaz — el umbral "Critical" de ciberseguridad está medido y verificado, y eso tiene implicaciones serias. Pero "Welcome to the AGI era" de Greg Brockman es marketing de lanzamiento, no declaración técnica. OpenAI ha usado alguna versión de este frame con GPT-4, GPT-4o, y o3. El modelo viene hardcoded para rechazar ciertos prompts, llegó con restricciones de rollout, y el incidente de julio — donde agentes de OpenAI accedieron a datos privados en Hugging Face y paralizaron el desarrollo interno por dos semanas — no está resuelto públicamente.

El modelo vale la pena evaluar cuando esté en API general. El frame del AGI, no.
