## The Wave Today — Noticias que mueven la aguja

### Claude Mythos 5.1: El modelo que Anthropic no quería soltar está suelto

Claude Mythos 5.1 fue lanzado el 1 de septiembre, pero no de forma pública. Anthropic retiene el modelo bajo [Project Glasswing](https://www.anthropic.com/project/glasswing) — una alianza con AWS, Apple, Cisco, CrowdStrike, Google, Microsoft y NVIDIA — precisamente porque Mythos puede descubrir vulnerabilidades de software de forma autónoma (zero-days) sin intervención humana. Esta semana, reportes indican que usuarios no autorizados obtuvieron acceso al modelo via un portal de terceros, lo que eleva el nivel de alarma en el sector de ciberseguridad.

La paradoja es brutal: el mismo modelo que Anthropic construyó para defender infraestructura crítica (ya encontró 10,000+ vulnerabilidades de alta severidad en software ampliamente usado) está potencialmente en manos equivocadas. Como contexto adicional, Anthropic también publicó su reporte "Detecting and countering misuse of AI" cubriendo operaciones identificadas entre diciembre 2025 y agosto 2026 donde actores de amenaza usaron Claude para ciberataques y espionaje.

**Por qué importa:** Si construyes agentes que se conectan a sistemas externos — APIs, bases de datos, credenciales — la superficie de ataque acaba de expandirse con un actor que tiene acceso a un model capaz de generar exploits autónomamente. El riesgo no es teórico.

*Fuentes: [Anthropic Project Glasswing](https://www.anthropic.com/project/glasswing), [Security Magazine](https://www.securitymagazine.com/articles/102251-unauthorized-users-accessed-claude-mythos-new-reports-suggest), [The Hacker News](https://thehackernews.com/2026/05/claude-mythos-ai-finds-10000-high.html), [Daily Pioneer](https://dailypioneer.com/news/slug-lite/anthropic-foils-ai-misuse-for-cyber-bio-threats?year=2026)*

### GPT-6 Astra: OpenAI declara la "era AGI" y apunta a ciberseguridad crítica

OpenAI lanzó GPT-6 Astra el 3 de septiembre como preview limitado con rollout activo a Plus/Pro/Enterprise y API/AWS. El modelo tiene 1.05M de contexto, 128K output, y benchmarks que saturan lo que existía: ARC-AGI-3 99.9%, FrontierMath Tier 4 97.6%, ExploitBench 100%. Sam Altman dijo que Astra "cambió sus propios workflows".

El detalle que no puedes ignorar: Astra es el **primer modelo OpenAI en alcanzar nivel Critical en ciberseguridad** — puede encontrar vulnerabilidades desconocidas y desarrollar exploits en sistemas bien protegidos sin guía humana paso a paso. OpenAI lo desplegó con salvaguardas, y el mismo motor alimenta Codex. El 10 de septiembre, OpenAI también abrió su Agents API en public beta (ver sección Tool Watch).

**Por qué importa:** Para quien usa Claude Code diariamente: tienes competencia directa a nivel de agente de coding de élite. La brecha entre el top tier y el resto de LLMs acaba de crecer. Monitorear si Anthropic responde antes de DevDay OpenAI (29 sept).

*Fuentes: [OpenAI](https://openai.com/index/gpt-6-astra/), [CNBC](https://www.cnbc.com/2026/09/03/open-ai-astra-gpt-6-cyber.html), [DataCamp](https://www.datacamp.com/blog/gpt-6-astra), [Fox Business](https://www.foxbusiness.com/technology/openai-unveils-gpt-6-astra-major-advances-ai-capabilities)*

### OpenAI Agents API Public Beta: El harness de Codex ya disponible para todos

El 10 de septiembre, OpenAI abrió en public beta su [Agents API](https://openai.com/index/introducing-the-agents-api/) — el mismo motor que impulsa Codex, ahora disponible via API para cualquier developer. Una llamada de API da acceso a: sesiones de agentes long-lived, herramientas MCP y custom, coordinación de subagentes, compactación automática de contexto, y ejecución en sandbox de OpenAI o entorno propio del developer.

El pricing es limpio: sin cargo separado por la API — facturas solo por modelos y herramientas usados en cada sesión. Resultados de early adopters: 60% reducción de costos (SafetyKit), 86% menos fallos (Hypha), 4x mejor latencia (Cirridae).

**Por qué importa:** Esto es directamente competitivo con el Claude Agent SDK. Si construyes agentes multi-step que requieren context compaction automática y subagents coordinados, ahora tienes dos opciones serias de nivel enterprise. Anthropic necesita responder con paridad de features o diferenciar claramente en el Claude SDK.

*Fuentes: [OpenAI](https://openai.com/index/introducing-the-agents-api/), [MarkTechPost](https://www.marktechpost.com/2026/09/10/openai-launches-the-agents-api-in-public-beta-putting-the-codex-harness-behind-one-api-call/), [KuCoin News](https://www.kucoin.com/news/flash/openai-launches-agents-api-public-beta-opens-codex-infrastructure-to-developers)*

## Tool & Repo Watch — Herramientas y repos

### Bumblebee (perplexityai/bumblebee) — Scanner de seguridad para supply chain y configs MCP

**Qué hace:** Scanner open-source de solo lectura que inspecciona metadatos de paquetes (npm, PyPI, Go, RubyGems), extensiones de IDE (VS Code, JetBrains), extensiones de browser, y **archivos de configuración MCP** para detectar compromisos de supply chain conocidos. Escrito en Go, binario único, cero dependencias externas. Apache 2.0.

**Por qué te importa:** Si usas Claude Code con MCP servers — y lo usas — este es el primer scanner open-source que trata los archivos de config MCP como superficie de seguridad. Si alguien inyecta un conector malicioso en tu config de Claude Code, tu AI assistant puede filtrar credenciales o ejecutar comandos no autorizados en background. Con el breach de Mythos esta semana y el reporte de misuse de Anthropic, el timing no podría ser más pertinente.

**Repo:** [github.com/perplexityai/bumblebee](https://github.com/perplexityai/bumblebee) | Apache 2.0
**Acción sugerida:** Instalar y correr contra tu setup de Claude Code esta semana. Prioridad alta.

### Claude Code v2.1.261 — Plugin evals, diff panel lateral, Containment Escape rule

**Qué hace:** La versión más reciente de Claude Code (semana del 3–10 sept) trae cambios de seguridad y UX relevantes:
- **Plugin evals:** Suites de evaluación corribles directamente desde Claude Code
- **Diff panel lateral:** Uncommitted changes en side-by-side para review más fácil antes de commits
- **Containment Escape rule:** En modo auto, los fetches a cloud metadata credentials, evasión de egress y cross-tenant reach ya NO se auto-aprueban sin configuración explícita
- **Claude Fable 5.1 como modelo default** con mejor pricing ($10/$50 Mtok, $0.25 cache reads)

**Por qué te importa:** El Containment Escape rule es el cambio de seguridad más importante para quien corre agentes automáticos. Si usas Claude Code en pipelines automatizados como este routine, este control previene que un agente comprometido robe credenciales de cloud sin aprobación. Revisa si algún workflow existente depende de calls que ahora requieren aprobación explícita.

**Acción sugerida:** Actualizar inmediatamente. Auditar workflows automatizados existentes.

### Claude Fable 5.1 — Nuevo default con pricing mejorado en cache

**Qué hace:** Modelo lanzado el 1 de septiembre, ahora el default en Claude Code. Terminal-Bench-Science mejoró de 24.7 a 52.6 (2.1x). Contexto 1M. Pricing: $10/$50 por Mtok (input/output), **$0.25/Mtok en cache reads**.

**Por qué te importa:** El cache reads pricing a $0.25/Mtok es especialmente relevante para workflows con contexto repetido — exactamente el caso de este routine de newsletter y cualquier pipeline con system prompts largos. Si tienes agentes n8n o pipelines de automatización que llaman a Claude repetidamente con contexto similar, el ahorro puede ser significativo comparado con versiones anteriores.

**Acción sugerida:** Monitorear quality en workflows existentes tras el cambio de default. El benchmark de 2x en Terminal-Bench-Science sugiere mejora en tareas de código.
