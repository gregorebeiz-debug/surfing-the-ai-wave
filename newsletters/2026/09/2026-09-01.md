### Claude Code: el "aumento del 25%" que en realidad es un recorte del 17%

Anthropic anunció que el 14 de septiembre sube permanentemente los límites semanales de Claude Code en un 25% para planes Pro, Max, Team y Enterprise. Suena bien — hasta que haces la matemática. ### MCP 2026-07-28: el protocolo abandona el estado — mayor cambio desde su lanzamiento

La especificación del 28 de julio es la revisión más profunda que ha recibido el Model Context Protocol desde su creación. El cambio central: MCP deja de ser stateful. Se elimina el handshake de inicialización, las sesiones a nivel de protocolo, y el `Mcp-Session-Id`. Cada request ahora lleva toda la información necesaria para procesarse de forma independiente — exactamente como funciona HTTP moderno. El resultado práctico: puedes correr servidores MCP detrás de un load balancer estándar, en Kubernetes, en funciones serverless, en Cloudflare Workers, sin infrastructure especializada ni shared storage entre nodos.

Cloudflare ya actualizó su Agents SDK para soportar la especificación desde day zero. Google también publicó guía de infraestructura. La crítica legítima que circula en InfoQ: ¿no es esto básicamente una API REST con pasos extra? La respuesta honesta: sí, en muchos casos. Pero la estandarización y el ecosistema de tooling que viene con MCP siguen siendo el argumento.

Para Gregorio: si tienes servidores MCP en producción, vale la pena revisar si la migración a la spec stateless simplifica tu infraestructura.

### Cursor + SpaceX + OpenAI: el más costoso drama del ecosistema en meses

El 14 de agosto, SpaceX completó la adquisición de Cursor por $60B. El 29 de agosto, OpenAI anunció que termina su partnership: el 12 de noviembre, Cursor pierde acceso directo a modelos OpenAI. Los modelos futuros, incluyendo Astra, no estarán disponibles. Justificación de OpenAI: "no podemos confiar en que SpaceX usará nuestra tecnología dentro de nuestros términos, basándonos en nuestra experiencia con empresas de Elon Musk violando contratos."

Lo que esto significa para el ecosistema: Cursor — que corre en Claude + GPT como backend — queda con un proveedor crítico menos. Anthropic no ha hecho anuncios similares. Cursor pasará a depender más de los modelos xAI/Grok y del acceso de SpaceX a Colossus. Para usuarios de Cursor: tu experiencia de codificación va a cambiar antes de fin de año. Para usuarios de Claude Code: esto es directamente favorable — un competidor principal acaba de perder un motor clave.

## 🛠 Tool & Repo Watch — Herramientas y repos

### Bumblebee (Perplexity AI) — Scanner de supply chain para tu entorno de desarrollo

**Qué hace:** Scanner de solo lectura para macOS y Linux que revisa tus dependencias npm/PyPI/Go, configuraciones de servidores MCP, extensiones de VS Code/Cursor/Windsurf, y extensiones de Chromium/Firefox en busca de indicadores de compromiso por supply chain attacks. Escrito en Go. Nunca ejecuta código — lee solo archivos de metadata — lo que lo hace seguro incluso si ya tienes paquetes comprometidos.

**Por qué te importa:** Usas Claude Code con MCP servers, y probablemente instalas extensiones frecuentemente. El ataque vectorial que Bumblebee detecta específicamente — configuraciones MCP manipuladas que inyectan instrucciones maliciosas en el contexto de trabajo de un agente para exfiltrar credenciales o invocar herramientas en background — es exactamente el tipo de ataque que te afecta a ti. Los gusanos Shai-Hulud y Mini Shai-Hulud que afectaron paquetes de TanStack, SAP y Zapier en meses recientes son el contexto de por qué esto existe. Nació en producción, no en academia.

**Detalles:** v0.1.1 (mayo 2026), Apache 2.0, ~stars no disponibles via web
**Acción sugerida:** Instalar y correr antes de continuar con cualquier nuevo MCP server. → [GitHub](https://github.com/perplexityai/bumblebee)

### Anthropic Managed Agents: session budget API — control de costo en tiempo real

**Qué hace:** La API de Managed Agents ahora permite set/update/remove un presupuesto (hard cap de gasto) en una sesión activa. Si la sesión alcanza el budget, se pausa con `stop_reason: budget_reached` — no se cancela, espera. Puedes subir el límite, bajar el límite, o removerlo (`null`) para reanudar. La remoción es irreversible: un budget removido no puede re-añadirse.

**Por qué te importa:** Si construyes agentes autónomos con la API de Managed Agents, esta capacidad es lo que convierte "déjalo correr" en algo viable en producción. Puedes arrancar agentes con un presupuesto conservador, monitorear, y aumentarlo dinámicamente si el trabajo justifica el costo. Es especialmente útil en flujos de n8n o pipelines custom donde un agente puede encontrar casos edge que disparen el costo inesperadamente.

**Precio base:** $0.08 por session-hour (solo tiempo en ejecución, no idle) + tokens estándar Claude API.
**Acción sugerida:** Explorar si tu stack de agentes se beneficia de esta capa de control. → [Anthropic Docs](https://github.com/anthropics/skills/blob/main/skills/claude-api/shared/managed-agents-api-reference.md)
