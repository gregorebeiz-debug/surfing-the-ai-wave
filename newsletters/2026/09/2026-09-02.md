## 🌊 The Wave Today — Noticias que mueven la aguja

### Claudeforce: Salesforce apuesta $300M en Claude como motor por defecto

Salesforce y Anthropic anunciaron "Claudeforce" el 26 de agosto: Claude pasa a ser el motor de razonamiento predeterminado en todo el ecosistema Salesforce. La integración no es cosmética — incluye 37 skills de ventas preconstruidas, acceso directo al pipeline de CRM desde Claude, y un plugin "Salesforce in Claude" que entra en beta abierta este mes de septiembre. Salesforce se comprometió a gastar ~$300M en tokens de Anthropic solo en 2026, sobre una inversión en equity de otros $300M. El mercado reaccionó: el stock de Salesforce (CRM) subió 12-14% en afterhours el día del anuncio.

Lo que importa más que el monto: esto señala el fin del "modelo-agnóstico" en enterprise AI. Las grandes plataformas eligen un modelo core y construyen sobre él.

*Fuentes: [Salesforce Press Release](https://www.salesforce.com/news/press-releases/2026/08/26/salesforce-and-anthropic-announce-claudeforce/), [Digital Commerce 360](https://www.digitalcommerce360.com/2026/08/27/salesforce-anthropic-claude-partnership-claudeforce/), [Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/salesforce-claudeforce-deal-anthropic-signals-102859998.html)*

### Fable 5.1 y Mythos 5.1: los nuevos modelos top de Anthropic

Anthropic lanzó Fable 5.1 y Mythos 5.1, descritos como los modelos más avanzados del mundo para coding y knowledge work respectivamente. Claude Security — el sistema de escaneo de vulnerabilidades en codebases — ya corre sobre Mythos 5.1. No hay benchmarks oficiales publicados todavía, pero la postura de Anthropic es directa: Fable 5.1 es el modelo para escribir código, Mythos 5.1 para razonar sobre él.

*Fuentes: [Releasebot Anthropic](https://releasebot.io/updates/anthropic), [Mean CEO Blog](https://blog.mean.ceo/anthropic-claude-news-september-2026/)*

### OpenAI frena el desarrollo de Astra por riesgo de seguridad

OpenAI reportó "evidencia preliminar" de que su próximo modelo Astra podría alcanzar el umbral de capacidades "cyber-críticas" definido en su Preparedness Framework. En respuesta, ralentizaron deliberadamente el ritmo de escalado. Es la primera vez que OpenAI aplica ese mecanismo de freno en público. Hay que observar: ¿es transparencia real o gestión de narrativa? La demostración del mecanismo importa independientemente del motivo.

*Fuentes: [OpenAI](https://openai.com/index/pacing-model-development-cyber-capabilities/), [OpenAI News](https://openai.com/news/)*

### Google mata a Google Assistant el 4 de septiembre

Google inicia el shutdown de Google Assistant el 4 de septiembre en su plataforma móvil, reemplazándola completamente con Gemini. El movimiento es definitivo: no migración gradual sino sustitución. Gemini 3.6 Flash y 3.5 Flash-Lite pasaron a disponibilidad general esta semana, con mejoras en token efficiency y capacidades de agent planning.

*Fuentes: [SiteProNews](https://www.sitepronews.com/2026/08/31/googles-gemini-will-start-replacing-google-assistant-today/), [Memeburn](https://memeburn.com/google-is-replacing-assistant-with-gemini-ai-shutdown-starts-september-4/), [Google AI Dev](https://ai.google.dev/gemini-api/docs/changelog)*

## 🔭 Deep Dives — Vale la pena explorar directamente

### Arquitectura de OpenClaw: lo que enseña el proyecto más estrellado en la historia de GitHub

El repositorio de OpenClaw cruzó los 210,000 stars en julio y sigue creciendo — ya supera a React, TensorFlow y Vue como el proyecto más estrellado de GitHub (388K stars, 81K forks al 26 de agosto). Un análisis de Medium de Micheal Lanham descompone por qué la arquitectura funciona: un único binario Go sin dependencias externas, zero cloud, que conecta un modelo local a 50+ herramientas (Gmail, Notion, WhatsApp, Telegram, Slack, GitHub, Postgres). El análisis no es de fanboy — explica los tradeoffs de diseño.

**Por qué leer:** Si estás pensando en cómo construir agents que corran completamente on-premise para clientes o para tu propio stack, OpenClaw es el caso de estudio más relevante del momento. La arquitectura es directamente transferible.

[Leer análisis](https://medium.com/@Micheal-Lanham/210-000-github-stars-in-10-days-what-openclaws-architecture-teaches-us-about-building-personal-ai-dae040fab58f)

## 🛠️ Tool & Repo Watch — Herramientas y repos

### Unabyss — Capa de contexto MCP-nativa para tus AIs
Sincroniza tu información de Slack, Gmail, Notion y GitHub en un vault estructurado que cualquier herramienta MCP-compatible (Claude Desktop, Cursor, Perplexity) puede leer con una línea de configuración. Es un conector oficial en el directorio de Claude.

**Por qué te importa:** Gregorio, esto resuelve directamente el problema de re-explicarle el contexto de tu trabajo a Claude en cada sesión. Si usas Claude Code + Claude Desktop como tu setup diario, Unabyss puede hacer que ambos lean tu contexto de Notion y GitHub sin configuración manual. La integración nativa MCP es el diferenciador real — no es otro plugin ad-hoc.

Acción sugerida: **Instalar y testear** → [unabyss.com](https://unabyss.com/)

---

### OpenClaw — Agente AI local, self-hosted, 50+ integraciones
Binario Go único, zero cloud, corre en tu máquina o un VPS pequeño. Conecta modelos locales (Llama, Mistral, o cualquier API) a WhatsApp, Telegram, Slack, Gmail, GitHub, Postgres, y más. 388K stars, Apache 2.0.

**Por qué te importa:** Si construyes automation workflows que necesitan privacidad total o correr on-premise para un cliente, OpenClaw es la base más probada disponible hoy. La cantidad de integraciones listas para usar supera lo que puedes construir manualmente en n8n en semanas. Vale explorar como complemento o alternativa ligera para ciertos casos de uso.

Acción sugerida: **Explorar** → [github.com/openclaw-ai](https://openclaw.ai/) | [openclaw-ai.net](https://openclaw-ai.net/en)

---

### Bumblebee (Perplexity) — Scanner de supply chain para developers
Binario Go, read-only, zero network calls durante el scan. Verifica tus dependencias de npm/pnpm/PyPI/Go, extensiones de VS Code, extensiones de browser, y — crítico — archivos de configuración de MCP. Open source, Apache 2.0.

**Por qué te importa:** Gregorio, usas Claude Code con múltiples MCP servers. Un MCP server comprometido puede inyectar instrucciones en el contexto del agente sin que lo notes — es el vector de ataque más silencioso contra setups de AI. Bumblebee es la única herramienta que hoy escanea especificamente configs MCP. No es paranoia: es higiene básica de seguridad para un stack como el tuyo.

Acción sugerida: **Instalar** → [github.com/perplexityai/bumblebee](https://github.com/perplexityai/bumblebee)

---

### OpenCode — Coding agent multi-plataforma con BYO-model
Agente de coding que corre en terminal, desktop app, extensión de IDE, o browser. Delega tareas de código mientras tú eliges el modelo y API key. Comparable a Claude Code pero modelo-agnóstico.

**Por qué te importa:** Interesante como referencia arquitectónica si construyes coding agents para clientes. Si tu cliente usa GPT o Gemini pero quiere la experiencia de Claude Code, OpenCode es una base que puedes adaptar. Para tu uso personal, probablemente Claude Code te da más.

Acción sugerida: **Monitorear** → [llm-stats.com](https://llm-stats.com/llm-updates)
